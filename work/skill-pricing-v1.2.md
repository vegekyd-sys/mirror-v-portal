## 一、定价方法论

### 1.1 定价公式

```
Skill Credit = 平衡（成本底线，业务价值底线，商业消耗底线）
```

- **成本底线** = 直接成本 × 风险系数 ÷ 0.01 ÷（1 - 目标毛利率）
- **业务价值底线** = 该动作对客户的实际商业价值
- **商业消耗底线** = 保证套餐在合理周期内被消耗完，驱动续费和升级

三个值取平衡而非简单取最大值。商业消耗作为上限约束，成本和业务价值作为下限保障。

### 1.2 成本测算方法

直接成本由两部分组成：

```
直接成本 = Token成本 + 外部API成本
```

**Token 成本来源于 6 个 dealclaw 内测群的实测数据：**

| 数据源 | 样本量 | 单价 |
|---|---|---|
| DealClaw 卧龙凤雏群 | 310,273 tokens / $0.85 | — |
| DealClaw 内测群 | 180,835 tokens / $0.11 | — |
| DealClaw Nexus 群 | 442,718 tokens / $0.26 | — |
| DealClaw 独立 Agent 群 | 110,406 tokens / $0.70 | — |
| DealClaw 测试群 | 43,762 tokens / $0.07 | — |
| DealClaw 主群 | 64,524 tokens / $0.10 | — |
| **合计** | **1,152,518 tokens / $2.09** | **$0.0018/1K token** |

> 模型：deepseek-v4-pro | 汇率参考 ¥7.2/$1 | Token 单价 ≈ ¥0.013/1K token

**外部 API 成本来源于各 Skill 的实际调用链路：**

- CDP search API（dealclaw_search.py）：展会国买家搜索
- Apollo API：非展会国买家搜索 + 联系人补全 + 邮箱解锁
- Resend API：邮件批量发送
- OCR/ASR 服务：名片识别与录音转写
- Web Search/Fetch：企业信息补全与验证
