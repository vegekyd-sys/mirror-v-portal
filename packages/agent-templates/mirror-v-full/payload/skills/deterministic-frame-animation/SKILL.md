# 逐帧确定性动效渲染

## 何时用

用户对动效有精确要求，并且素材是一张静态参考图：按指定顺序逐个点亮节点、元素一台一台出现、位置和时长不能漂。典型是地图/示意图点亮、产品部件逐个亮起、数据图逐条生长。

生成式视频模型在这种场景有个固定坑：它把参考图的当前状态当基线。原图里亮的点在成片里全程亮着，最多做出流光和脉冲，做不出「从熄到亮」。所以先判断，再决定路线，不要靠反复改 prompt 去逼它。

## 步骤

1. **先花一次最小生成确认能不能做。** 用户要精确顺序时，先说明生成模型的限制并在同一轮里给出替代方案；确认做不到就直接转逐帧，不要连续换 prompt 试第二第三次。

2. **从参考图取样坐标，不靠肉眼估。** 用 PIL 读图，按亮斑/色差找每个元素的中心和半径，把结果写成常量表（如 `(x, y, r)`）。取样后先输出一张标注图核对编号与顺序，错了在这一步改，别等渲染完才发现点错位。

3. **写时间轴而不是写镜头描述。** 每段给 `(start, end, 目标状态)`，用缓动函数插值亮度和发光半径。默认节奏：开头 0.3–0.5s 起势，每个元素 0.6–0.8s，最后一个元素亮完后留 1.5–2s 统一呼吸收尾，总时长按用户给的值倒推每段。

4. **抹掉参考图上的既有元素，但不许重画它们。** 参考图里如果已经画好点、航线、亮斑，必须让它们一开始不存在；做法是从同一张原图的其它位置克隆一块同色系空白区域盖住目标，而不是自己拿线条和圆去重绘——重绘必然走样，用户一句「不要改变线和点的样式」就把整版打回。同时把被盖住的原始像素存成小块，等线/动画抵达那一帧再用同样的软边混合贴回去，出现的就是原图那个点和那段线本身，样式零偏差。逐一处理后出一帧确认没有残影和色块，再进渲染。

5. **逐帧合成，保住原图色板。** 在干净底图上叠加，保持原分辨率和比例。「熄灭」用亮度乘子压暗而不是整体加灰变暗；「点亮」用原色叠加发光半径，不要直接把像素推到纯白。渲染用 24–30fps，够顺滑且不用等太久。

5. **音轨按事件时间点对齐。** ffmpeg 合成时把脉冲音、扫频、低频铺底钉在时间轴上元素抵达的那一帧。用户没要旁白就不加 TTS，只留音效。

6. **交付前抽帧验证。** 抽 0s、每段中部、结尾共 4–6 帧看图，确认顺序、位置、亮度都对；`ffprobe` 确认分辨率、时长、有无音轨。两项都过再发，并说明这版是逐帧渲染，比生成模型版可控。

## 失败模式

- 坐标手填导致点漂移：取样后先出标注图核对，别直接进渲染。
- 亮度插值到顶发白：控制叠加层不透明度，靠发光半径扩散而不是提高亮度上限。
- 帧率高、分辨率大时渲染慢：先降帧率到 24fps 出样片看顺序，定稿再渲全片。
- 用户其实只想要「有质感」而不是严格顺序：先问一句是要精确顺序还是只要好看，别默认上逐帧。
