# 荒诞物理流 · 爆款产品视频生成 Skill

## 与"极端产品力"Skill 的区别

| | 极端产品力 | 荒诞物理流 |
|---|---|---|
| 逻辑 | ✅ 合理，产品真实功能 | ❌ 反常识，但好笑 |
| 视觉 | 产品征服极端环境 | 物理定律崩坏的奇观 |
| 传递 | 直接展示功能 | 前10秒整活→最后3秒软着陆 |
| 例子 | 暴风雪中面料保暖 | 人趴在飞机外假发不散 |

## Trigger
用户要求"假发那种感觉"、"荒诞好笑但展示产品"、"开局暴击+最后软着陆"的 15-20s 短视频。

## 核心公式：荒诞物理四段式
🔥 暴击钩子 0-3s → 😂 荒诞展开 3-10s → ✂️ 丝滑转场 10-13s → 🎯 软着陆 13-15s

## 跟画面 bug 的界限
荒诞是故意的创意，不是 AI 生成错误。
✅ 人站飞机机翼假发不散 ❌ 沙子从风扇掉下来
✅ 人自由落体产品完好 ❌ 窗帘里喷冷气
✅ 高空精准砸进店 ❌ 横版素材被挤压

## 策划案 → Prompt
1. 读策划案 → 提取企业名/品牌愿景/产品名/核心卖点
2. 基于 1 个核心卖点设计反常识场景
3. 写三段式荒诞故事
4. 走 Seedance 出片

## 模型：仅 Seedance
有实拍素材必须走 Seedance 保产品不走样。渲染后用 project media 查成品，API 有缓存延迟等 2-3 分钟重试。

## QC 检查清单（7 项）
1. 前3秒是否"反常识到让人停下滑动"（不是平淡开场）
2. 荒诞是否服务于产品卖点（不是为荒诞而荒诞）
3. 转场是否流畅（不是硬切）
4. 最后3秒是否有清晰利益点/品牌/CTA
5. 画面是否有 bug（沙子掉落、水塘、素材挤压）
6. 字幕是否单行、下方1/3、不重复
7. 是否只发了 1 条
