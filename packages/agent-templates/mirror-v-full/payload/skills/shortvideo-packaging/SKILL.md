# 短视频包装（字幕 / 花字 / 封面 / 转场）

## 何时用

用户要做或评审短视频的**包装层**：口播字幕、装饰性字幕、花字、封面字、转场、抠像贴纸、emoji 策略、配色与字体排版。

典型触发：包装、花字、字幕、封面、转场、字体、配色、排版、抠像、emoji、视频看起来丑/乱/廉价。

## 不适用

- 只写脚本或选题 → 用对应脚本/策划 skill
- 只生成视频 → 用 Makaron / 对应视频 skill
- 只做数据复盘 → 用数据 skill

## 核心：先定四件事，再动手

1. **这句话的任务**：钩子 / 证据 / 数字 / CTA / 解释
2. **镜头类型**：半身口播 / 全身走播 / 产品特写 / 大景工厂 / 图文页
3. **市场性格**：德国 / 印尼 / 阿联酋 / 英语综合
4. **背景复杂度**：干净 / 货架纸箱 / 高光白墙 / 深色车间

包装不是选一个模板，是按这四个输入组合出方案。

## 包装层级

- **L1 轻包装（默认）**：开场顶部标题 + 可读口播字幕；0–2 个关键词；适合探厂、仓库、日常讲解
- **L2 强调**：L1 + 4 个装饰关键词；适合功能、认证、产能、交期、对比
- **L2+ 技术增强**：3D 剖面、热成像、CAD 图纸、认证徽章、大数字；适合结构/性能证明
- **L3 促销**：2–3 行大字块、价格徽章、产品抠图；适合批发价、多品类、展会、清仓
- **F 趣味探厂（可选）**：字幕上 1/3、漫画爆炸字 3–4 次、1 个反应表情；只用于高能/展会版

判断顺序：先问“这条要不要叫卖？”不要 → L1；要强调 → L2；要证明结构 → L2+；要打价格 → L3。

## 双层字幕（硬规则）

| 层级 | 作用 | 位置 | 字号 | 样式 |
|-|-|-|-|-|
| 口播字幕 | 让人听清 | 下方安全区或上 1/3 | 中等 | 白/黄字，细边或贴字底 |
| 装饰性字幕 | 抓眼、强调 | 上方/侧边/中部 | 1.8–2.5 倍 | 粗体、彩色、可描边 |

- 两层永不重叠；装饰层不进入字幕区
- 口播字幕逐句跟语音；装饰字幕 15 秒 4–6 次

## 字幕位置按镜头

- 半身口播 → 底部 78%–82%
- 全身/走播/脚部动作多 → 上 1/3（18%–28%）
- 产品特写 → 让位给产品，字幕靠边
- 大景工厂 → 顶部场景条 + 底部字幕

## 可读性方案按背景

- 干净背景：纯白字或细阴影
- 货架/纸箱/机器：贴字小底（55%–65% 半透明圆角，只包文字）或上 1/3
- 高光白墙：细黑边 2–3px
- 深色车间：白字 + 柔和外发光

不要一律加粗黑边，也不要一律加通栏黑条。

## 字体系统

角色只有三种：

- 展示字：Noto Sans Display ExtraCondensed Black；备选 DIN Condensed Bold / Montserrat Black / Inter Black
- 口播字幕：Noto Sans Display Condensed Black；备选 DIN / Inter SemiBold
- 标签：同一字体，小字号、宽字距

规格（1080×1920）：

- 展示字 96–140；口播字幕 48–54；标签 24–28
- 字距：展示 +0 到 +10；字幕 +10 到 +20；标签 +100 到 +150
- 行高：展示 1.0–1.1；字幕 1.2–1.3
- 一帧最多 2 个字号、2 个字重
- 全片只用 1 个字体家族

## 排版网格

- 8px 基线网格；左右安全边距 40–48
- 每帧只用一个锚定轴：左对齐 / 居中 / 右对齐，不混用
- 固定间距：标题→分隔线 12；分隔线→大数字 64；大数字 bbox→说明 8
- 对齐边缘，不对齐不同字号的中心
- 一帧最多 3 个文字块
- 顶部/底部各留 8% 安全区

## 配色语义

- 红：痛点、高价、低质、中间商
- 琥珀/金：注意力、价格、方案、工厂直供
- 蓝：信任、技术、工业
- 绿：环保、批发、性价比
- 白：高端、干净

一套片最多 1 个强调色 + 白/黑；文字与背景对比 ≥ 4.5:1。

## 装饰版式（同一系统轮换，不每条一样）

- **胶囊条**：主字幕正下方同轴；干净、日常
- **角标印章**：右上/左上，轻微旋转；轻趣味
- **下三分之一色带**：强强调、价格/结论
- **手写下划线/圈**：轻趣味、关键词强调
- **漫画爆炸**：高能/展会，最多 1–2 次

同一条片最多用 2 种版式；不要四个角各放一个。

## 抠像 / 贴纸 / emoji

- 抠像只在“材料→成品”“多品类 SKU”“价格对比”时用；探厂/真人信任类不用
- 产品抠图统一白描边或柔光，同一光源方向
- 专业贴纸可用：CAD 图纸、认证徽章、检测报告、白色手绘箭头
- 情绪 emoji（😂🔥💯）B2B 不用；UGC/招募可少量，且只用于遮脸/隐私
- 箭头只指向具体产品/参数/CTA

## 转场

- 优先：一镜到底、手势带镜头、同方向运动匹配、遮挡转场
- 场景切换加顶部场景条，0.5 秒内让观众知道在哪
- 不要每个转场都加同一 whoosh；不要频闪/闪光叠层

## 钩子与结构（来自 TK 反馈表）

- 开头 0–1 秒给动作 + 一句招呼：招手 + “Hello boss”、开门 + “没有中间商”、推盖 + “Call me”
- 一个场景只讲一个卖点；不要一个镜头塞三个信息
- 用具体数字和规模证明实力；数字单独放大
- 信息直给，先结论后公司介绍
- 口播字幕可以单词/短语逐个蹦出，跟语速
- 封面可用弯曲花字，但只做一次

## 平台规格

- 9:16，1080×1920，30fps
- 顶部 8%–12%、底部 18%–22%、右侧 12% 为平台 UI 安全区
- 字幕不进入底部 UI；品牌卡不压 CTA

## 评审清单

交付前抽 3 帧（钩子/中段/结尾）检查：

1. 全片是否只有 1 个字体家族、最多 2 个字号
2. 口播字幕是否在安全区、是否遮脸/遮产品
3. 装饰字是否超过 6 次、是否散在四个角
4. 是否只有 1 个强调色、对比是否足够
5. 是否有 emoji/卡通贴纸误用
6. 转场是否重复同一音效、是否频闪
7. 品牌卡/logo 是否与字幕重叠
8. BGM 是否盖住人声（低 22–26 dB + sidechain）

## 失败模式

- 用默认字体、字重不足、字距拥挤
- 粗黑边配彩色大字块 → 廉价
- 字幕贴头顶、压脸、压产品
- 每句都加花字、四个角乱放
- 一套片三种以上强调风格
- B2B 用情绪 emoji
- 转场全靠同一 whoosh
- BGM 盖人声

## 交付物

给出一份包装 spec：层级、字体/字号/字重、颜色、每个元素的位置百分比、装饰清单、转场清单、emoji 策略、验证帧。

如果继续制作，把 spec 交给 Makaron；不要说“感觉一下”，要给可执行参数。

## 边界

- 不编造数字、认证、客户案例；没有出处就不写
- 市场本地化不确定时，先要参考或明确假设
- B2B 默认不用情绪 emoji、不做人物全身抠像
- 包装不能压过口播和产品；主张 > 装饰
