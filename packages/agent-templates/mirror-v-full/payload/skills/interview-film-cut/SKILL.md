# 采访精剪（中文竖版全片）

适用于已有采访原始素材、要做一条中文竖版采访成片，且用户会连续提「人物标位置不对」「BGM 没铺满」「太长要精简」这三类修改。

## 0. 先拿到音轨与词级时间码

1. 群里发的视频如果回复里出现「provider does not support native video」，且 `media/inbound` 下只有图片、没有新视频，不要等它自动落地：用 bot 身份按消息 id 直接取资源
   `lark-cli im +messages-mget --as bot --message-ids <om_...> --download-resources`
   落地文件在 `lark-im-resources/`，`ls -lh` 确认大小非零、`ffprobe` 确认时长，再往下做。
2. 抽音频：`ffmpeg -i <video> -vn -ac 1 -ar 16000 -c:a pcm_s16le audio16k.wav`，用 `ffprobe` 核 wav 时长与视频相差 <0.5s。
3. 本地转写用 `faster_whisper`。1.2.1 与已装的 PyAV 不兼容，`decode_audio` 会抛 `TypeError: open() got an unexpected keyword argument 'metadata_errors'`：把已抽好的 wav 直接交给 `WhisperModel.transcribe()`，或在调用前 patch 掉该参数，不要为此改去装别的 ASR。
4. 一次导出三份同源产物：带时间码的 txt、srt、segments json。之后删词、重排时间轴、烧字幕都吃同一份 segments。
5. 中文转写里的人名、公司名、工艺名（冰裂、水洗皱这类）错得最多。成稿前把听不准的词单独列成确认清单交给客户，不要先写进字幕再返工。

完成标准：wav 时长与视频一致；segments 数量与语速相符（约每 3–4 秒一段）；srt 首末句时间码能对回原片。

## 1. 先量参考坐标，再摆人物标与字幕

人物标位置靠目测一定会返工。改为从已验收成片取坐标：

1. 对已确认的参考成片抽帧：`ffmpeg -ss <时间点> -i ref.mp4 -frames:v 1 ref.jpg`。
2. 在帧上量出人物标左上角像素坐标、人物标高度、字幕首行位置与字幕行宽，写成脚本里的常量（不要每次现调）。
3. 渲染后对**同一时间点**抽帧，与参考帧并排看：人物标与字幕的相对间距一致才算过。

完成标准：本片首帧与参考帧叠图对齐，人物标压在字幕正上方，间距一致。

## 2. BGM 从 0s 铺到结尾

1. BGM 时间轴起点设为 0 秒，用循环铺满全片长度，再按总长截断；不要只在有口播的段落铺。
2. 人声轨做 sidechain（或等价 ducking）：说话时 BGM 自动压低，说完回升。

完成标准：抽 0.5s 处音频确认已有 BGM；任取一段说话处，人声清楚不被盖住；片尾不出现音乐突断。

## 3. 精简按整句删，不按秒数砍

1. 逐段标出：提问铺垫、重复确认、离题半句、与下一段重复的补充说明——这些是首要删除对象。
2. 提问只留问题句本身；回答保留完整语义，宁可整段删，不要掐半句。
3. 金句、结论、数字口径不动。

完成标准：目标时长内每段话都能独立听懂，观众不觉得跳。

## 3.5 词级重建：字幕与音频必须同源

用户说「字幕跟音频劈叉」「语气词没去干净」「字幕高高低低」时，根因通常是字幕按原视频时间戳事后贴、音频整段保留。改用词级重建一次解决：

1. ASR 要返回 `words`（词级 start/end），不要只取句子级 utterances。
2. 删词先做：语气词（呃、啊、嗯、哦、这个、那个）、口癖、受访者复述提问的整句、提问里的铺垫与重复确认，都按词/按句标记删除。
3. 剩余词重排成新时间轴：词与词之间超过约 0.1s 的空白收掉，句间留固定小间隔。
4. 音频按这份新时间轴切词、拼回人声轨；字幕用同一份时间轴生成。两者同源，不会再漂移。
5. 字幕规则：全部单行、固定同一基线，不因字数多少上下浮动；按语义切句，避免 1–2 个字单独成句。
6. 片头、提问卡、转场这些插入段，先把它们的时长当静音补进音频时间轴，整片拼完后再对整条成片一次性烧字幕；不要逐段渲染时套全片字幕文件——插入段吃掉的时长会让每段各错开一点，累积成整片漂移。
7. 竖版安全区：字幕末行底边落在约 66% 高度（整块压在 58%–76% 之间），离底边留 24% 以上避开平台按钮。压在实拍 B-roll 上时用 ASS `BorderStyle=4` + 半透明深色底条（`&HA0000000` 量级），只靠描边在亮底上会看不清。
8. 切句按词表装句，不按字数硬切：把词级字符先拼成 token（jieba + 自定义词典补人名与行业词，如 买手店、面料工作室、工贸一体），再按 token 装满一行；硬切字数会把「买手店」裂成两句。尾部落单不足 1 秒的 cue 合并进相邻句，不留孤字。
9. 烧完必须验字幕，不要只看 ASS：先扫字幕带亮行确认文字只在安全区内，再用 `tesseract <frame> - -l chi_sim` 在片头后、中段、结尾各 OCR 一张，比对文案；OCR 认出的错字多为字形误读，整行为空才是真问题（被亮底吃掉或位置偏了）。
10. 问答型访谈可只保留约 1.5 秒提问卡文字、不放提问人声：两分钟片里能省近 30 秒，节奏也更紧。
11. 客户给的词义与素材行业对不上时（例：面料访谈里解释成模切/专色印刷），先按音频和行业写，并在回复里点明这处矛盾请其确认；不要为了照抄而让字幕自相矛盾。

完成标准：任取片中三处，字幕出现时刻与说出该字时刻对齐；全片字幕基线一致；连续听 30 秒无语气词和长停顿。

片头若有人物/地域标签（如「宜兴 · 中国陶都 · 面料智造」），直接压在地标画面上跟着画面走，不另起一张纯字卡。

## 4. 交付

1. 出审片版：缩到 720×1280、CRF 29 左右，控制在一二十 MB，便于群里直接预览；母版保留原分辨率。
2. 只发完整成片一次，不拆分镜、不发零散片段。
3. 回复里写清这版改了什么，以及下一刀准备砍哪一段、能省多少秒，方便用户一次决定。

## 5. 外语配音版（日语等）：逐段合成，画面给配音让位

用户会连续提「语速忽快忽慢」「上一句没说完下一句就上来」「配音停了嘴还在动」——这三类都是同一根因：整段合成后按静音切分。改用下面的顺序：

1. **逐段合成**，一段一问一答，不要整段录完再切。整段切分必然切在句子中间，造成重叠。
2. 某些公司名会让合成接口直接拒稿（返回无内容）：先用假名读法替换公司名重试（如 百聯紡織 → ヒャクレン紡織），再不行就改写句子，并把兜底文本也记下来。
3. 每段配音规整到 5–7 字/秒；偏离超过 0.5 字/秒用 atempo 拉回（不超过 1.2 倍）。
4. 画面长度 = 前置 0.12s + 配音长度 + 尾 0.18s。原素材不够就在该段句尾的空白里延长（最多 1.6s，且不得越过下一段起点）；仍不够才把配音压到 1.3 倍以内。
5. 出片前自检每段：`end_gap = 段长 - (前置+配音) ≥ 0.02s`（保证配音不压到下一段），且各段语速极差 ≤1.5 字/秒。不达标的段落单独返工，不整片重来。
6. 结尾加 1.8 秒片尾：米白/品牌底色 + 官方 logo 居中 + 公司名，BGM 延续并淡出；不要用空的色块板凑版式。

完成标准：任取两个段边界，后一段开头不会抢在前一段尾音之前；每段最后一句说完，画面才切走。
