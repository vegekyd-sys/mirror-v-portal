# 社媒资料与案例检索

## 1. 判断资料需要什么来源

在用户要找资料、案例、竞品、口碑、经验、教程、爆款或参考时判断来源价值；用户不必说 Apify、API 或平台名。
- 明确指定小红书 / XHS / Rednote、TikTok / TT、抖音、视频号、Instagram / Reels、B 站，按指定平台检索。
- 未指定平台，但需要真实使用经验、消费口碑、生活方式、图文视觉案例，优先考虑小红书；海外短视频表达、创作者案例、竞品视频，优先考虑 TikTok / Instagram；中文视频教程考虑抖音 / B 站 / 视频号。按受众和信息类型选 1–2 个有价值的平台，不把全部平台一律跑一遍。
- 官方 API、定价、法规、论文、严肃事实核验优先官方或权威资料；社媒只是使用经验或案例补充，不作为唯一事实依据。
- 纯生成、用户已给齐素材且不需要外部参考、只总结现有文件、内部 Scene 素材检索不触发此技能。通用网页图片检索交给 image-search-apify-first。
完成判据：能解释所选来源如何回答用户的问题；不因为用户没提工具名而跳过社媒，也不因“资料”二字盲目开爬。

## 2. 读取唯一执行规则，选择已有能力

执行前读 [Apify runtime](references/apify-runtime.md)，获得凭据隔离、Actor 清单、费用/时间边界和故障处置。
- TikTok：`node scripts/apify-search.mjs tiktok "<query>" --limit 3 --json --state <task-dir>/tiktok-state.json`
- 小红书：`node scripts/apify-search.mjs xhs "<query>" --limit 3 --json --state <task-dir>/xhs-state.json`
- 趋势查询：`node scripts/apify-search.mjs trends "<query>" --limit 1 --json --state <task-dir>/trends-state.json`。`trends --daily --geo US` 兼容入口使用 Google 官方实时趋势 RSS，不是历史每日榜单；默认地区 US，按需求显式指定。
- 抖音、视频号账号名发现 / 单链接 / 解密、B 站下载以及 Instagram：按 [平台工作流](references/platform-workflows.md) 对应章节执行；首次使用先用当前 build schema 核对参数。
已有 CLI 是兼容入口；共享客户端 scripts/apify-client.mjs 是 API 执行底座。没有适合 Actor 或遇到明确覆盖缺口，再选择 browser / 已有平台脚本；B 站不使用已知失败的 yt-dlp 路径。
完成判据：输入符合当前 schema，范围符合目标；每个任务有独立状态路径。

## 3. 小样本验证后再扩展

先取 1–3 条元数据：检查内容相关性、作者/标题、真实来源标识、数量和字段质量。空结果是 empty，错误行或缺少来源是失败，不算成功。若关键词过窄，最多先换一个合理同义词；不因失败自动重复收费提交。
需要更多样本时按主题扩展少量关键词，按平台稳定 ID 去重，先相关性后互动量排序；点赞、播放、收藏分别保留，不互相冒充。没有播放量就注明采用互动代理。
需要媒体时才取媒体，按平台工作流及时下载并验证。下载、解密、ASR 和文档归档保持原有能力；批量编码、重型处理不在 Gateway 跑，ASR 使用既有 Volcano 路径。
完成判据：样本与用户问题相关；下载有实际媒体 QC，而非仅 HTTP 200。

## 4. 控制执行与交付

少量、可预测的 probe 可同步；批量、多关键词、下载/ASR、长等待或持续 polling 交给后台 worker/子会话。父会话说明范围与首个检查点，执行会话回传 run ID、终态、样本数、失败项和安全产物；未经委派不自行发群消息。清理短效原始媒体链接，记录取消/超时及交付失败。
正常小样本使用执行层默认费用/时间上限；超出小样本、扩大费用或跨账号时先对齐范围。用户只要检索时不替他发布、评论、发私信；不使用私人内容/凭据绕开权限。
向用户给出实际结果、公共来源链接、平台/关键词/检索时间和覆盖限制。多个来源交叉核验事实，社媒样本不代表总体；Actor 成功也不代表结果完整。
完成判据：能追溯 run 与样本；未完成、稀疏、限额中断和下载失败明确区分。

## 自然语言路由例

- “小红书上找几个收纳案例” → 小红书，无需说 Apify。
- “帮我找空气炸锅真实使用体验” → 按人群选小红书作口碑样本，可补官方参数。
- “看看海外 AI 工具短视频怎么拍” → TikTok / Instagram 案例。
- “查 OpenAI 官方 API 价格” → 官方资料，不爬社媒。
- “用我这张图生成海报” → 生产技能，不自动爬取。
