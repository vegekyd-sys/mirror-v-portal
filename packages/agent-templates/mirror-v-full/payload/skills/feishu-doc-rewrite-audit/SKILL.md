# 飞书文档重排后的一致性审查

用于：把在线飞书文档整体重排、合并章节、覆盖重建，或用户说「检查一下有没有差池」。

## 1. 重建前先取线上正文

覆盖用的底稿必须来自线上，不要用本地旧文件。

```bash
lark-cli docs +fetch --doc <doc_url> --doc-format markdown --as user
```

本地 md 是某一轮的快照，线上可能已经改过；用旧快照 overwrite 会把之后的原位修改全部回滚（实测丢过整列、丢过已删段落、丢过图片）。

## 2. 覆盖后先看目录

```bash
lark-cli docs +fetch --doc <doc_url> --scope outline --max-depth 3 --as user
```

核对两件事：

- 顶级序号连续，没有重号或缺号（一、二、三…）。
- 子编号前缀与父级一致：第 4 节的子节必须是 4.x，第 6 节是 6.x。重排后最常出错的正是这里——标题改了、子编号没跟着改。

## 3. 扫交叉引用

正文里的「第 N 节」「见第 N 条」必须指向真实存在的章节。重排会移动章节，引用不会自动更新；用文本扫描确认每个编号都能对上。

## 4. 补回图片块

overwrite 会删掉已插入的图片。检查 `![` 计数；缺失时重新插入并挪回原位置：

```bash
lark-cli docs +media-insert --doc <doc_url> --file <png> --caption "<说明>" --width 520 --as user
lark-cli docs +update --doc <doc_url> --command block_move_after --block-id <目标段> --src-block-ids <图片块>
```

## 5. 扫已废弃说法

对每个曾被推翻的说法做一次全文计数，例如：具体数量（六款）、错误参数（24 小时运转）、旧代号（TK-E1）、旧配比（产品 50/50）。

判读规则：出现在正文结论里＝错误，要改；出现在「不能写」清单里＝正常，是禁止项本身，不要删。

## 6. 收敛成一份清单

修完只回一份「改了什么、现在干净在哪、还剩哪几件需要确认」，不逐条解释过程。客户可见文档尤其不要留内部归因。
