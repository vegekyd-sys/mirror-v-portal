# 极端产品力演示 · 爆款视频生成 Skill

## 与"荒诞物理流"Skill 的区别

| | 极端产品力 | 荒诞物理流 |
|---|---|---|
| 逻辑 | ✅ 合理，产品真实功能 | ❌ 反常识，但好笑 |
| 视觉 | 产品征服极端环境 | 物理定律崩坏的奇观 |
| 传递 | 直接展示功能 | 前10秒整活→最后3秒软着陆 |
| 例子 | 暴风雪中面料保暖 | 人趴在飞机外假发不散 |

## Trigger
用户给出策划案，要求"用极端产品力/产品性能展示帮 XX 产品出条视频"、"参考面料/风扇那种感觉"。

## 核心公式
🔥 极端钩子 0-3s → 💪 产品制霸 3-9s → 🌪 高潮验证 9-13s → 🎯 品牌收尾 13-15s

## 三条铁律
1. **卖点必须符合逻辑** — 场景极端，但产品功能必须真实。不能出现反物理的用法。
2. **不要多余道具** — 不喝茶、不看手机。只有产品、人物、测试环境。道具抢戏。
3. **前3秒必须有视觉冲击** — 不铺垫、不介绍、不"hey guys"。第一帧就是极端场景中的冲突。

## 策划案 → Prompt 转换
1. 读策划案 → 提取：企业全称、品牌愿景、产品名、核心卖点（3-5个）
2. 设计极端场景 → 基于产品真实卖点，设计"极端但逻辑合理"的环境
3. 套公式生成 prompt → 填入骨架，输出给 Seedance
4. 出片 → 每个产品只抓 1-2 个最强的卖点（15s 塞不下太多信息）

## 模型：仅 Seedance
有实拍产品素材必须走 Seedance 保产品不走样。渲染后用 project media 查成品，API 有缓存延迟等 2-3 分钟重试。

## QC 检查清单（7 项）
1. 卖点是否逻辑合理（不能出现反物理的产品用法）
2. 有无多余道具（茶杯、手机、多余人物）
3. 前3秒是否有视觉冲击
4. 字幕是否单行、下方1/3、不重复
5. 结尾是否有品牌全称 + 愿景
6. 是否只发了 1 条
7. 时长是否 15-20s
