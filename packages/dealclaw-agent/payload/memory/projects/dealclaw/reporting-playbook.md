# Reporting Playbook — Daily Brief / Advisor（skill_improvement 落点）

> 由 reflection `skill_improvement` 晋升（人工审核后落位）。**「Agent 如何表达/分析/排序/执行」的规则**，
> 不属于行业领域知识；发布时随 payload 分发。

- **[客户价值口径]** 客户感知价值 = **数字与 ROI**（今日会谈 / 待跟进 / 收到回复、
  展会漏斗的到场率·商洽率、高匹配买家数），不是叙事性文案。
  - 表达：早晚报先给量化块（今日数据 / 展会战报），再给行动。
  - 排序：Top-N 只放**有商机证据**的客户；把商机**归因到本届展会**。
  - 边界：这是"怎么讲"的规则；行业事实（买家类型/认证/渠道）另见 `industry-knowledge.md`。
  - 源：reflection `skill_improvement`（2026-09-11，从 industry-knowledge 迁出）
