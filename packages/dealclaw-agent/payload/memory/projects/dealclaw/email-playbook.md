# Email Playbook — 展会开发信与买家回复跟进

> **通用打法（跨租户复用，随 payload 分发；分身只读）。**
> 只写方法 / 模板结构 / 适用条件，**不含具体客户、邮箱、真实往来原文**。
> 来源：真实展会获客实战归纳（2026-09 拉美家具展）。**样本量小，属"经验打法"，不是无条件结论** —— 套用前先看适用条件。

---

## 零、通用原则（所有邮件适用）

- **每封邮件都必须有 CTA（行动号召）** —— 明确的下一步动作。没有行动号召的邮件等于没写。
- **但 CTA 不能激进** —— 低门槛、给对方选择权；不催促、不施压、不制造虚假紧迫感。
- 一句话：**邮件里永远有一个"下一步"，但这个下一步要轻到对方愿意接。**

---

## 一、展前开发信（邀约到展位）

**适用**：已拿到目标买家线索（名片 / 到展名单 / 搜索），展前触达，争取回复 + 到展。

**主题行公式**：`品类 + 稳定供应 + 展会名 + 展位号`

**正文顺序（按此排）**：

1. 自我介绍 —— 公司名 + 一句话列全产品线
2. 匹配理由 —— 按买家业务画像点明"为什么联系你"（用它的品类说话，不要泛泛）
3. 展会信息 —— 展会名 + 日期 + 城市 + 展位号
4. 差异化 —— OEM/ODM、自有产线、产能、交期、MOQ 灵活
5. **品类选择题（关键设计）** —— 列 3–5 个品类，让买家"回复勾选"
6. 行动召唤 —— 回复品类 → 我发对应目录 / 报价
7. 附件 —— 电子邀请函

**设计要点**：

- **用买家母语**（西语市场用西语、巴西用葡语），不要用英文。本地化 ≠ 翻译，按当地商务习惯落笔。
- 结尾必须是**低门槛动作**（勾选一个品类），**不要开放式提问** —— 把买家的回复成本压到"选一个词"。
- 品类清单 = 替买家把决策拆分好；**这就是把 CTA 做到最轻的方式**（对方只需回一个词）。
- 全篇仍要有**唯一的、明确的 CTA**：回复品类 → 我发目录/报价。

---

## 二、买家回复后的处理（两步闭环）

**买家一回信 = 热线索，当天处理。**

1. **代回一封给买家**，抄送负责人（老板 / 销售负责人）
2. **再给负责人一封内部说明邮件**（结构见第四节）

**每一步先出草稿给用户确认，确认后才发**（默认口径；用户明确授权直接发时除外）。

**口径必须一致**：给买家说的"谁接待、何时以什么方式联系"，必须与内部说明一致，不能两套说法。

---

## 三、给买家的回复要点

- 买家问 **MOQ / 价格**：**不直接给数字** → 先确认**品类 + 型号**（MOQ 按品类/型号不同），拿到后再报。
- **主动查邮箱，不要反问用户**：买家用哪个邮箱回信，从往来记录里查。
- 介绍负责人并说明角色，**称谓要准确**（用对方语言里对应的词；"老板" ≠ manager）。
- 说明负责人会在展位接待 / 稍后直接联系（WhatsApp 等），口径与内部说明对齐。
- 附**产品目录**，让买家挑意向型号。
- **不反问已明显的信息**（如买家所在市场）。
- **排版**：分段；关键词加粗（MOQ、品类、负责人、行动项）。整段挤成一坨观感差。
- **收件人**覆盖买家所有有效邮箱（发件邮箱 + 签名里的工作邮箱）；签名里的无关第三方邮箱不要加。
- 正式发前，**先发一封测试到自己的邮箱**确认渲染效果。

---

## 四、给负责人的内部说明邮件（固定结构）

**主题**：`国家/地区 + 买家 + 关键信号 + 请对接`

**正文五段（顺序固定）**：

1. **买家底细** —— 公司 / 官网 / 国家 / 联系人 / 职务 / 邮箱 / 电话 / 特征标签
2. **判断** —— 推荐级别 + 理由（对标程度：产品线是否对口、是否目标市场）
3. **回复要点** —— 买家原话要点（可附原文）
4. **建议动作** —— 编号、可执行（加 WhatsApp、带哪些目录、什么时间点）
5. **【已代回复·请知悉】（加粗）** —— 说明已代回复并抄送；建议后续回复**保留我方邮箱**，以便继续协助起草、给要点建议
6. **完整邮件记录** —— 开发信 + 买家回复 + 我方回复（保留原文，便于负责人判断语境）

---

## 五、归档（不允许遗漏）

买家来信、我方回复与转发，**全部原文归档留痕**（含索引清单）。遗漏往来 = 丢掉专业性的底线，不靠提醒，默认执行。

---

## 六、展会时效

- 展前：邀约到展位（第一节）。
- 展中：展位接待，口头沟通为主。
- 展后：**转为线上跟进**（确认品类 → 报价单），**不再发二次邀约**。

---

## 七、这套流程的价值（为什么这样做）

- 买家回复**当天接住**，不拖 —— 热线索不隔夜。
- 负责人通过**抄送 + 说明邮件**被自动拉进跟进链，销售跟单不脱节。
- 每封往来**永久归档**，后续跟进有据可查、不会丢。
- 用户只需在草稿上点头，不用自己写。
