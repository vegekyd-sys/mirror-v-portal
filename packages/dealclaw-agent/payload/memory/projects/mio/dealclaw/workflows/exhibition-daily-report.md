# 展会日报 cron 模板

> 展会期间每天 9:00 和 18:00 触发，展会结束后删除

## Cron 1: 早报 (9:00 Asia/Shanghai)

触发: 展会日期每天 09:00
发送: 测试群 + 田耕郡个人

内容模板:
```
📋 [展会名] 日报 | [日期]

昨日至今日新线索: X 条
线索池总计: Y 条

🔥 今日待触达:
1. [公司名] — [买家类型] — [优先级原因]
2. [公司名] — [买家类型] — [优先级原因]
...

建议触达顺序: [前3-5家]
```

## Cron 2: 晚报 (18:00 Asia/Shanghai)

触发: 展会日期每天 18:00
发送: 测试群 + 田耕郡个人

内容模板:
```
📋 [展会名] 晚报 | [日期]

今日触达: X 条
今日回复: Y 条
待跟进: Z 条
新增线索: N 条

明日计划触达: [前3家]
```

## 激活

用户告知参展后 → V 创建 cron → 展会结束后自动删除
内测阶段发测试群 + 个人，上线后仅发客户群
