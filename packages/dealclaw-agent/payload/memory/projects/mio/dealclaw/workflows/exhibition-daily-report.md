# 展会日报 cron 模板

> 展会期间每天 9:30 / 17:30 触发；最后一天 17:30 出过程总结 + 预告；展会结束后第二天 9:00 出完整复盘报告。展会结束后删除所有 cron。

## Cron 1: 早报 (9:30 Asia/Shanghai)

触发: 展会日期每天 09:30
发送: 测试群 + 田耕郡个人

内容模板:
```
📋 [展会名] 早报 | [日期]

昨日至今日新线索: X 条
线索池总计: Y 条

🔥 今日待触达:
1. [公司名] — [买家类型] — [优先级原因]
2. [公司名] — [买家类型] — [优先级原因]
...

建议触达顺序: [前3-5家]
```

## Cron 2: 晚报 (17:30 Asia/Shanghai)

触发: 展会日期每天 17:30
发送: 测试群 + 田耕郡个人

内容模板:
```
📋 [展会名] 晚报 | [日期]

今日触达: X 条
今日回复: Y 条
待跟进: Z 条
新增线索: N 条

明日计划触达: [前3家]
```

## Cron 3: 最后一天晚报 + 展会过程总结 (展会最后一天 17:30)

触发: 展会最后一天 17:30（与当天晚报合并发送）
发送: 测试群 + 田耕郡个人

内容模板:
```
📋 [展会名] 晚报 | [日期]（展会最后一天）

今日触达: X 条
今日回复: Y 条
待跟进: Z 条
新增线索: N 条

---
📊 [展会名] 展会过程总结 | [展会日期范围]

## 累计数据
- 线索总数: X 条
- 触达总数: Y 条
- 回复总数: Z 条
- 高意向买家: N 家

| 日期 | 新增线索 | 触达 | 回复 |
|------|:---:|:---:|:---:|
| Day 1 | X | Y | Z |
| Day 2 | X | Y | Z |

## 🏆 本届展会亮点
- 最热门产品: [产品名/品类]
- 最活跃市场: [国家/地区]
- 关键洞察: [1-2句话总结]

---

⏰ 明天早晨九点你将收到本次展会的完整复盘报告。
```

> ⚠️ 强制规则：最后一条消息必须以「⏰ 明天早晨九点你将收到本次展会的完整复盘报告。」结尾，不可省略。

## Cron 4: 展后完整复盘报告 (展会结束后第二天 9:00) — 🚧 待定

> ⚠️ 状态：**待定**，暂不落地。飞书六章完整报告的自动生成逻辑先搁置，待后续确认后再实施。

触发: 展会结束后第二天 09:00
发送: 测试群 + 田耕郡个人
飞书文档: 自动创建 + 开编辑权限给田耕郡

📄 完整报告: [飞书文档链接]

## 数据来源映射

| 报告字段 | 数据来源 |
|------|------|
| 展会概况（名称/时间/城市/展位号） | `dc-knowledge-query` 展会库 |
| 主推产品 | 公司画像 + 展会日报高频产品 |
| 录入/有效/重点线索数 | 线索池 `lead-status.md` + 展会期间日报汇总 |
| 意向金额 | 线索池意向金额字段累加 |
| TikTok 数据 | TikTok 账号报告/展会日报 |
| TOP 3 商机 | 线索池评分排序，取 top 3 |
| 线索来源分布 | 线索池 `source` 字段统计 |
| 知识库成长 | 知识库展会前后 diff |
| 亮点/不足 | 线索转化率 + 跟进数据 + 展会日报记录 |
| 下次展会建议 | `dc-knowledge-query` `status=planned` |

## 激活与生命周期

| 阶段 | Cron 1 (早报) | Cron 2 (晚报) | Cron 3 (过程总结) | Cron 4 (完整复盘·待定) |
|------|:---:|:---:|:---:|:---:|
| 展会 D-1 | ✅ 激活 | ✅ 激活 | — | — |
| 展会 D1~D(N-1) | ✅ 运行 | ✅ 运行 | — | — |
| 展会最后一天 | ✅ 运行 | ✅ 运行 + 合并过程总结 | ✅ 触发 | — |
| 结束后第二天 9:00 | — | — | — | 🚧 待定 |
| 复盘报告生成后 | ❌ 删除 | ❌ 删除 | ❌ 删除 | 🚧 待定 |

> 用户告知参展后 → V 创建 3 个 cron（早报 + 晚报 + 过程总结） → 展会结束后自动全部删除。
