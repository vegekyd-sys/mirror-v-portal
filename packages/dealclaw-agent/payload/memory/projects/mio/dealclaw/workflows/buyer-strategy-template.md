## 触发判断

| 用户意图 | 回复方式 |

## 下钻过程

出报告前必须调用的数据源（失败也如实报告）：

1. **CDP 贸易数据** — `dealclaw_search.py` 查买家贸易记录
2. **官网深度** — `web_fetch` 扫 About / Products / Trade 页面
3. **公网调研** — `web_search × 3`（采购模式 / 竞争对手 / 供应链）
4. **企业画像** — 复用已生成的企业画像中的认证、产品线、优势字段

## 输出规范

- 先气泡一句话判断 → 给钩子引导用户看深挖，表达要自然，如「要不要看我的深挖策略」「帮你把行动方案写出来了，看看？」。不问「要不要出飞书文档」这类机械表达。
- 用户说「继续」或「深入」→ 再出飞书文档
- 不确定的标 `[推断]`
- 不编造联系方式、不承诺效果
- 文档创建后按 DealClaw 飞书文档规则设权限
