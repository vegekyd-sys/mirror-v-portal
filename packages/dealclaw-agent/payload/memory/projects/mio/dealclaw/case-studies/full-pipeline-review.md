# DealClaw 端到端流程复盘

> 复盘日期: 2026-07-06 | 从输入企业信息到买家成交的完整链路
> 案例基础: 光华士/NTC、渤程生物、德粘堡、力颖自动化

---

## 核心原则

**用户唯一目标是成单。** 所有步骤服务于这个目标。

企业画像和买家画像是公司级共享的（光华士就是做精铸件的，所有销售共用）。但不同销售有不同偏好——格格只做欧洲真空泵，另一个销售可能做美国涡轮增压器。偏好从对话中获取记录，用于后续筛选和营销。

---

## 流程总览

```
用户提供企业信息（URL/PDF）
  → ① 企业画像（CBIE）
    → ② 市场情报 + 竞争情报（MI）
      → ③ 买家画像定义（CBIE + 用户对话）
        → ④ 买家线索匹配（公网搜索 → CBIE反向背调）
          → ⑤ 邮件/WhatsApp 营销（内容生成 → 发送）
            → ⑥ 线索反馈（✅/❌/📋 → 偏好强化）
              → 成交
```

## ① 用户进入：提供企业信息

### 输入方式

| 方式 | 已验证 | 案例 |
|------|:---:|------|
| 企业官网 URL | ✅ | 光华士、渤程、力颖 |
| 产品目录 PDF | ⚠️ | 德粘堡 DNB E-catalog（图片型PDF仅解析50%） |
| 企业名称 | ⚠️ | 未单独测试，依赖搜索 |
| 用户口述 | ✅ | "我们主要做染色机" → 给URL |

### 当前实现

V 接收 URL → 后台跑 CBIE → 2 句聊天气泡总结 → 完整画像走文档链接。

### 已验证效果

用户丢 URL 后 10 秒内得到摘要。"力颖，2006年成立，做服装洗染设备。研发强，CE有，出口20+国。" → 用户确认"这人懂我的生意"。

### 风险

- 图片型 PDF 解析不全（德粘堡 29 页只出 15 页）
- 官网信息少的公司画像偏薄（如小厂只有单页网站）
- 中文官网不写出口信息 → V 需要追问

## ② 获取市场情报 + 竞争情报

### 市场情报（DC-MI）

输出内容：全球市场规模、中国出口数据、目标区域进口量、增长趋势、行业门槛。

| 案例 | 核心数据 | 用户反馈 |
|------|---------|---------|
| 德粘堡 | BOPP 胶带 $200亿市场，中国出口印尼 3860 万美元 | ✅ 有用 |
| 力颖 | 染色水洗设备东南亚增速最快，Tonello 配件 2-3 周到货 | ✅ 直接打竞品弱点 |

### 竞争情报

V 自动搜索竞品在目标市场的弱点。力颖案例中最关键：Tonello 在孟加拉的售后慢 → 力颖 48 小时配件到 Dhaka → 切入点成型。

### 当前实现

公网搜索 + 海关数据（公开源）。搜索竞品名称 + 目标国 + "distributor/price/after sales"。

### 未实现

- 付费海关数据库（提单级竞品出口数据）
- 竞品在当地的价格/代理/客户情报
- 竞品产品的技术参数对比

## ③ 两张画像 + 两层排除

### 画像分层

| 层级 | 内容 | 存储 | 适用范围 |
|------|------|------|---------|
| 企业画像 | 公司基本信息、产品线、认证、产能、客户 | `profiles/{company}.md` | 全公司所有销售共享 |
| 买家画像（抽象） | 产品可以卖给哪几类买家 | CBIE 输出 | 全公司共享 |
| 销售偏好 | 具体销售只做哪个市场/行业/产品 | `preferences/{uid}.md` | 单个销售 |

### 排除规则两层

**公司级排除**：由企业画像决定，所有销售共用。
- 光华士只做精铸件 → 排除锻件/冲压件客户
- 渤程只出口离心机 → 排除耗材/封膜类客户
- 渤程无 CE/FDA → 排除欧美日（资质硬门槛）

**销售级排除**：由销售偏好决定，每人不同。
- 格格：只做欧洲真空泵 → 排除亚洲/北美客户
- 另一个销售：做美国涡轮壳体 → 排除真空泵客户
- 老板：看全部 → 不排除

### 偏好获取

V 在对话中主动问四件事：卖什么产品？去哪些国家？有认证吗？有不能卖的地区吗？
用户随口说 V 自动提取，确认后存进 `preferences/{uid}.md`。
不搞表单。

### 案例：光华士

```
CBIE: 4 类买家（真空泵/涡轮/排气歧管/高尔夫）
  → 格格: "我只卖给欧洲真空泵生产商"
    → 收缩为 1 类: 欧洲真空泵制造商
      → 三层偏好: Europe / Industrial_Equipment / Investment_Casting
```

### 案例：渤程生物

```
CBIE: 国内药企/CRO/高校/海外经销商
  → 格格: "海外只卖离心机，不能去欧美，俄+东南亚"
    → 收缩为: 俄罗斯/东南亚离心机经销商，排除欧美日
```

## ④ 匹配买家线索（DC-BSM 六维评分）

### 流程

```
企业画像（公司级） + 用户偏好（销售级）
  → 生成"理想买家"客户画像
    → 从数据源获取候选池
      → DC-BSM 六维评分
        → 去重 → 分类 → 排序
          → 输出 Top N 推荐
```

### 六维评分方法论

| 维度 | 权重 | 说明 |
|------|:---:|------|
| 行业匹配度 | 25% | 买家主营业务是否直接使用供应商产品 |
| 采购可能性 | 25% | 是否有采购记录/需求信号 |
| 渠道价值 | 15% | 终端用户 vs 渠道商，覆盖范围 |
| 客单价 | 10% | 预估订单规模 |
| 准入难度 | 15% | 认证要求、竞品锁定、决策周期 |
| 触达可行性 | 10% | 是否有决策人联系方式 |

满分 5.0。≥3.5 推荐追，2.5-3.5 备选，<2.5 放弃。

> DC-BSM Skill 提案已创建: `dc-buyer-scoring-matching-20260706-93ccb82182`

### 案例：光华士（4 条 → 1 条匹配）

| 买家 | 匹配结果 | 原因 |
|------|---------|------|
| PVR Vacuum Design | ✅ 匹配 | 意大利中规模真空泵制造商 |
| VACUUBRAND | ⚠️ 待验证 | 德国实验室真空品牌，可能自产 |
| Pompetravaini | ❌ 排除 | 90年+80国巨头，光华士产能跟不上 |
| VAKUO GmbH | ⚠️ 待验证 | 信息不足 |

### 案例：力颖（3 条）

| 买家 | 优先级 | 策略 |
|------|:---:|------|
| Green Fashion Indonesia | ⭐ 首攻 | GAP/Uniqlo 代工厂，30%价格打进去 |

≤3条：聊天气泡逐条介绍 + 策略建议
\>3条：聊天气泡总结 + 多维表格链接

## ⑥ 线索反馈 → 成交

### 反馈机制

用户在多维表格里改"状态"字段 → 飞书自动化通知 V → V 读表执行下一步。

| 标注 | 动作 |
|------|------|
| ✅ 我的买家 | 加入跟进队列，V 主动出开发信/报价/邀约 |
| ❌ 不是 | 追问原因（产品/市场/规模不对），更新排除规则 |
| 📋 已有 | 加入已有池，不再推荐 |
| 🚫 黑名单 | 永久排除 |

### 从线索到成交的缺口

当前断在"V 出内容 → 用户手动执行"。理想流程是：

```
V 出邮件 → 用户确认 → V 发送 → 追踪打开/回复 → 未回复时提醒跟进 → 已回复时提取下一步 → 推进到报价/样品/合同
```

打开追踪和回复检测需要 Resend webhook（Resend 支持，未配置）。
