## 七、定价原则

1. 客户按业务场景买，不按 Skill 买。对内 CBIE/LS/OS/EL，对外"展会增长""持续获客"。
2. 平台能力与外部成本分离。自然对话不按 Token 收费；联系人/海关数据/邮件/WhatsApp 走 Credits + Wallet。
3. 不按席位惩罚。参考 Smartlead——套餐内含团队，额外用户只收轻量管理费。
4. 早期不承诺固定询盘量。百雀/光年的"按结果付费"模式风险高，先收年费保现金流。
5. 展会客户 60 天内升级获客可抵扣软件部分。同一个 V，同一套企业记忆，自然过渡。
