# 企业宣传片脚本生成 v2.0

> 输入企业材料 + 客户要求 → 行业调研 → 风格决策 → 弹性结构 → 专业分镜脚本
> v2.0 变化：不再假设企业是 TO B 制造厂。新增行业前置调研、风格决策矩阵、弹性结构设计。品类不同，语言不同。

---

## 触发条件

- 用户要求为企业/品牌制作宣传片脚本、企宣片分镜、corporate video script
- 用户提供了企业相关材料（PPT/Word/PDF/图片/文字要求/链接等，形式不限）
- 用户明确给出企宣片要求（时长、基调、受众、结构等）

---

## 工作流程总览

```
收材料 → 行业调研 → 风格决策 → 结构设计 → 出脚本 → 对齐检查 → 定稿
```

关键约束：行业调研和风格决策必须在出脚本之前完成，不可跳过。

---

## 阶段一：前置准备 & 行业调研

### 1.1 收材料

客户给什么就用什么——PPT、Word/PDF、图片、飞书文档链接、聊天文字要求。不限定格式和数量，有多少输入多少。

### 1.2 提取信息

从所有材料中提取公司信息、产品线、产能数据、团队/组织、品牌定位、战略方向、客户渠道、已有视觉素材等。

### 1.3 对齐客户要求

逐项对照客户企宣片要求（时长、基调、受众、结构、红线、禁用项），先列出差距分析。材料中没有覆盖到的要求点，标注"需客户补充"。

### 1.4 行业前置调研

> 目标：建立该品类的视觉/节奏/音乐参考系。不凭经验硬套。

1. **确定行业品类**：从客户材料中提取行业标签（如：工业液压设备 / 儿童益智玩具 / SaaS 软件 / 餐饮连锁 / 新能源等）

2. **搜索同品类参考片**：搜索该品类头部品牌的官方宣传片 / 品牌片，至少 2-3 条有效参考。来源：YouTube/Bilibili 品牌官方频道、行业展会视频、企业官网。优先近 3 年。

3. **拉片摘要**：

   | 维度 | 参考片A | 参考片B | 参考片C |
   |------|---------|---------|---------|
   | 品牌 | | | |
   | 时长 | | | |
   | 主线结构 | | | |
   | 影调/色调 | | | |
   | 节奏 | 快/中/慢 | | |
   | 音乐风格 | | | |
   | 字幕风格 | | | |
   | 旁白风格 | 有/无，风格描述 | | |
   | 突出亮点 | | | |

4. **提取品类信号**：从多条参考片中提取共性（该品类的"默认语言"）和个性（可突破的方向），输出一段总结。

## 阶段二：风格决策矩阵

> 行业品类 × 客户要求 → 确定本片的镜头语言策略

### 决策维度

| 决策维度 | 选项 |
|----------|------|
| **视觉基调** | 制造感/硬朗 → 科技感/冷峻 → 温暖/生活化 → 潮酷/活力 → 奢华/质感 → 清新/自然 |
| **影调倾向** | 低饱和深沉 / 高饱和明快 / 冷暖对比 / 自然光 / 棚拍精致 |
| **节奏** | 慢沉稳（每镜6-8s）/ 中速叙事（每镜4-6s）/ 快节奏（每镜2-4s）/ 混合 |
| **音乐风格** | 工业打击乐 / 电子科技 / 管弦史诗 / 轻快流行 / 氛围环境 / 爵士质感 |
| **旁白策略** | 有旁白（沉稳男声/亲和女声/品牌创始人）/ 无旁白（纯画面+字幕+音乐）/ 混合 |
| **字幕风格** | 数据硬输出 / 情感金句 / 极简关键词 / 无字幕 |
| **画面来源** | 实拍为主 / 素材+实拍混合 / 3D/动画为主 / 纯实拍纪录片风 |

### 品类默认映射（参考，非强制）

| 行业品类 | 默认视觉基调 | 默认节奏 | 默认音乐 | 典型结构偏向 |
|----------|------------|---------|---------|------------|
| 工业/制造/重工 | 制造感/硬朗 | 中速叙事 | 工业打击乐 | 规模→能力→交付 |
| 消费品/快消 | 温暖/生活化/活力 | 快节奏 | 轻快流行 | 场景共鸣→产品→情感 |
| 玩具/母婴 | 温暖/活力/趣味 | 中快 | 轻快+童趣 | 痛点→产品体验→快乐收尾 |
| 科技/SaaS | 科技感/冷峻 | 中速 | 电子科技 | 问题→方案→价值→愿景 |
| 新能源/绿色 | 清新/自然+科技 | 中速 | 管弦+环境 | 使命→技术→影响→未来 |
| 餐饮/食品 | 温暖/质感/烟火气 | 中快 | 轻快/氛围 | 场景→食材/工艺→品牌温度 |
| 时尚/奢侈品 | 奢华/质感 | 慢沉稳 | 氛围/爵士 | 态度→产品→身份认同 |
| 建筑/地产 | 大气/质感 | 慢沉稳 | 管弦史诗 | 空间→生活→价值 |

### 风格决策输出

在开始写脚本前，必须输出一段**风格决策说明**：
- 选定的视觉基调及理由
- 节奏策略及理由
- 音乐风格选择
- 结构策略（沿用默认或自定义分段）
- 与品类默认映射的偏离及理由（如有）

## 阶段三：结构设计（弹性）

> 不再强制四段式。根据品类和客户要求自定义。

### 结构设计原则

**先确定叙事主线**——这条片子到底讲什么故事：

- **制造企业**：从能力到信任（"我们是谁 → 我们能做什么 → 为什么选择我们"）
- **消费品**：从痛点到解决（"你有这个问题 → 我们的产品解决它 → 用了之后的生活"）
- **科技公司**：从问题到未来（"世界有这个问题 → 我们的方案 → 带来的改变"）
- **品牌片**：从价值观到共鸣（"我们相信什么 → 我们做了什么 → 邀请你加入"）

**确定分段和比例**：根据主线分配段落，每段有明确功能。

### 默认结构：TO B 制造企业（v1.0 保留）

| 段 | 比例 | 功能 |
|----|------|------|
| 01 开篇：势能 | ~20% | 大场景冲击，大景别工厂航拍/机械阵列 |
| 02 规模：制造 | ~30% | 双基地/产线/数据硬输出。产能数字、物流、全球布局 |
| 03 专业：能力 | ~30% | OEM/ODM、设计研发、多国团队、资质认证、全球渠道、交付闭环 |
| 04 收尾：团队 | ~20% | 多国团队合影→品牌落版→Slogan |

### 示例：消费品结构

| 段 | 比例 | 功能 |
|----|------|------|
| 01 痛点/场景引入 | ~15% | 生活场景，消费者使用前的问题 |
| 02 产品亮相 | ~20% | 产品特写、设计、功能展示 |
| 03 使用体验 | ~35% | 使用场景、效果展示、细节体验 |
| 04 品牌价值 & CTA | ~30% | 品牌态度、金句、Slogan 收尾 |

### 时长控制

- 3 分钟以内为目标
- 每镜时长依风格决策：慢节奏 6-8s，中速 4-6s，快节奏 2-4s
- 开篇留白 10-15s 建立氛围，结尾黑屏 3-5s
- 总镜数 25-35 镜浮动，不强制 30 镜

## 阶段四：出脚本

### 脚本输出格式

使用 10 列分镜表格：

| 镜号 | 时间 | 景别与运镜 | 画面内容描述 | 画面字幕（英文） | 中文字幕对照（内部参考） | 英文旁白 | 中文旁白 | 音乐与音效 |

### 各列填写规范

**镜号**：`段号-镜号`，如 `1-3`、`3-5`

**时间**：每镜精确到秒，如 `0:10–0:15`。全片时长控制在客户要求范围内，每段分配合理时长。结尾留 3-5s 黑屏余韵。

**景别与运镜**：远景/全景/中景/近景/特写 + 航拍/推/拉/摇/跟/升/固定/手持/斯坦尼康。每镜必须有明确的景别和运镜方式，相邻镜头要有变化避免单调。根据风格决策选择运镜偏好（如消费品多用斯坦尼康跟拍生活场景，工业品多用航拍+推轨）。

**画面内容描述**：具体描述画面核心元素和动作，注明素材来源（来自哪个文档/图片/客户提供/需版权素材/需拍摄）。

**画面字幕（英文）**：成片打出的画面叠加文字。仅英文。风格依风格决策而定：
- 工业品：数据大字金色 #D4A843 加粗 + 白色副标，底部暗底保护条；地名标签白色左下/右下 fade-in+上浮；关键词白色闪现；金句金色居中 scale-in
- 消费品/生活：暖白圆体；浅色半透明底标签；品牌色居中弹入
- 科技：冷白细体；极简线条标签；冷白 typewriter
- 无画面字幕的镜头留 `—`

**中文字幕对照**：画面字幕的中文翻译，仅内部参考，不出现在成片中。

**英文旁白**：配音员读的完整英文句子。短句、句号分隔、有力量感。无旁白留 `—`。旁白风格依风格决策而定。

**中文旁白**：英文旁白的中文对照。同样短句有力。无旁白留 `—`。

**音乐与音效**：每镜配乐/音效变化。音乐风格严格遵循风格决策矩阵的选型。音效环境声与品类匹配（消费品：生活音效、翻阅声、笑声；工业品：金属、锤击、机械运转；避免弦乐煽情/钢琴/民谣除非风格决策明确要求）。

### 画面字幕视觉规范（按风格分流）

| 风格类型 | 数据/大字 | 标签/地名 | 金句/Slogan | 字体偏好 |
|----------|----------|----------|------------|---------|
| 工业/制造 | 金色 #D4A843 粗体 | 白色+外描边 | 金色居中 scale-in | DIN Pro Bold |
| 消费品/生活 | 暖白 #FFF8E7 圆体 | 浅色半透明底 | 品牌色居中弹入 | 圆体/无衬线 |
| 科技/SaaS | 冷白 #E8F0FF 细体 | 极简线条标签 | 冷白 typewriter | Inter/SF Pro |
| 时尚/奢侈 | 金色细体 | 衬线体小号 | 衬线 fade-in | Didot/Playfair |
| 新能源/绿色 | 绿色 #4CAF50 | 自然色标签 | 绿色呼吸动画 | 无衬线简洁 |

> 画面字幕仅打英文。字号和动画参数由后期设计，脚本中只描述风格和位置。旁白字幕底部居中白色+深色外描边。

### 内置参考（v1.0 保留）

参考拉片：**安基橡胶企业宣传片 23 镜拆解分析**。结构、节奏、镜头语言已内化为本 Skill 的默认范式。当行业品类为工业/制造时，该参考作为风格基线。其他品类以行业调研的参考片为基线。

## 阶段五：客户要求对齐检查

完成后逐项对照：

| 检查项 |
|--------|
| 行业调研是否完成且纳入风格决策 |
| 风格决策是否与品类匹配且有明确理由 |
| 时长是否在规定范围内 |
| 基调是否正确 |
| 受众正确（TO B / TO C / 混合） |
| 结构是否贴合品类而非机械套用模板 |
| 音乐/字幕/运镜风格是否与风格决策一致 |
| 客户红线（禁用 AI/采访/特定内容） |
| 片尾落版形式 |

## 迭代流程

1. **行业调研**：先出调研摘要 + 拉片表，客户确认方向
2. **风格决策**：出风格决策说明，客户确认
3. **初稿**：基于确认的方向出完整分镜脚本 + 字幕规范
4. **对齐检查**：逐项对照客户要求，有偏差立即修正
5. **根据反馈迭代**：格式/内容/细节调整
6. **定稿**：写入飞书文档，互联网可读 + 需求方可编辑
