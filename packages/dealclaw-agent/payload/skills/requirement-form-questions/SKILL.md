# 需求表提问库 Skill

## 定位

在 CSM + 运营 + 客户的需求对齐会上，从视频内容制作视角输出一套提问清单。聚焦内容可落地性，不涉及拍摄现场细节（灯光/噪音/时间等由运营自行确认）。

## 触发条件

用户发送客户需求表，要求输出「提问库」「问题清单」「会上要问的问题」「对齐问题」。

## 输入

客户填写的 VIP 需求确认表（docx 文件）。

## 输出

一套中文提问清单，按四大类分组，每类约 3-5 个问题。每问一句话，开放式为主，禁止是非题。

---

## 四大类提问框架

### 一、画面能拍什么

目标：确认选题库里的内容方向有没有画面素材支撑，避免写了脚本发现根本拍不了。

方向：
- 客户提到的行业案例/标杆客户能不能在视频中提及？能到什么程度（行业名/客户名/项目细节）？
- 核心方案/系统（如 CAPP、MES、数字孪生等）的软件界面能不能录屏？有没有敏感数据需脱敏？
- 核心产品的演示拍摄——有真实工件/真实场景可以上机演示，还是只能用标准样件/模拟场景？
- 如果有"改造前后对比"的叙事，有没有真实的改造前后画面可用？还是只能靠动画/图表？
- 客户提到的"极端测试""暴力测试"——有没有实际做过可以复现？需要提前准备什么条件？

> 所有问题必须基于需求表的具体产品/方案/工艺来定制，不能用泛化模板文字。

### 二、账号方向

目标：搞清楚买家是谁、竞品是谁、品牌有什么调性约束。

方向：
- 各市场买家画像能不能更具体：工厂主还是采购经理？CEO 还是技术负责人？不同人看到的视频深度应该不同
- 有没有参考的竞品或行业标杆账号/TikTok 主页？不一定是直接竞对，同行业的也行
- 品牌调性上除了需求表写的关键词，有没有"绝对不能出现的画面/话术/风格"？
- 各市场对同一产品的关注点有什么区别？（基于需求表的具体市场和产品来问）

### 三、素材资产

目标：确认有没有现成素材可用，早拿到就早开工。

方向：
- 有没有手机拍的工厂/产线/产品片段？哪怕质量一般也可混剪
- 有没有已经积累的客户好评、合作反馈或验收报告可以出镜？
- Logo/产品图/认证证书等能不能先发电子版？
- 有没有企业宣传片/产品手册/技术白皮书等可作为脚本参考的物料？

### 四、竞争叙事

目标：搞清楚客户自己怎么说服买家，这些话就是转化类视频的核心脚本。

方向：
- 客户被问到"你跟大品牌比凭什么选你"时，销售团队最常用的三句话是什么？
- 有没有实际成交案例的对比数据？比如"引入方案后设备利用率从 X% 提到 Y%""废品率下降 Z%"，这些数字是转化内容最有力的素材
- 买家最大的顾虑是什么（除了需求表上写的），销售团队一般在哪个环节丢单最多？

## 输出格式

群里直接回复，结构如下：

```
按需求表内容整理了会上要问客户的问题，四类：

一、画面能拍什么
1. xxx？
2. xxx？
...

二、账号方向
1. xxx？
2. xxx？
...

三、素材资产
1. xxx？
2. xxx？
...

四、竞争叙事
1. xxx？
2. xxx？
...
```

最后加一句：「全部问题基于需求表内容定制，不含拍摄现场细节（灯光/噪音/禁拍区域等，由运营现场确认）。」

---

## 编辑原则

- 所有问题必须基于需求表的具体产品/方案/工艺/市场来写，不能用泛化模板
- 每问一句话，开放式为主，禁止「是不是」「有没有」式的是非题（除非该问题本身就是确认一件明确的事）
- 不涉及拍摄现场细节：灯光、噪音、产线运行时间、穿戴防护、架机位等。由运营自行确认
- 每类控制在 3-5 问，总问题数 12-18 个
- 需求表缺失字段（如竞争对手、对标账号），优先问客户
