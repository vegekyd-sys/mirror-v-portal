# 优质内容复盘分析 (Video Review Analysis)

> 完整的"素材获取 → 视频理解 → 结构化复盘 → 飞书输出"工作流。

## 触发条件

用户要求对一批 TikTok/社媒优质视频做复盘分析，典型信号：
- "帮我分析下这些视频为什么数据好"
- "做个优质视频复盘"
- "参考骏业/圣岳的复盘模板，帮XX客户也出一份"
- 用户上传了视频素材或视频链接 + 要求分析

## 输入要求

开始前必须确认：
1. **视频来源**：飞书表格附件 / FCloud后台下载 / 直接发送的视频文件 / 视频URL
2. **客户身份**：企业名、目标市场、语言、品类
3. **分析数量**：通常 5-7 条优质视频
4. **已有参考**：如果用户给了已有的复盘模板，必须参考其分析结构和口径

## 执行流程

### Step 1：获取视频

根据来源类型：
- **飞书表格**：从多维表中提取视频附件并下载到本地
- **FCloud后台**：通过API拉取TikTok账号作品列表，按播放/互动数据取Top N
- **直接发送**：从飞书消息中下载视频附件
- **URL**：使用yt-dlp或直接下载

下载到 `work/<客户名>-review/` 目录，记录文件名映射。

### Step 2：视频理解

对每条视频做两步分析：

**Vision（画面分析）**：
- 抽帧分析：产品、场景、人物、设备、文字/字幕、品牌露出
- 画面信息密度判断（高/中/低）
- 剪辑节奏判断（快剪/慢推/卡点/ASMR等）
- 镜头序列推演

**ASR（语音/字幕分析）**：
- 提取口播内容
- 识别语言和市场
- 提取关键词、钩子话术、CTA话术
- 无声或不可识别要标记，不硬写

### Step 3：结构化复盘

每条视频按以下模板拆解，输出到飞书多维表：

| 字段 | 说明 |
|------|------|
| 序号 | 视频编号 |
| 截图 | 视频关键帧截图 |
| 视频文件 | 文件名 |
| 优质分析 | 4条核心分析点，覆盖：钩子有效性、内容结构、B2B信任链、转化动作、短板/改进建议 |
| 内容核心 | 根据视频实际内容自动归类，如"全流程产线证明型""展会咨询转化型""材料实测证明型"等，不限定固定分类数量 |
| 复用公式 | 结构化模板：`{钩子类型} + {画面序列} + {CTA类型}` |

**优质分析 4 条编写规范**：
1. **第1条**：钩子分析 — 前2秒用什么抓住买家？为什么有效？
2. **第2条**：内容结构/视觉证据链 — 画面如何推进？建立了什么信任？
3. **第3条**：差异化优势 — 这条视频跟同类比强在哪？
4. **第4条**：改进空间或执行建议 — 短板是什么？下次怎么强化？

**内容核心归类原则**：
- 根据每条视频的实际内容特征自动归纳类型名
- 标签要能一眼看出视频的核心策略（如"全流程产线证明型""展会咨询转化型"等）
- 不拘泥于固定分类列表，每条视频的内容核心应贴合该视频的实际策略
- 如果多条视频属于同一类型，使用一致的命名

### Step 4：总体结论

跨视频提炼 3-5 条共性成功因素：
- 钩子规律
- 画面类型规律
- 信任构建规律
- CTA 规律
- 语言/市场适配规律

### Step 5：执行建议

给出 3-5 条下一步内容方向建议：
- 优先做什么类型的视频
- 每个类型对应的钩子话术（客户语言）
- 需要补的素材类型

### Step 6：输出到飞书

创建飞书多维表，字段结构：
- 序号、截图、视频附件/文件名、优质分析、内容核心、复用公式
- 底部追加：总体结论 + 后续执行方向

同时可选择性输出飞书文档版本（用于客户交付）。

## 已有案例参考

以下为已完成的复盘案例，可作为分析口径参考：

**骏业**（工业锯片/CNC磨齿机）：7条视频，提炼出6个内容公式，核心规律包括前2秒制造冲突/损失感、高频工业画面替代长篇讲解、每条视频完成B2B信任链闭环。

**圣岳**（橡塑科技/铝挤压）：6条视频，提炼出全流程产线证明型、展会咨询转化型、材料实测证明型、自动化工厂实力型、展会强CTA转化型等类型，核心规律包括开头给采购理由而非公司介绍、画面以工业证据链为核心。

## 质量红线

- ❌ 不允许只根据标题、封面或播放量写结论
- ❌ 不允许只评论"这条视频不错"而不说明具体原因
- ❌ 不允许跳过 vision + ASR 直接写分析
- ❌ 分析必须输出到飞书表格/文档，不在群聊里堆文字
- ✅ 每条视频至少覆盖：钩子、结构、卖点、可复刻动作、风险
- ✅ 结论要能指导下一批视频的拍摄/生成
