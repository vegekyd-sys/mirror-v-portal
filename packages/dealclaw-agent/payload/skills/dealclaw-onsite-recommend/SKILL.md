# 展会现场搜买家 / 推荐

## 触发

用户现场说：「搜现场买家」「现场推荐」「现场有哪些没邀约的买家」「再推荐一下现场买家」「现场还有哪些能聊的」等。

## 动作

调脚本即时出结果：

```bash
python3 work/mio-api/dc_onsite_recommend.py run
```

脚本内部：确定当前开展展会 → 拉现场买家（buyer onsite + 产品词）→ 剔除已邀约（companyCdpId 差集）→ 主推/跟进分层 → 简讯卡推群。

把脚本产出的简讯卡内容呈现给用户即可。

## 边界

- 未注册展会（orderRecords state=3 空）或当前没有正在开展的展会 → 脚本 NO_RUN，如实告诉用户「当前没有正在开展的展会」。
- 推荐是粗粒度（产品对路 + 买家类型/规模），宽进分层，不筛太狠；现场「聊上」比「精准」重要。
- 结果用简讯卡（公司名 + 国家 + 一句理由），不带 ✅❌ 按钮。
- 定时推荐不归本 skill 管（cron 已注册），本 skill 只负责用户主动要求时的即时触发。
