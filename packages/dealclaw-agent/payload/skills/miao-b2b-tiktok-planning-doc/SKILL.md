## 🔴 强制规则 6 条

### 1. 人员出镜规则

| 允许 ✅ | 禁止 ❌ |
|---------|---------|
| **AI 数字人出镜讲解** | 真人出镜口播、对镜头讲解 |
| 产线工人自然操作设备 | 真人面部特写 |

### 2. 脚本语言规则

- 每条选题配**书面语+口语**混合脚本，口语为主（约6:4）
- 必须带当地语言语气词、缩写、日常表达

### 3. Hook 规则

- 每条选题必须有**前3秒Hook设计**（画面+字幕/音效）

### 4. TikTok 同行案例规则

- 🔴 **必须环节** — 搜索近半年TikTok同行高播放视频
- 至少4条（娱乐型2条+工厂型2条），带账号名+播放量+可点击链接
- 📍 **必放位置：§3 内容矩阵之后、§4 服务周期之前**

### 5. §4 内容要求

**内容触达逻辑**（必有小节）：
1. 持续露出：月均100条本地语言视频，稳定出现在目标市场信息流
2. 数据观察：通过后台数据观察哪些方向获得更好关注
3. 方向优化：根据数据反馈向高效方向倾斜
4. 品牌积累：从"被刷到"到"被记住"再到"被搜索"

**禁用词**：❌ 互动 / 询盘 / WhatsApp / 成交 / 意向客户 / 线索
**替代表达**：✅ 数据观察 / 持续优化 / 内容匹配度

### 6. §5 Q1 内容方向（4方向，删买家FAQ）

| 方向 | Hook | 内容 |
|------|------|------|
| 1 工厂实力 | 千分表归零特写 | 自动化产线/精度测试 |
| 2 产品矩阵 | 品类蒙太奇闪切 | 品类宽度展示 |
| 3 质量可视化 | 钥匙刮板特写 | PET耐磨/耐用测试 |
| 4 定制交付 | 手绘草图→CAD | 非标全流程 |
