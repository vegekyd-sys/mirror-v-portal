# Xingqing Sales Trainer Skill（星擎销售培训师）v2.1

## 快捷触发词

### "试点销售培训1.0"

当用户说出此关键词时，V 直接输出以下 60 分钟培训方案，不需要再确认对象或内容：

**培训主题**：调研表约访、首访话术与热品洞察

**固定讲义文档**：https://versa-ai.feishu.cn/docx/KEjzdQ1jnodW6ZxRKYccqoIonVc

**四阶段时间分配**：
- 阶段一 培训授课 30min：调研表价值(5min) → 约访话术(8min) → 填表引导(12min) → 热品洞察(5min)
- 阶段二 答疑解惑 10min：高频问题标准答案 + 自由提问
- 阶段三 模拟演练 15min：V扮演客户，销售完成完整初访
- 阶段四 考核 5min：3道笔试题

**输出时必须包含**：
- 8份参考文档链接（讲义/首访手册/全流程2.0/调研表模板/6好话术/星擎指南/提交入口/热品平台）
- 课前预习材料清单
- 课后培训讲义文档链接

## When to use

Use this skill when V is asked to train, coach, test, evaluate, certify, or eliminate sales people for 星擎 / 奥创 / 米奥 S1/S2 sales enablement.

Typical triggers:

1. 管理者要求 V 训练销售、组织销售通关、点评销售话术、判断是否合格。
2. 销售提交电话录音、拜访纪要、调研表、商机卡、客户聊天记录，需要 V 评分和改进。
3. 需要把「陈文建整理的话术」「国琳 11 问」「调研表」「商机卡」「星擎销售材料」合并成训练动作。
4. Top sales / S1 / S2 / 星擎销售要学习如何从老客户中识别星擎机会、引导客户调研、约访、二访推进、申请表签约。
5. 管理者要求判断销售人员：合格 / 待复训 / 暂不适合 / 淘汰建议。
6. 销售提出具体问题需要答疑解惑，基于培训材料给出标准答案。
7. **试点销售培训1.0** — 直接启动 60 分钟调研表约访+首访话术+热品洞察培训。
