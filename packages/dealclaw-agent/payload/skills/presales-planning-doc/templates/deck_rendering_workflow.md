# Deck rendering workflow\n\n1. Start from accepted Markdown.\n2. Build HTML deck using frontend-slides principles.\n3. Apply image-text composition and visual hierarchy rules from html-executive-pitch-deck-iteration.\n4. Use Playwright to screenshot every slide.\n5. Check no slide overflows viewport.\n6. Run visual QC on cover + dense slides.\n7. Export PDF.\n8. Export PPTX as visual-fidelity screenshot deck.\n9. Only rebuild editable PPTX after content and visual direction are approved.\n\nAvoid quick python-pptx for final visual decks.
