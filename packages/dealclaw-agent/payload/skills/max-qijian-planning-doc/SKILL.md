# Max 旗舰版 AI 短视频策划案 全流程

> 基于 VIP 客户需求确认表，输出 12 章全球市场 AI 短视频策划案 Pro 版飞书文档，覆盖 12 个月服务周期。

## 触发条件

- "给 XX 客户做 Max 旗舰版策划案"
- "基于需求表输出 XX 客户 AI 短视频策划案"
- 群内收到 VIP 客户需求确认表文件

## 输入要求

1. **VIP 客户需求确认表**（.docx 文件，群内或本地）
2. **客户参考素材**（如有）：Logo、产品图、工厂图、认证证书、参考账号链接等
3. **参考模板**：已有的同级别客户策划案（如骏业/伊科凡/戴诺维），用于对标结构

## 执行流程

### Step 1：档案建立

提取需求表关键信息，建立企业档案：
- 基础信息：中英文名、行业、地址、联系人
- 产品/工艺：主推品类、核心卖点、认证背书
- 目标市场：区域、语种、买家类型
- 交付包：账号数、视频数、询盘目标、服务周期
- 素材资产：已有素材 + 待补充素材
- 拍摄条件：产线时间、光线、禁拍区域

### Step 2：联网市场调研

对每个目标市场做数据调研（不编造数据，标注来源）：
- 市场规模 & 增长率（Grand View / IMARC / OEC 等）
- 买家画像 & 核心痛点（按国家差异化）
- 关税/物流/合规注意事项
- TikTok B2B 纺织/工业品内容趋势 & 对标分析

### Step 3：文档结构（12 章）

飞书文档标题：`XX企业英文名｜全球市场 AI 短视频策划案 Pro 版`

| 章 | 内容 |
|---|---|
| 1 | 项目背景（企业信息+核心优势+项目内容+挑战+破局思路） |
| 2 | 项目内容规划（Q1-Q4 年度策略总览+三次拍摄轮次，不含2.3 各季度一句话策略） |
| 3 | 海外买家画像（核心买家类型+最担心问题+分市场痛点+洞察→内容策略转化表） |
| 4 | 行业洞察与 TikTok 机会（全球市场数据+内容趋势+对标分析+爆款公式提炼） |
| 5 | AI 混剪视频内容策划（5 个方向 × 各 3-5 条选题 = 25 条，每方向末尾附内容目标） |
| 6 | Q2 内容方向（放大期·3 个方向） |
| 7 | Q3 内容方向（深耕期·3 个方向） |
| 8 | Q4 内容方向（冲刺期·3 个方向） |
| 9 | **矩阵账号规划**（国家/语种总览表 → 三层漏斗分层 → 官号 → 分发策略 → 命名与主页） |
| 10 | 拍摄清单（P0/P1/P2 优先级+画面内容+用途+拍摄建议） |
| 11 | 流量&分发策略（Hashtags+分发策略） |
| 12 | 不确定信息与需客户确认项 |

### Step 4：Q1 内容策划（第 5 节核心）

5 个方向、25 条选题的结构：
1. **工厂实力与一体化生产** — 建立"自有工厂+全流程自控"信任
2. **面料/产品质感与品类矩阵** — 展示品类宽度，触发采购冲动
3. **破坏式质量测试** — 用物理测试将品质可视化，消除买家顾虑
4. **工艺前后对比** — 展示工艺附加价值，支撑溢价
5. **从询盘到出货** — 展示 B2B 服务链路，引导下单动作

每个方向包含：目的说明（callout）+ N 条具体选题（H3+bullet）+ 末尾内容目标（blockquote）

### Step 5：矩阵账号规划（第 9 节）⭐

**9.1 账号矩阵总览** — 先列一张国家/语种/账号分配总表（表格），一目了然：
- 行：市场（巴西、墨西哥、哥伦比亚、全球英语、官号、YT分发）
- 列：语种 | 引流+内容号 | 信任+转化号 | 英语综合号 | 小计

**9.2 账号分层与职能** — 三层漏斗：

| 层级 | 职责 | 内容特征 |
|---|---|---|
| **层级一：引流+内容号** | 拉播放、涨精准粉、建立品类认知 | 工厂壮观画面、产品解压变形、极端测试；纯画面输出，不挂联系方式；为信任号导流 |
| **层级二：信任+转化号** | 建立信任、承接询盘 | 认证/工厂验证、质量对比、买家 FAQ、报价指引；引导评论区留言/私信询盘；主转化号 |
| **层级三：英语综合号** | 英语采购补充、国际采购承接 | 共用英语素材池，差异化封面/Hashtag；覆盖全产品线；辅助转化 |

账号编号：客户缩写 + 市场代码 + 层级编号，如 ZC-BR1、ZC-BR2、ZC-BR3

**9.3 官号**（2 个）：品牌形象号 + 企业 IP 号

**9.4 YT 分发号**（1 个）：TK 英语素材同步分发，补充曝光渠道，不做长视频，不独立承担转化

**9.5 内容分发策略**：素材复用机制（一轮拍摄→按语种/品类匹配到对应号→本地化字幕/标签/CTA），官号与矩阵号联动（爆款→官号深度重制；官号新品→矩阵号拆成多条 AI 混剪）

**9.6 账号命名与主页设置**：命名规范、主页 Bio 统一格式、头像、链接指向

⚠️ **参考截图的结构和逻辑，但不要照搬内容**——行业、品类、市场分配、账号编号都要根据客户实际情况定制。

### Step 6：Q2-Q4 内容方向

**Q2（放大期·4-6 月）：** 客户案例+应用场景+深度工艺
**Q3（深耕期·7-9 月）：** 客户回访+产能升级+旺季备战+行业趋势
**Q4（冲刺期·10-12 月）：** 爆款面料合集+标杆客户案例+新品预热与预售

⚠️ **Q4 是服务期内的冲刺阶段，不是复盘结项。** 不要做年度总结/回顾/数据可视化。

### Step 7：拍摄清单

按 P0（必拍）/ P1（重要）/ P2（补充）三级优先级列出，每项含画面内容、用途、拍摄建议。

### Step 8：待确认项

从需求表中提取所有未填写或不明确的信息，逐条列出 + 建议处理方式。

### Step 9：迭代修改

使用 `lark-cli docs +update --command str_replace` 做定点替换。
**不要用 `--command overwrite --doc-format markdown` 覆盖 HTML/XML 格式文档**（会内容丢失且格式损坏）。
正确覆盖方式：
```bash
cat content.html | lark-cli docs +update --doc <token> --command overwrite --content - --as user --doc-format xml
```

## Verification Gate（生成后必检）

文档生成后，执行以下验证：

1. `lark-cli docs +fetch --scope outline` → 验证 12 章结构完整
2. 确认关键表格（账号矩阵总览、拍摄清单、待确认项）完整无截断
3. 全文搜索 "复盘""年度总结""数据回顾""结项" → 确保 Q4 无违禁词
4. 全文搜索 "奥创""星擎" → 确保无自夸章节
5. 确认所有 market data 有来源标注

## Self-QC Checklist

生成后逐项自检，全部通过才能创建审核：

- [ ] 12 章结构完整，每章有实质内容（非空）
- [ ] 2.1 年度策略总览与 6/7/8 节对齐
- [ ] Q4 无复盘/总结/结项等事后视角内容
- [ ] 矩阵账号规划按客户行业/市场定制，未照搬模板
- [ ] 每个方向的选题是具体的、可执行的画面描述
- [ ] 待确认项逐条列出
- [ ] 所有 market data 有来源标注，无编造
- [ ] Q1 25条选题覆盖 5 个方向
- [ ] 文档面向运营/销售可读，无技术术语

**QC 不通过 → 重试最多 2 次 → 仍不通过 → 写阻塞原因。**
**QC 通过 → 创建 Base 审核记录。**

## Failure Modes

| 情境 | 处理 |
|---|---|
| web_search 不可用 | 跳过市场数据，标注"待补充" |
| 客户行业特殊，无通用模板 | 基于需求表定制，标注哪些是推断 |
| 矩阵账号参数不明确 | 按保守规则分配，标注"待确认" |
| 拍摄清单超出合理范围 | 按 P0/P1/P2 分级调整 |
| 文档编辑权限不足 | 告知用户，不继续修改 |
| Q4 出现违禁词汇 | 全文替换后重新 QC |
