# 国别市场报告 HTML 模板

## 1. 输出结构

文件名：`[品类]_[国家]_市场决策与开拓报告.html`

HTML 必须包含：`<!doctype html>`、`lang="zh-CN"`、UTF-8、viewport；完整内联 `<style>`，不依赖 CDN、外部字体或脚本；`<main class="report">` 与 16–20 个 `<section class="report-page">`；每页页眉、页脚、逻辑页码和 `data-page`；可点击来源链接，页面末尾有来源账本；打印 CSS：A4、保留背景色、稳定分页。

封面显示：品类、国家、报告日期、数据截止日、版本、保密等级。报告先给结论，后给证据和执行方案。

## 2. 18页页面预算

| 页码 | 页面 | 必须回答的问题 |
|---:|---|---|
| 1 | 封面 | 分析哪个品类、哪个国家、何时、什么版本 |
| 2 | 决策仪表盘 | 进入/条件进入/暂缓/不进入，首发品与最大风险 |
| 3 | 品类边界 + 国别环境 | 当地如何称呼、谁购买、该国为何形成机会 |
| 4 | TAM/SAM/SOM | 有多大；若不能精确估算，代理池是什么 |
| 5 | 趋势与季节 | 增长是否持续，何时进入 |
| 6 | 地区与细分机会 | 哪些地区、场景和买家优先 |
| 7 | 渠道与采购链 | 通过谁销售，各方负责什么 |
| 8 | 竞争格局 | 活跃企业、定位、价格和空白 |
| 9 | 价格与VOC | 买家比较什么、接受什么价格和价值 |
| 10 | 合规、贸易、物流 | 能否合法、稳定、经济地交付 |
| 11 | 选品池评分 | 10–20个候选中谁值得验证 |
| 12–13 | TOP5产品卡 | 卖给谁、规格、价格、差异化、测试 |
| 14 | 单位经济 | 落地成本、贡献毛利、盈亏和敏感性 |
| 15 | 进入模式与组合 | 定位、产品组合、渠道、本地化 |
| 16 | 90天行动地图 | 每阶段任务、负责人、产出、KPI |
| 17 | Kill Criteria + 风险 | 何时继续、调整、暂停或退出 |
| 18 | 方法、置信度、来源 | 结论可靠度与数据缺口 |

仅在行业强制合规或关键公司表无法压缩时使用第19–20页。不得通过缩小到难读字号满足页数。

## 3. 中国外贸企业阅读逻辑

每页标题直接写结论，不写"市场概况"一类空标题。信息顺序：一句话结论 → 3–5个关键数据/证据 → 对中国供应商的影响 → 建议动作或验证条件。

语言要求：简体中文、短句、少术语。当地公司、法规、平台和搜索词保留原文；首次出现时给中文解释。使用"出口商/制造商/渠道商/项目方/买家"而非模糊的"我们"。

## 4. HTML视觉规范

以 `assets/report-shell.html` 为基础。关键设计变量：`--navy:#0b1f3a;--blue:#1f4b7a;--red:#b42318;--orange:#d97706;--green:#16794b;--ink:#172033;--muted:#667085;--line:#d9e0e8;--paper:#ffffff;--soft:#f4f7fa`

字体：`"Microsoft YaHei", "PingFang SC", Arial, sans-serif`。正文打印字号不低于9.5pt，屏幕正文建议14–16px。

组件：`.decision-badge`(总体结论)、`.kpi-grid/.kpi-card`(关键数字，单页≤6个)、`.insight`(一句话商业解释)、`.data-table`(比较与映射，避免>8列)、`.bar`(份额/评分条，必须有真实数值)、`.tag.fact/.tag.estimate/.tag.assumption`(区分事实/估算/假设)、`.risk.high|medium|low`(风险等级)、`.source-note`(紧贴图表的来源/时间/地区/单位)。

图标点缀：关键卡片标题、决策徽章和页面结论可适度使用 emoji 图标做视觉引导（如 📊市场规模、⚖️合规、💡洞察、🎯选品、⏱️90天行动、⚠️风险），每页 1-3 个，只作点缀不作正文，避免密集或卡通化。

避免大面积渐变、霓虹、玻璃拟态、卡通插画和运营后台风格。图标用圆形徽章（`.ico-badge`）适度点缀卡片标题、决策徽章和 KPI 卡，每页 1-3 个。封面可以有克制的几何装饰，正文保持白底和咨询报告感。

## 5. 图表与来源

所有图表显示标题、单位、币种、时间范围、国家/地区和来源编号。可用 CSS 条形图、热力格、时间轴、矩阵和漏斗；无需为了"好看"制造曲线。数据不足时使用"数据缺口卡"，说明缺什么、为什么影响决策、30天内如何验证。正文引用格式：`<a class="cite" href="URL">[S01]</a>`。来源账本至少记录：编号、机构/页面、支持结论、数据期、采集日、证据等级、链接。企业官网公开价标为"挂牌/线索价"，不得写成成交价；企业自述不得直接证明市场份额。

## 6. 打印与压缩规则

必须包含：`@page{size:A4;margin:0}.report-page{width:210mm;min-height:297mm;page-break-after:always}.report-page:last-child{page-break-after:auto}*{-webkit-print-color-adjust:exact;print-color-adjust:exact}`

屏幕端页面可有阴影和间距；打印时去除阴影。移动端取消固定A4宽高，双栏/三栏折为单栏。

超页处理：1.删除无关宏观背景和重复解释 2.合并同类图表，长公司表只留代表性企业 3.将TOP5压缩为每页2–3张产品卡 4.保留结论、公式、硬门槛、90天动作和来源 5.不删除合规红线，不缩小至不可读字体。
