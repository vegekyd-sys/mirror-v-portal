# 国别数据与证据规范

## 1. 无 Exa 研究路径

不得安装、要求或调用 Exa MCP。按以下顺序检索：

1. 目标国政府、海关、统计局、标准/监管机构、官方贸易门户
2. 国际组织与透明的贸易数据库
3. 当地平台前台、零售商、批发商、经销商、招投标和企业披露
4. Google Trends或其他可复现的搜索趋势、公开评论、问答和社交信号
5. 行业协会、上市公司报告和方法透明的研究机构
6. 专业媒体、论坛和社区，仅用于线索/VOC

普通网页浏览已足够完成研究。动态页面或登录限制无法核实时，记录"不可验证"，不要用搜索摘要补造数据。

## 2. 国家证据隔离

证据账本的 `country` 必须与报告国家一致。以下情况不得直接进入评分或市场规模：其他国家的平台销量、价格、评论或搜索趋势；区域平均值替代目标国数据；全球市场规模按人口机械切分；另一国家的法规、认证、税率、节日或渠道结构；上一份报告的结论或产品评分。若必须用跨国代理，标记 `跨国代理`，解释差异和偏差方向，只能用于提出待验证假设。

## 3. 决策数据地图

| 决策问题 | 首选证据 | 补充证据 |
|---|---|---|
| 市场规模 | 目标国官方统计、进口额、行业协会 | 研究报告、平台/账户反推 |
| 增长趋势 | 多年贸易/行业数据、可复现搜索趋势 | 新项目、新品与政策信号 |
| 竞争 | 当地平台、渠道货架、企业官网/披露 | 搜索可见度、评论量、项目案例 |
| 价格 | 当地挂牌价、平台价、经销/RFQ | 历史促销与报价线索 |
| 需求/VOC | 当地评论、问答、售后、RFQ、访谈 | 社交媒体与论坛 |
| 合规 | 目标国监管、海关、标准、法律原文 | 律所/检测机构解释 |
| 物流 | 承运商、货代、仓配和安装报价 | 行业基准，仅用于敏感性 |
| 成本利润 | 供应商成本、税费、渠道费率 | 管理假设，必须标注 |

## 4. 时效与验证

- 价格、库存、平台排名：尽量不超过30天
- 搜索趋势：采集至报告日期
- 税率、认证、标签、平台政策：使用当前有效官方版本
- 汇率：标注换算日和来源
- 宏观与买方数据：尽量不超过12个月
- 竞品产品、渠道和项目：尽量不超过90天

每个决策关键数字优先由两个独立来源验证。无法交叉验证时降低置信度。市场规模方法差异超过2倍时展示差异，不取简单平均。

## 5. 证据账本

| ID | 国家 | 结论/数据 | 数值与单位 | 数据期 | 来源与链接 | 采集日 | 等级 | 标签/备注 |
|---|---|---|---|---|---|---|---|---|

证据等级：A=目标国官方/监管/海关或直接一手数据；B=当地平台前台/企业披露/渠道实价/招标项目文件；C=国际组织/透明贸易库或方法透明研究；D=媒体/社区/单一样本或分析推断。D级不能单独决定 Go/No-Go。所有证据另标 `事实 / 估算 / 推断 / 管理假设 / 跨国代理`。
