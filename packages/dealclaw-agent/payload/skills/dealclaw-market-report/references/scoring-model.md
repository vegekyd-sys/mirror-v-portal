# 选品决策评分模型

> 每份报告必须针对"当前品类 × 当前国家"重新设定锚点并重新评分。不得沿用另一国家的分数、价格基准、渠道权重或合规判断。

## 1. 硬门槛

评分前先判断以下门槛。任一项无法在合理成本和周期内解决，则标记 `淘汰/待整改`，不得用高需求分抵消：

1. 禁止或高度受限进口
2. 强制认证、注册或责任主体不可满足
3. 明显专利、商标、外观或平台侵权风险
4. 基准情景下单件贡献毛利为负
5. 物流、危险品、温控、破损、安装或售后不可控
6. 核心事实无法验证，缺失权重超过 40%

## 2. 基础权重

| 维度 | 权重 | 评估问题 |
|---|---:|---|
| 需求强度 | 18 | 搜索、成交、进口、买方和评论信号是否充足？ |
| 增长与趋势持续性 | 10 | 增长是否高于大盘，是否为结构性而非短期噪声？ |
| 竞争空白 | 14 | 集中度、评价门槛、同质化和未满足需求是否允许新进入？ |
| 价格与利润潜力 | 16 | 价格带、落地成本、渠道费用和贡献毛利是否健康？ |
| 渠道适配 | 8 | 主流渠道能否触达，进入条件和获客方式是否清晰？ |
| 合规可行性 | 10 | 认证、标签、税费、主体和责任要求是否可控？ |
| 物流与售后 | 8 | 体积重、破损、退货、安装、维修和备件风险是否可控？ |
| 中国供应优势 | 8 | 成本、产能、MOQ、交期、技术和定制是否有优势？ |
| 差异化空间 | 5 | 是否能通过产品、包装、内容、服务或渠道形成可验证差异？ |
| 复购/生命周期价值 | 3 | 是否有耗材、配件、升级、续购或长期服务价值？ |
| **合计** | **100** |  |

## 3. 计算方法

每个维度按 0–5 分评分：0=不可行或无证据；1=显著弱于品类基准；2=略弱于基准；3=达到基准；4=明显优于基准；5=强证据支持的领先机会。

不得使用跨行业统一锚点。先根据该国家、类目和渠道样本建立本次报告的相对锚点，并公开锚点。

`总分 = Σ(有效维度权重 × 维度得分 ÷ 5) ÷ Σ有效维度权重 × 100`

缺失值不按 0 分处理；删除缺失维度并将剩余权重归一化。缺失权重超过 40% 时不输出总分。

## 4. 结论分级

| 得分 | 默认结论 | 动作 |
|---:|---|---|
| 80–100 | 优先测试 | 进入样品、认证、渠道和首批备货验证 |
| 70–79 | 小批量验证 | 只验证关键假设，不直接重仓 |
| 60–69 | 条件进入/观察 | 先解决毛利、合规、渠道或差异化缺口 |
| <60 | 暂缓/淘汰 | 记录淘汰原因和重新评估条件 |

硬门槛永远优先于分数。

## 5. 行业适配

保持总权重 100，最多调整 20 个百分点，并公开调整理由：
- B2B 工业品：提高合规、渠道、物流售后和中国供应优势；降低复购和短期趋势。
- 快消/耗材：提高复购、渠道和利润；加入保质期与补货风险。
- 监管品：提高合规至核心权重；未经验证不得给出 Go。
- 时尚/季节品：提高趋势、竞争和库存风险；加入尺码/颜色/退货。
- 大件/易碎品：提高物流售后；加入本地仓、安装和破损率。

## 6. 置信度

- 高：关键结论由至少两个独立的一手/平台来源支持，数据时效符合要求
- 中：大部分结论可验证，但销量、份额或成本含合理估算
- 低：依赖单一来源、陈旧数据或强推断

高分低置信度产品只能进入"小批量验证"，不能直接列为规模化进入。
