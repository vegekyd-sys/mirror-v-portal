# Content Creation Workflow（内容创作全流程）

作者：莫惠琴 | 沉淀时间：2026-07-30
实战来源：越南工业行系列推文

## 核心流程（8步）

### S1 需求理解
目标读者、系列定位、禁止项、参考风格。系列文章开篇串联前文，列出具体拜访对象。背景越后置，核心新闻前置。

### S2 资料检索或素材梳理
- 用户有素材 → 梳理：人物/企业/数据 → 对照表 + 关键信息提炼
- 用户无素材 → 自行搜索：市场数据/企业信息/行业背景 → 形成素材库
- 品牌名通用翻中文、冷门保留英文（最高优先级）；数据标注来源；无来源不采用

### S3 选题策划
2-3个方向+侧重点+推荐理由，等用户确认。

### S4 搭建框架
Lead + PART 01/02/03 + 收尾CTA。标题事实>意愿，与正文一致。核心新闻前置，背景后置。抽象链路翻译为业务场景。

### S5 填充成稿
B端务实风，有数据有对比有归纳。单一企业融入叙事。篇幅控制在800-1200字。

### S6 检查核验
5项自动检查：事实数据交叉验证、敏感词违禁词排查、病句错别字通读、逻辑通顺检查、B2B调性审查。完成后输出核查报告。

### S7 修改迭代
收敛修改：意愿→事实，具体>抽象，内部流程不入稿，系列结尾每篇不同。检查清单11项逐条打勾。

### S8 排版交付
- S8.1：飞书文档（供复制粘贴秀米，含分割线/加粗/列表）
- S8.2：排版预览HTML（375px手机端效果，分区标题+卡片+图片位）
- S8.3：最终交付HTML预览链接（上传Drive，手机打开即见排版效果）
秀米格式参数：字号16 / 行间距1.6 / 字间距0 / 段落间距8 / 颜色rgb(62,62,62)

## 关键规则速查

| 类别 | 规则 |
|---|---|
| 标题 | 事实>意愿，与正文一致；消息重时直接告知事实 |
| 品牌名 | 通用品牌翻中文（可口可乐/百事/喜力），冷门保留英文 |
| 结构 | 核心新闻前置，背景后置；单一企业介绍融入叙事 |
| 表达 | 具体动作>抽象比喻；抽象链路翻译业务场景 |
| 禁止 | 内部工作流程、"敬请关注"、空话宏堆、标题党、极限词 |
| 结尾 | 每篇不同，有行动CTA，系列收尾做全链回顾 |
| 公众号 | PART分块+分隔线，非H2标题 |

## G2 用户偏好库（12项）

| 维度 | 偏好 |
|---|---|
| 标题风格 | 消息重时直接给结论 > 提问式 |
| 标题动词 | 事实 > 意愿 |
| 段落长度 | ~300字/段 |
| 结构 | 核心新闻 > 案例 > 背景 |
| 企业介绍 | 融入叙事，不单独成章 |
| 收尾 | 归纳式 > 宏大叙事 |
| CTA | 紧迫感驱动（"您的同行已报名"） |
| 版式 | PART分块+分隔线 |
| 系列索引 | Lead列具体对象名称 |
| 品牌名 | 通用品牌中文 > 冷门保留英文 |
| 表达 | 具体动作 > 抽象比喻 |
| 禁用词 | "巨大的"/"首届"/"腾飞"/"敬请期待" |

## G4 纠错知识库（17条）

1. 系列连载越往后背景越后置，核心新闻越前置
2. Lead概括不如直接点名——列具体名称
3. 消息够重时标题直接告知事实，不需要悬念
4. 标题动词分清"事实"和"意愿"——"确认参观">"想对接"
5. 单一企业时介绍融入叙事，不单独成章
6. 预告一条线也有价值——170字能维持追更节奏
7. 抽象概括不如具体动作
8. 系列文章开篇必须串联前文
9. 项目细节宁可多不可少
10. 公众号用PART分块，不是H2标题
11. 结尾必须有CTA，"敬请关注"等于无CTA
12. 英文品牌名：通用的翻中文，冷门的保留
13. 段落组织：公司→需求→市场，三层分离可跳读
14. 标题和正文必须对得上
15. 内部流程不写进新闻稿
16. 抽象模型翻译成业务场景
17. 系列结尾每篇不同

## 适用场景
新闻稿、行业推文、买家拜访实录等B端内容创作。多篇系列保持统一调性。从大量原始素材中提炼结构、形成有洞察力的稿件。
