## 🆕 §展会 展会短视频策略（展会新增章节）

### 结构

每场展会独立拆解，多展会按时间顺排：

1. **展会概览** — 展会名称、时间、城市、摊位号、主推产品
2. **展前倒计时内容矩阵** — 60/30/14/7/3/1 天节奏
3. **展中即时视频策略** — 展位+产品+互动+引流
4. **展后复盘内容** — 3天内发布，数据回顾+买家反馈
5. **跨展联动**（如有2场）— 墨西哥展素材复用到沙特展预热

### 展前倒计时（例：倒推60天）

| 节点 | 内容关键词 | 数量 | 目的 |
|------|-----------|:---:|------|
| 60天 | 工厂预热：产线、质检、新品预告 | 8条 | 建立品牌认知 |
| 30天 | 展会预告+展位号公布+产品亮点 | 10条 | 引发期待 |
| 14天 | 倒计时+免样/优惠预告+邀约视频 | 8条 | 吸引到场 |
| 7天 | 每日1条倒计时+展位指引+暴力测试 | 7条 | 强化行动号召 |
| 3天 | 展品出发/团队出发vlog+展位搭建预告 | 4条 | 临场感 |
| 1天 | 明日开幕+展位实拍+限时优惠 | 3条 | 紧迫感 |

### 展中即时视频（3天展会）

| 类型 | 数量 | 内容 | 拍摄要求 |
|------|:---:|------|----------|
| 展位全景 | 3条 | 航拍/广角展位人流 | 每天1条 |
| 产品演示 | 6条 | 暴力测试/对比/试穿试戴 | 现场实拍 |
| 买家互动 | 3条 | 客户试产品/交流（背影或授权正脸） | 许总审核 |
| 限时行动 | 3条 | "最后一天""仅剩X名额" | 每天1条 |
| 展位小剧场 | 3条 | 工作人员自然状态+多镜头混剪 | 轻快BGM |

### 展后复盘（3天内发布）

| 内容 | 发布时效 |
|------|:---:|
| 展会数据回顾视频（来访数/样品领完/签约数可视化） | Day+1 |
| 精彩花絮混剪（BGM+快节奏） | Day+2 |
| 买家反馈+下届预告 | Day+3 |

## 🔴 强制规则（继承 + 展会新增）

### 继承自标准版

| 规则 | 说明 |
|------|------|
| 禁真人出镜口播 | ✅ AI数字人可出镜，产线工人自然操作可出镜 |
| 脚本口语化 | 书面语:口语 ≈ 4:6，带当地语气词 |
| 每条带Hook | 前3秒画面+字幕/音效 |
| TikTok案例 | 4+条，放§3后§4前 |
| §4内容触达逻辑 | 4步：持续露出→数据观察→方向优化→品牌积累 |
| 禁用词 | ❌ 互动/询盘/WhatsApp/成交/意向客户/线索 |
| Q1只有4方向 | 删方向5买家FAQ |
| Q4不能复盘/结项 | 保持展望调性 |

### 🆕 展会版专用规则

| 规则 | 说明 |
|------|------|
| ✅ 允许展会O2O | 展会版核心场景，展位→线上→展位闭环 |
| ✅ 允许多展会联动 | 单季度可有2场展会，素材和选题复用 |
| ✅ 允许倒计时紧迫感 | "7天后墨西哥见"类型可接受 |
| ✅ 现场互动需审核 | 含客户正脸/对话的视频需许总确认 |
| ❌ 不允许虚假紧迫感 | 不能说"仅剩最后3个名额"如实际不限 |
| ❌ 不允许展位人流量造假 | 不夸大来访数据 |
| ❌ 不允许竞品/其他展位入镜 | 展中拍摄注意画面清洁 |

## 多展会处理

若客户有2场或更多展会（如本例：墨西哥+沙特），按时间先后独立出展前/展中/展后计划，并在最后加"跨展联动"：

- 墨西哥展（9/8-10）→ 展后复盘素材 → 复用于沙特展（12/20-22）预热
- 沙特展前预热引用墨西哥展数据："Mexico was packed, now Saudi"
