# shooting-checklist-builder

## 触发条件

用户提供拍摄脚本、选题大纲或拍摄需求，要求生成拍摄清单文档。

典型触发语句：
- "根据这个脚本给我生成拍摄清单"
- "帮我把这些选题拆成拍摄项目"
- "按之前的格式出一份拍摄清单"

## 文档结构（三部分，固定模板）

### 一、拍摄前准备

一张勾选表格，列：☐ | 类型 | 准备内容 | 负责人

- **类型**枚举：设备 / 物料 / 场景 / 人员 / 安全
- 从拍摄内容反向提取所需物料和人员，归入对应类型
- 负责人默认填"工厂"，特殊跨部门项可标注"客户+工厂"

示例格式：
```
☐ | 设备 | 五大主推设备各≥1台，可正常运行，表面整洁、铭牌清晰 | 工厂
☐ | 物料 | 测试工件：金属件/轴承/轴类等各5-10件 | 工厂
☐ | 场景 | 车间整理干净、通道畅通 | 工厂
☐ | 人员 | 操作员1-2名、工程师1名 | 工厂
☐ | 安全 | 防护用品到位；设备安全装置到位 | 工厂
```

### 二、拍摄项目执行清单

核心部分，按拍摄科目归类。每个科目一个表格，有**两种类型**：

#### A. 勾选清单表（需要现场逐条打勾确认的）

用于实际需要逐项确认的拍摄条目。表头：☐ | 具体内容 | 物料/配合

适用于：
- 工厂环境 / 设备概览
- 简短可直接确认的条目（≤10条）
- 开拍即拍的科目

#### B. 镜头参考表（不需要打勾，作为摄影师创作参考）

用于内容丰富、拍摄时有创作空间的科目。表头：具体内容 | 物料/配合

适用于：
- 精度演示、制造工艺等细节丰富的科目
- 有"三块内容"或子结构引导的科目
- 作为摄影师发挥的参考提纲

#### 科目设计原则

根据素材反推拍摄科目，常见类别：
1. **工厂/场景环境** — 外部、内部、标志、证书
2. **产品概览** — 每款产品的多角度基础镜头
3. **核心功能演示** — 产品的关键动作、精度、数据
4. **制造工艺** — 产线流程、关键工序
5. **品质细节** — 材质、做工、对比
6. **特色场景**（娱乐/解压/测试等）— 品牌特色内容
7. **团队人物** — 操作、互动、特写
8. **物流交付** — 打包、发货、运输

科目划分原则：
- 同类画面归并到一个科目，避免重复架机位
- 不同产品共享的科目只拍一次，不按产品重复
- 差异化内容（每个产品不同的核心功能）按产品×科目设计

#### 镜头预算控制（核心约束）

**总条目 ≤ 350 条。** 按以下方法分配：

1. 工厂环境：2-4条
2. 产品概览：设备数 × 3-6条
3. 功能演示：设备数 × 5-8条（仅核心项按设备重复）
4. 制造工艺：6-9条（只拍一次全流程）
5. 品质细节：1-2台代表性设备 × 4-6条
6. 特色场景：4-7条（只拍1台设备）
7. 团队人物：4-6条
8. 打包发车：4-6条

计算后如超350，优先压缩：制造工艺（选关键工序）、功能演示（非核心项不重复）、品质细节（减少代表设备数）。

#### 每个科目的结构

对"A类勾选清单"科目：
```
<h2>科目名称</h2>
<callout>一句话拍摄提示</callout>
<table>☐ | 具体内容 | 物料/配合</table>
```

对"B类镜头参考"科目（内容丰富时使用）：
```
<h2>科目名称</h2>
<callout>一句话拍摄提示</callout>

<!-- 三块内容清单（可勾选） -->
<table>☐ | 拍摄内容</table>（列出2-3个核心拍摄方向，打勾确认）

<!-- 镜头参考表 -->
<table>具体内容 | 物料/配合</table>（详细的镜头参考，不勾选）
```

### 三、拍摄结束确认签字

```
签字表：角色 | 姓名 | 签字 | 日期
- 客户代表
- 摄影师
```

## 文档创建流程

1. **分析素材**：理解拍摄对象、产品数量、核心卖点、特殊需求
2. **设计科目**：按科目设计原则归并同类镜头
3. **分配预算**：按预算控制约束计算每个科目的条目数
4. **生成XML**：参考 XML 模板（见下方），生成完整文档
5. **创建飞书文档**：用 `lark-cli docs +create --api-version v2 --as user`
6. **授予权限**：用 `lark-cli drive permission.members create --as user --yes` 给用户 `full_access`

## 视觉规范

- 表头统一 `background-color="rgb(242,243,245)"`（浅灰）
- A类清单表（需要勾选）：`callout` 背景 `light-green` 边框 `green`
- B类参考表（不需要勾选）：`callout` 背景 `rgb(254,255,240)` 边框 `rgb(255,242,88)`（浅黄）
- 预算概览 `callout`：`light-blue` 边框 `blue`
- 表格 `colgroup` 宽度与列数匹配：
  - 三列表（☐ | 内容 | 配合）：40 + 300 + 250
  - 两列表（内容 | 配合）：386 + 250
  - 二列清单（☐ | 拍摄内容）：40 + 580

## 重要规则

1. 总条目严格 ≤ 350
2. 不要在 `--content` 中一次性写入全文，先建骨架再分章节填充
3. 创建文档后必须调用 `drive permission.members create` 授予用户 full_access
4. 同类镜头归并到同一科目，不按"选题→分镜"拆解（避免重复劳动）
5. 制造工艺/品质细节/特色场景等科目只拍1次，不按设备重复
