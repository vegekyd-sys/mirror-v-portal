# DC-MI: 市场洞察

> DealClaw Skill | analyze-company 完成后触发 | 输出 → 给老板做市场决策
> 来源：田耕郡@格格 · V-Makaron

## DC-MI vs 买家策略模板 铁律分界线

| | DC-MI | 买家策略模板 |
|------|------|------|
| **对象** | 市场/行业/国家 | 单一买家 |
| **粒度** | 宏观：大盘、趋势、竞争格局 | 微观：这家公司采购谁、怎么切入 |
| **产出** | 行业报告（老板看市场方向） | 行动策略（销售拿去用） |
| **含买家？** | ✅ 1-2个示例，不超过2个 | ✅ 核心内容：深入一家 |
| **触发** | analyze-company 确认后 | 买家 ≥90分 确认后 |
| **数据源** | 行业报告 + CDP贸易统计 + 公网 | Apollo联系人 + 官网深度 + CDP |

> 如果一份报告里出现某个买家的采购量、联系人、供应商关系——那是 买家策略模板，不是 DC-MI。

## 触发条件

| 触发 | 示例 |
|------|------|
| 指令触发 | 「Everich 市场洞察」「看看保温杯出口市场」 |
| 画像关联 | analyze-company 画像确认后，用户说「看看市场」 |
| 行业探索 | 「印尼杯壶进口市场」— 不绑定特定企业 |

---

## 判断准则

**认知不能比老板差。** 这是 MI 的最高准则。数据必须是最新最前沿的（优先 2024-2025），分析角度要给老板启发——他们天天在自己的行业里，你拿去年的数据和泛泛的「市场增长 X%」糊弄不了人。宁可数据少但精准，不堆过时信息。每一条判断背后都问自己：老板看到这句会觉得「废话」还是「有意思」。

## 输出格式铁律

**文字段落 + 表格混合，不可全表。** 每节先写一段 2-4 句的分析判断，再跟数据表格。

```markdown
### ① 行业大盘

[先写段落：市场现状、增长驱动力、核心趋势，2-4句]

| 维度 | 数据 | 来源 |
|------|------|------|
| ... | ... | ... |
```

**买家示例规则：** 最多 2 个买家作为"典型渠道"举例说明，不可展开采购明细、联系人、
供应商关系（那是 买家策略模板 的活）。买家只用于说明市场特征，不是搜索结果。

## 执行流程（强制按序，不可跳步）

```
Step 1: 数据采集（并行）
  ├─ 1a. CDP 贸易数据 → 调用 searchCompanyNameWithTrade (企业名)
  ├─ 1b. 公网行业报告 → web_search × 3 方向 (市场规模/进口趋势/竞争格局)
  └─ 1c. 企业画像复用 → 产品线 + 目标市场 + 认证资质
  ↓
Step 2: 数据整理
  ├─ 贸易数据 → 进口量级、主要进口国、贸易趋势
  ├─ 行业报告 → 市场规模、增长率、驱动因素
  └─ 竞品发现 → 在目标市场搜同类供应商
  ↓
Step 3: 六章报告生成
  └─ 按模板输出飞书文档
  ↓
Step 4: 一句话结论（气泡）
  └─ 发布链接 + 核心发现
```

### Step 1 数据采集细则

**1a. CDP 贸易数据（必须调用）**

```bash
python3 -c "
from work.mio_api.dealclaw_search import search_company
result = search_company('<企业英文名>')
# 提取: totalExportCount, chinaExportRatio, recentYearTradeCount, 
#       recentYearTradeMoney, tradeWithChinaRatio, recentTradeTime
"
```

| 提取字段 | 用途 |
|---------|------|
| totalExportCount | 全球供应商数量 |
| chinaExportRatio | 中国供应商占比（进口依赖度） |
| recentYearTradeCount | 近12月贸易活跃度 |
| recentYearTradeMoney | 进口金额量级 |
| tradeWithChinaRatio | 从中国进口金额占比 |
| recentTradeTime | 最近交易时间 |

**1b. 公网搜索（必须调用，三个方向各搜一轮）**

| 方向 | 搜索词模板 | 提取 |
|------|----------|------|
| 市场规模 | `{产品} market size 2024 2025 {国家}` | 全球/区域规模、CAGR |
| 进口趋势 | `{国家} {产品} import data HS code` | HS编码、进口量、增长率 |
| 竞争格局 | `{国家} {产品} top brands suppliers manufacturers` | 主要玩家、市场份额 |

**1c. 企业画像复用**

从已生成的企业画像提取：目标市场、产品线列表、认证资质、产能规模。不重复爬官网。

## 六章报告模板

### ① 行业大盘

```markdown
## 一、行业大盘

| 维度 | 数据 | 来源 |
|------|------|------|
| 全球市场规模 | $XX Bn（2024） | IMARC / Grand View Research |
| CAGR | X.X%（2024-2030） | 同上 |
| 2030 预测 | $XX Bn | 同上 |
| 最大区域市场 | 北美/欧洲/亚太（XX%） | 同上 |
| 增长驱动 | 1. ...  2. ...  3. ... | 同上 |
| 技术趋势 | 1. ...  2. ... | 行业报道 |

> ⚠️ 买家示例规则：≤2个，仅用于说明市场特征，不展开采购明细/联系人/供应商关系。超过2个 → 越界，是 买家策略模板 的活。
```

### ② 产品线市场分析 + 进口依赖度

```markdown
## 二、产品线分析

### 产品线 1: {产品名}

| 维度 | 数据 | 来源 |
|------|------|------|
| 全球市场规模 | $XX Bn | 行业报告 |
| HS Code | XXXX.XX | WCO HS |
| 最大出口国 | 中国（XX%） | UN Comtrade |
| 最大进口国 | 美国/德国/... | UN Comtrade |
| 进口依赖度 | 中国占进口 XX% | CDP trade |
| 企业匹配度 | ⭐⭐⭐ | [推断] |
| 机会点 | ... | [推断] |

### 进口依赖度分析

| 目标市场 | 总进口额 | 从中国进口额 | 中国占比 | CDP验证 |
|---------|---------|------------|---------|---------|
| {国家1} | $XX M | $XX M | XX% | ✅ / — |
| {国家2} | $XX M | $XX M | XX% | ✅ / — |

> 中国占比 >30% → 买家对中国供应商熟悉，竞争激烈但门槛低
> 中国占比 <10% → 蓝海市场，但需要教育买家
```

### ③ 目标进口市场对比

```markdown
## 三、目标市场对比

| 市场 | 进口规模 | 增长趋势 | 中国占比 | 竞争强度 | 企业匹配 | 优先级 |
|------|---------|---------|---------|:---:|:---:|:---:|
| {国家1} | $XX M | ↗ +XX% | XX% | 高/中/低 | ⭐⭐⭐ | 🟢 |
| {国家2} | $XX M | → +XX% | XX% | 高/中/低 | ⭐⭐ | 🟡 |
| {国家3} | $XX M | ↗ +XX% | XX% | 高/中/低 | ⭐ | 🔵 |

**优先级判定：**
- 🟢 优先进入：进口规模大 + 增长快 + 企业匹配高
- 🟡 持续渗透：有壁垒但可进入
- 🔵 观望：不增资源
```

### ④ 竞争格局

```markdown
## 四、竞争格局

### 供给端（中国出口对手）

| 类型 | 代表企业 | 规模 | 与{企业名}对比 |
|------|---------|------|---------------|
| 上市龙头企业 | {企业1} | 年收 $XX M | 价格无优势，差异化打 |
| 中型专业厂 | {企业2} | 年收 $XX M | 直接对手，都在抢同一批客户 |
| 小型作坊 | {企业3} | 年收 <$X M | 品质不如你，但价格能砍 |

### 需求端（目标市场品牌/渠道）

| 类型 | 代表企业 | 采购特征 | 机会判断 |
|------|---------|---------|---------|
| 品牌商 | {品牌} | 年采购XX万件 | [推断] |
| 进口商 | {进口商} | 多品类代理 | [推断] |
| 电商DTC | {品牌} | 小批量高频 | [推断] |
```

### ⑤ 机会矩阵

```markdown
## 五、机会矩阵

| 象限 | 市场×产品 | 理由 | 动作 |
|------|----------|------|------|
| 🟢 主攻 | {国家}·{产品} | 进口$XXM+增长+中国企业占比高 | DC-LS 搜买家 |
| 🟢 主攻 | {国家}·{产品} | 同上 | DC-LS |
| 🟡 渗透 | {国家}·{产品} | 有壁垒但企业有认证优势 | DC-LS 小范围 |
| 🟡 走量 | {国家}·{产品} | 低利润但量大 | 跟单/配套 |
| 🔵 观望 | {国家}·{产品} | 规模小或门槛高 | 不增资源 |
```

### ⑥ 风险提示

```markdown
## 六、风险提示

| 风险 | 概率 | 影响 | 应对 |
|------|:---:|------|------|
| 关税变动 | 中 | 美国对华关税若扩至杯壶→利润压缩 | 泰国/柬埔寨工厂已建成，可转产能 |
| 原材料波动 | 中 | 不锈钢价格受镍价影响 | 长协锁定+库存缓冲 |
| 大客户集中 | 低 | 前5客户占收入>60% | 主动拓展中型客户分散风险 |
| 汇率波动 | 高 | 人民币升值侵蚀出口利润 | 人民币计价合同/FX对冲 |
| {企业特有风险} | ... | ... | ... |

> 风险评估基于当前已知信息。概率=低(<10%)/中(10-30%)/高(>30%)。
```

## 输出节奏（两阶段）

### Phase 1 — 一句话结论

以判断式语气给出数据锚点。不确定的不提。不反问用户「有没有废话」「你觉得怎么样」——你是行业专家，对自己出的报告负责。

✅ 「保温杯全球市场 $3.2B，北美占 38%。中国出口占美国进口 65%——你们切入的赛道是对的。」
❌ 「保温杯市场可能存在一定机会……」

### Phase 2 — 飞书文档

包含完整六章报告。文档标题格式：`{企业名} · 市场洞察`

## 数据来源规范

| 类型 | 标注格式 | 示例 |
|------|---------|------|
| CDP 贸易 | `（CDP trade）` | 中国出口占比 65%（CDP trade） |
| 行业报告 | `（{报告机构}）` | 全球 $3.2B（IMARC 2024） |
| 海关数据 | `（UN Comtrade）` | HS 9617.00 进口 $450M（UN Comtrade） |
| 推断 | `[推断]` | 买家对中国供应商开放 [推断] |
| 企业官网 | `（官网）` | 450+设计/年（官网） |

**不可出现的表述：**
- 「据报道」→ 未标注来源
- 「大概」「约」「可能」→ 数据不可靠
- 「预计」→ 除非引用机构预测并标注来源

## 与 DC-LS 的分工

| | DC-MI | DC-LS |
|------|------|------|
| 做什么 | 市场大盘 + 竞争格局 + 机会矩阵 | 找具体买家公司 + 联系人 |
| 数据源 | 行业报告 + CDP贸易统计 + 公网 | CDP searchAIV2 + Apollo |
| 输出 | 战略级市场判断 | 可执行的买家清单 |
| 受众 | 企业老板做市场决策 | 销售做具体触达 |

---

## Scope Boundary

✅ 行业市场规模(标注来源) | 进口数据引用 | 竞争描述 | 机会风险判断(基于数据)
🚫 销售推荐 | 客户优先级排序 | 市场预测补全 | 营销词(best/leading) | 编造

## 验证标准

- ✔ 至少1条产品线有市场分析
- ✔ 所有数据标注来源（CDP/web/行业报告）
- ✔ 进口依赖度至少覆盖1个目标市场
- ✔ 无销售推荐/优先级/营销词
- ✔ 风险提示≥3条有应对
- ✔ 数据可溯源
