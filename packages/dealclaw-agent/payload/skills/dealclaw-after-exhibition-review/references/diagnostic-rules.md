# 展后诊断与表达规则

## 诊断优先顺序

先检查数据质量，再沿漏斗从前向后定位第一个证据充分的阻塞点：

1. 数据覆盖：关键来源是否完成同步、字段是否可比。
2. 目标范围：目标买家数量与画像是否明确。
3. 邀约：是否成功触达、确认参与。
4. 到展：买家是否到达展会。
5. 展位互动：到展后是否到展位、扫码或发生会议。
6. 资格确认：是否形成产品、数量、项目或时间等需求证据。
7. 展后跟进：是否及时发送，是否送达和收到回复。
8. 商务推进：是否进入样品、报价、二次会议或谈判。

后段数据差不能自动证明前段策略有问题。例如回复低可能来自目标不准、信息未送达、跟进太慢或价值主张不足，需要结合相应证据区分。

## 证据等级

- 高：当前届唯一客户事件、原始互动引用、完整数据源，或口径一致且样本充分的对照。
- 中：多个一致的结构化信号，但原文或部分来源缺失。
- 低：单一标签、模型推断、小样本或不可验证描述。

低可信判断写成“值得验证的假设”，不能写成事实或根因。

## 基准使用

优先使用本企业同产品、同国家或同类型展会历史表现；其次使用同行业、同区域、相近企业规模、相近展会阶段的匿名聚合中位数和上四分位；没有可靠对照时只展示企业自身漏斗。

使用基准必须披露样本企业数与展会数、时间范围、行业和地区、指标分子分母、去重口径及缺失数据处理。不要用单个“优秀同行”刺激客户；样本过小或可反推企业身份时不展示。

## 买家分层

匹配度、阶段和跟进优先级分别回答不同问题：

- `fit_grade`：是不是理想买家。
- `stage`：关系推进到哪里。
- `followup_priority`：现在是否应该优先行动。

以下信号不能单独判为 A 级高意向：VIP、历届到展、活跃参展、存在决策人、扫码、名片、采购标签命中。高优先级至少要说明当前届关联、产品/角色匹配、互动或需求证据，以及为什么现在应行动。

## 产品使用健康度

对每项功能区分：

```text
available → offered → used → succeeded → contributed
```

- `available`：当时功能和数据源可用。
- `offered`：用户在该场景有使用机会。
- `used`：产生实际使用事件。
- `succeeded`：功能执行成功且数据完整。
- `contributed`：有证据说明它帮助完成了业务动作。

不能根据“使用次数少”直接断言客户浪费时间，也不能把未使用功能算作参展效果差的原因。产品故障、数据未接入、用户未使用和场景不适用必须分开。

## 表达分级

优先使用：

- “数据表明……”：事实完整且可重算。
- “更可能的解释是……”：有多个一致证据。
- “值得验证的假设是……”：证据有限。
- “当前无法判断……”：关键来源缺失或冲突。

禁止使用：

- “客户不会用小元，所以效果差”。
- “未使用某功能导致每天浪费两小时”，除非有测量依据。
- “明年效果肯定翻倍”。
- “这些都是高采购意向买家”，如果依据只有标签或历史到展。

## 从参考报告得到的校验重点

- “原始触达记录”“产品匹配企业”“本届到展企业”是不同集合，不能串成没有包含关系的漏斗。
- “积极到展”“历届到展买家”“活跃参展”可能语义重叠，聚合前需去重并说明定义。
- A/B/C 必须区分产品匹配与真实采购意向，不能只依赖 VIP、到展历史或决策人标签。
- 展后高优先级机会应优先安排 24 至 72 小时内行动；一个月适合长期培育，不适合等待报价和明确需求。
