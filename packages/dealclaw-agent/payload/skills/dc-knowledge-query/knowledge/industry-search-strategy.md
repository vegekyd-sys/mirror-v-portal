**买家类型优先级**：
- A级：工业设备经销商、工业传动产品代理商、减速机/齿轮箱/动力传动产品渠道商、有进口记录的工业品贸易商

**输出标准**：按采购可能 / 代理可能 / OEM配套可能三维度判断，不只看"是否直接采购"。第一轮完成筛选。
