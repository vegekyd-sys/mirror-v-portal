# 素材验真 (Material Verification)

> 夜班模式轻量 gate：在拍摄服务完成后，混剪脚本生成前，验证 DAM 素材是否可用于生产。
>
> 不做分析，不做筛选，不做 QC——只做存在性和可访问性的验真。

## 触发条件

当夜班模式从「拍摄服务」阶段推进到「混剪脚本」阶段时自动触发。典型场景：
- 拍摄清单已审核通过
- 拍摄交付物已上传 DAM
- 需要确认素材链路可用才能继续

**不触发：**
- 素材质量判断（那是人工的事）
- 素材筛选/分类（那是混剪脚本阶段的事）
- 策划案/拍摄清单相关的任务

## 输入要求

1. **DAM 项目信息**：projectId 或项目名称
2. **拍摄交付物记录**：拍摄条数、交付物链接
3. **客户信息**：企业名称、对应策划案

## 执行流程

### 1. 读取 DAM 素材列表

```bash
# 通过 DAM API 或 AutoFlow CACHED_DATA 获取素材列表
# 验证素材 ID、名称、时长、originUrl 可访问性
```

### 2. 验证项

| 检查项 | 方法 | 标准 |
|---|---|---|
| DAM 项目可访问 | 查询 projectId | 返回 slicingCount > 0 |
| 素材 ID 存在 | 逐条 ID 查询 | 存在且状态正常 |
| originUrl 可访问 | HTTP HEAD | 返回 200 |
| 素材数量 | 对比拍摄交付物 | DAM 素材数 ≥ 拍摄交付物条数的合理比例（非精确对比） |
| 素材时长 | 抽样检查 | 大部分素材在 2-15 秒范围（适合混剪） |

### 3. 输出

通过 → 返回 `pass`，附素材摘要（总数、品类分布、异常项）
不通过 → 返回 `blocked`，附具体阻塞原因（哪些素材不可用、缺失什么）

## Self-QC Gate

- ✅ DAM 项目 ID 正确且可访问
- ✅ 素材总数 > 0
- ✅ 抽样 URL 可访问（至少检查 5 条）
- ✅ 有明确的 pass/blocked 结论

失败 → 写阻塞原因到 Base，不继续推进。

## 边界

- ❌ 不筛选素材质量——那是人工和混剪脚本阶段的事
- ❌ 不修改 DAM 数据
- ❌ 不代替拍摄交付物验真（交付物由人工确认）
- ✅ 只做技术可访问性检查
- ✅ 快速轻量，不下载全量素材
