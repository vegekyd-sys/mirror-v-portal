# CSM 高端营销海报生成 SOP

## Trigger
当 CSM / 用户需要生成高端营销海报、活动海报、权益海报、社媒营销海报、招商/出海/展会/科技感推广海报，并希望达到「精致、细腻、高端、电影级、可商用」质感时使用。

典型触发话术：
- “V，按 CSM 高端海报 skill 做一张……”
- “用高端营销海报 SOP 出一张 3:5 海报……”
- “我要一张精致营销海报，主题是 X，色调是 Y，内容如下……”
- “参考之前中东/蓝色科技那种质感，但换成 X 主题……”
- “给客户做活动/喜报/出海/招商/社媒营销海报，保持高端质感。”

## Defaults
- **默认尺寸 / 比例：3:5 竖版海报。**
- 如 CSM 有特殊尺寸要求（如 9:16、4:5、小红书封面、朋友圈海报、横版物料等），由 CSM 在需求里临时说明。
- 工具无精确 3:5 时，优先用接近长竖版观感的 9:16 生成，并在必要时说明。

## Core Principle
不要把成功案例固化成单一模板。应拆成四个独立变量：

1. **主题（What）**：中东、AI短视频营销、喜报、展会、招商、节日、行业解决方案等。
2. **视觉风格/色调（Look）**：红金、蓝色科技、黑金、绿色可持续、白金、橙色增长感等。
3. **材质语言（Material）**：丝绒、金箔、磨砂玻璃、粒子、金属拉丝、宣纸、水晶、霓虹等。
4. **信息结构（Structure）**：头图、3/4/6卡片、价格、二维码、CTA、时间轴等。

主题不绑定色调。比如：
- 中东主题可以是红金奢华、蓝金科技、沙金高端、黑金商务。
- 红金色调可以用于中东、喜报、促销、节点活动、限量权益。
- 蓝色科技可以用于 AI、SaaS、智能制造、数据服务，也可以用于中东数字营销。

## 品质锚点（每张都应保留）
在 prompt 中稳定加入：

- 高端营销海报 / premium luxury Chinese B2B marketing poster
- 电影级光影 / cinematic lighting
- 8K 印刷质感 / 8K print quality
- 奢华/高端品牌调性 / premium brand campaign feel
- 背景有材质，不是纯色平面
- 精致内容框：细边、微光、浮雕/玻璃/金属/纸张材质
- 中文文字清晰、分层明确、可读性优先
- **主图必须贴合海报主题生成相关头图**，不能只用通用抽象背景
- 主图与下方内容自然过渡，避免硬切

## 主图强相关规则
每张海报顶部主图必须服务海报主题，而不是套通用背景。

生成前先把主题翻译成具体可视化场景：
- 中东增长计划 → 中东城市、地标、沙漠、买家网络、展会/贸易元素
- AI短视频营销 → 视频矩阵、AI指挥中心、社媒屏幕、全球买家连接、工厂/产品短视频缩略图
- 喜报/战报 → 胜利光效、增长曲线、榜单、奖杯/绶带（避免廉价奖状感）
- 展会邀约 → 展馆、人流、展位、客户洽谈、倒计时
- 招商/权益包 → 高端会场、会员权益、礼盒、稀缺席位
- 绿色可持续 → 智能工厂、清洁能源、供应链、绿色数据流

如果主题不清楚，先按文案中的行业/活动/目标客户推断一个主图方向；低置信时问 CSM 一句。

## 四变量采集法
生成前先向用户确认或从需求中抽取：

1. **主题**：这张海报讲什么？例如中东增长计划、AI短视频营销、客户喜报、展会邀约。
2. **色调/风格**：想要什么视觉情绪？例如红金奢华、蓝色科技、黑金商务、明亮增长感。
3. **内容结构**：几个核心点？底部放价格、二维码、联系方式还是 CTA？
4. **限制/偏好**：不要什么？例如不要奖状感、不要标题框、不要数字编号、不要陈旧色。

如果用户没说全，V 自动补齐一个合理方案，并在交付说明中简短说明选择。

## 主题变量（What）示例
主题描述“内容方向”，不决定颜色：

- 中东市场 / 区域市场开拓
- AI短视频营销 / 社媒矩阵
- 客户喜报 / 战报 / 成交捷报
- 展会邀约 / 展前蓄客 / 展后转化
- 招商加盟 / 权益包 / 限量席位
- 行业解决方案 / 工厂实力展示
- 节日节点 / 品牌周年 / 新品发布

## 色调与风格变量（Look）示例
色调描述“视觉情绪”，可套到不同主题：

- 红金奢华：热烈、限时、喜报、权益、稀缺
- 蓝色科技：AI、数据、SaaS、社媒矩阵、智能系统
- 黑金商务：高客单价、CEO、私董会、战略合作
- 绿色可持续：低碳、环保、供应链、长期主义
- 白金高级：干净、专业、发布会、咨询服务
- 橙金增长：增长、营销、流量、成交转化

## 材质语言变量（Material）示例
材质根据主题与色调组合选择：

- 丝绒 / 绸缎：奢华、仪式感、红金/黑金
- 金箔 / 金粉：稀缺、权益、价格、喜报
- 磨砂玻璃 / glassmorphism：科技、SaaS、AI、数据
- 粒子 / 光轨 / 数字网格：科技、增长、全球连接
- 金属拉丝：工业、高端商务、硬科技
- 宣纸 / 水墨 / 纸纹：文化、品牌故事、东方美学
- 水晶 / 冰蓝光：科技发布、高级清透感

## 信息结构变量（Structure）
先确认信息结构，再生成：

1. **顶部主图区**
   - 主标题 / 副标题 / 说明文字
   - 主图必须与主题强相关，不要只做抽象背景
   - 标题不要默认用框套住；除非用户要求，否则优先融入主图光感

2. **中部内容区**
   - 3 个核心卖点：1×3 或纵向三卡
   - 4 个权益：2×2 卡片
   - 6 个优势：建议 2×3 宽卡片；优先用精致 icon，不默认数字编号
   - 内容多时：主动压缩文案，保持每卡 2–3 行，避免小字过密

3. **底部 CTA 区**
   - 可选：价格 + 限量徽章
   - 可选：企业二维码 / CSM 二维码 / 公众号二维码
   - 可选：预约诊断 / 联系方式 / 活动时间
   - 二维码先用占位框，真实二维码后期替换

## Copy Compression Rule
AI 直出中文海报时，长文案容易出错。若每卡文字超过 20–28 个汉字，先压缩。

推荐格式：
- 标题：2–4 字，如「矩阵」「数据」「算法」
- 主句：8–14 字
- 副句：8–14 字

## Model / Generation Notes
- 优先使用 `google/gemini-3-pro-image-preview`：本案例中文准确率和结构执行较好。
- 默认 3:5；工具无精确 3:5 时，用 9:16 近似。
- 大段中文必须拆行；避免 tiny paragraph。
- 用户要求减少刷屏时，严格：一段简短说明 + 一张图。

## QC Checklist
生成后必须先检查再发：

1. 主标题、副标题是否正确
2. 主图是否贴合海报主题，而不是通用背景
3. 所有卡片标题和重点文案是否有错字/漏字
4. 卡片数量和布局是否符合要求
5. 是否有用户禁止的元素（如奖状感边框、标题框、数字编号等）
6. 背景是否有材质，不是平面色块
7. 主图是否抓眼球并与主题相关
8. 内容框是否精致、线条细腻、空间利用合理
9. 底部二维码/价格/CTA 是否按要求出现
10. 是否只发送 1 段说明 + 1 张图

## Iteration Pattern
用户反馈时，不要推翻重做；抽取可执行修改项：

- 主题主图更抓眼球 → 强化 hero scene
- 不要框套标题 → explicitly: no headline box/frame
- 数字换 icon → no numeric labels, use bespoke icons
- 字太小 → larger readable text, reduce copy length
- 框粗糙 → hairline border / glass edge / gold foil thin line
- 色调陈旧 → vibrant modern palette, no brown/dull tones
- 背景太平 → add material texture: particles / fabric / paper / glass / metal
- 尺寸变化 → only change if CSM explicitly requests a non-3:5 size

## Delivery Style
在 Feishu 群里：
- 如果已用 message 工具发图，最终回复 `NO_REPLY`
- 用户明确要求减少刷屏时，严格：一段简短说明 + 一张图
- 说明中只写关键变化和已知小问题，不写长报告

## Known Failure Modes
- 长中文小字容易错：压缩文案、加大字号
- 模型可能少出二维码：下版明确 “three QR placeholder frames side by side”
- 模型可能自动加数字：明确 no numeric labels
- 头部标题可能套框：明确 no box/frame around headline
- 直角需求可能变圆角：明确 sharp corners / beveled corners
