# 星擎销售全流程话术 Skill

## 触发场景

当以下情况时使用本 Skill：
1. 销售需要标准话术进行线上首访邀约
2. 销售需要线上拜访全流程话术（趋势/同行/6好/11问/方案价值）
3. 销售需要二访线下见面邀约话术
4. 销售需要线下方案讲解和签约推进话术
5. 新销售入职培训需要标准话术模板
6. Bright/郑总要求更新或查阅销售话术

## 话术结构

### 第一部分：邀约线上首访
- 线上会议目的（让客户从"跟我有什么关系"到"我得认真了解"）
- 5种邀约场景话术：
  - A：首次触达（电话/微信通用）
  - B：有展会/活动铺垫
  - C：客户犹豫说"没时间"
  - D：约访前确认（降低爽约）
  - E：开场定调子

### 第二部分：线上全流程拜访
- 趋势：不给客户上课，给客户"他在错过什么"
- 同行：不指名道姓，讲同行动作制造紧迫感
- 6好：先问客户"中了几个"，再对准痛点讲（数据/算法/矩阵/安全/保效/服务）
- 11问：不是审问，是帮客户判断适不适合。含禁区和铁律
- 方案价值：不是卖方案，是让客户理解"为什么必须等方案"

### 第三部分：调研表→方案生成
- 调研表提交后流程：整理调研表+妙记→提交V→生成方案→约访线下
- V提交流程：@V 出销售方案，附调研表+妙记+补充素材
- 铁律：缺预算或缺决策人不出方案；方案出来前不谈价格
- 拿到方案后销售自查清单

### 第四部分：线下二访
- 二访目标：让客户认可方案→敲定档位→签申请表
- 3种邀约场景话术：方案出来邀约/客户要线上看/客户说忙
- 线下见面标准流程（暖场2-3min→方案讲解15-20min→答疑10min→签约5-10min）
- 6段核心话术：开场定调/方案讲解节奏/过渡推动/处理犹豫/推动签约/结束
- 5条禁区：不念PPT/不放弃犹豫客户/不先报价/不逐页念/走之前必须确认下一步

## 使用规则

1. **对照文档使用**：所有话术以飞书文档为准，本 Skill 提供索引和触发规则
2. **场景匹配**：根据销售当前阶段选择对应话术模块，不要跳步骤
3. **不能跳步骤**：没有调研表不出方案，没有方案不报价格
4. **铁律优先**：每个模块标有❌禁区和✅铁律，违反即无效
5. **更新同步**：Bright 修改文档后，本 Skill 需同步更新路径
