# 奥创标准解决方案模板

> 基准文档：https://versa-ai.feishu.cn/docx/JfondEgKvovrl2xlXicc6bfInXb
> 用途：生成新客户方案时以此为结构基准，在原文档内原地修改而非新建链接

## 文档结构

### 主体7章

| 章节 | 标题 | 核心内容 |
|------|------|----------|
| §1 | 客户前沿诊断 & 达成目标 | 能力底座表、核心痛点、五种语言框架、期望目标 |
| §2 | 市场洞察 | 目标市场客户画像、平台机会&用户数据、产品市场机会、4层竞品分析 |
| §3 | 趋势分析 | 三大不可逆趋势、4种获客方式对比、社媒+展会O2O联动 |
| §4 | 为什么选奥创 | 奥创6好、已验证案例、自建vs外包vs奥创对比 |
| §5 | 客户交付后具体解决方案 | 账号布局、内容输出(6类×1500条)、推广投流(P0/P1/P2)、线索承接(七步漏斗+S/A/B/C) |
| §6 | 具体陪跑计划 & 验收保障 | 三阶段路线图、Max旗舰版12月清单、首月KPI、服务边界矩阵、兜底机制 |
| §7 | 为什么现在报名 | "三个不等"叙事、三列对比表、方案选择 |

### 末尾6个销售工具模块（全部使用 callout 气泡格式）

所有模块内容必须包裹在 `<callout emoji="💬"><blockquote>...</blockquote></callout>` 中。

1. 📸 4张截图建议 — 三列表格(序号/截图内容/截取位置)，4行数据指向§1-§5章节，表头加粗、无空行
2. 💬 配套邀约话术 — callout 气泡，三段邀约文案
3. 💰 给老板的三句话 — callout 气泡，3个要点
4. 📋 给外贸经理的三句话 — callout 气泡，3个要点
5. ✅ 方案讲完后小结 — callout 气泡，现场总结话术
6. ❓ FAQ 应对话术 — 4组Q&A，每组使用一个 callout 气泡

### 4张截图建议表格式

```xml
<p>微信发给客户时按以下4张截图：</p>
<table>
  <thead><tr><th><p><b>序号</b></p></th><th><p><b>截图内容</b></p></th><th><p><b>截取位置</b></p></th></tr></thead>
  <tbody>
    <tr><td><p>①</p></td><td><p>诊断核心痛点</p></td><td><p>§1 能力底座表 + 核心痛点4条</p></td></tr>
    <tr><td><p>②</p></td><td><p>市场洞察</p></td><td><p>§2 目标市场客户画像 + 平台机会</p></td></tr>
    <tr><td><p>③</p></td><td><p>同行情况</p></td><td><p>§2④ 4层竞品分析表</p></td></tr>
    <tr><td><p>④</p></td><td><p>账号布局</p></td><td><p>§5① 6账号矩阵表</p></td></tr>
  </tbody>
</table>
```

### 气泡格式示例

```xml
<callout emoji="💬">
  <blockquote>
    <p>第一段内容</p>
    <p>第二段内容</p>
  </blockquote>
</callout>
```

## 执行规则

- **原地修改**：改已有文档，不新建链接
- **多人协作防护**：每次操作前先 fetch 最新状态，避免基于过期 block ID 操作
- **末尾全部气泡**：6个模块内容必须 callout 包裹，不能用纯文本段落
- **表格必须干净**：无空 `<p>` 标签、表头 `<th>` 加 `<b>` 粗体、`<thead>/<tbody>` 分离
