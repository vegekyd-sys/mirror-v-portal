# Review — 自然语言买家画像校准

## Agent 原则

1. **继续 ≠ 确认。** 「继续」只表示当前会话沿用当前方向，不代表长期授权。
2. **负反馈先归因。** 先判断偏差来自国家、买家类型、产品/工艺、规模、渠道角色还是信息不足。能判断就直接修正下一批；不能判断才问一个关键问题。
3. **画像稳了再自动化。** 用户明确认可，或连续多轮自然语言反馈稳定后，才减少追问，在低风险内部动作上自动推进。
4. **意图模糊先反问。** 反馈没说「这次」还是「长期/永远」时，反问一句再执行——答「这次」进本轮 profile_patch，答「以后都」才写长期规则。不默认「这轮」。

## 交互单位

一次用户自然语言反馈算一轮。没有按钮轮次，也不因用户提到多家公司而重复计轮。

Agent 从完整语义中判断：
- 当前方向继续、需要纠偏、无法归因，还是已经稳定；
- 哪些是正例、负例；
- 当前搜索画像具体改了什么；
- 用户是否明确表达了长期规则。

脚本只保存证据、当前搜索画像和建议，不替代 Agent 判断。

## 执行

1. 读取用户整句反馈和本批结果上下文。
2. 给出语义判断：`continue | correcting | unclear | stable`。
3. 能归因时形成具体 `profile_patch`，例如品牌商优先、当前轮降低分销商权重；不要只写「买家类型需要调整」。

推荐使用可执行 schema：

```json
{
  "country": {"include": ["DE"], "avoid_current": ["US"]},
  "buyer_type": {"prefer": ["品牌商"], "avoid_current": ["分销商"]},
  "product": {"prefer": ["outdoor lighting"]}
}
```

`include/prefer` 会进入下一次搜索参数；`avoid_current` 只影响当前校准方向，不自动晋升长期排除。

### 隐式行为（behavior，可选）

除显式纠偏外，Agent 顺手观察并记录用户的「隐式行为」（用户没说、但行为体现的稳定模式），供每周蒸馏沉淀为用户行为偏好：

- 用户跳过某类线索（「这家跳过」）
- 用户反复追问某维度（「报价多少」「交期呢」）
- 用户总是优先看某市场 / 某类型

在 `interpretation` 里带一个可选的 `behavior` 数组：

```json
{
  "behavior": ["用户跳过贸易商", "用户追问交期"]
}
```

`behavior` 落盘到 feedback.jsonl，蒸馏时读取；不为空时才填，不必每次强求。
4. 调用：

```bash
python3 work/mio-api/dc_feedback.py buyer-turn \
  '<enterprise>' '<user_open_id>' '<用户原话>' \
  '<interpretation_json>'
```

5. 读取返回的当前搜索画像和建议，结合业务上下文决定下一步：直接重跑、沿用当前方向，或只问一个关键问题。
6. 下一批搜索必须带企业和用户标识，让搜索脚本自动读取并回显 `calibration.plan`；如果返回中没有该字段，不得声称纠偏已经生效。

## 偏好边界

- 单次反馈立即影响下一轮，但不自动成为长期偏好。
- 只有用户明确说「以后不要这类」「这个市场我们不做」等，才写入长期规则。
- 多轮重复信号可以形成偏好候选，仍由 Agent结合语义判断是否稳定。
- 偏好按企业和用户隔离；open_id 缺失时退化为企业共享观察，不直接晋升长期规则。
- 对外发送、报价、承诺交期始终需要确认。

## 目标

在 1–3 轮自然语言交互中形成 enough-to-act 的买家画像，而不是追求一次性完美画像。
