## 总流程

```
名片照片
 1. OCR 结构化提取
 2. GDPR 隐私门

 4. 意图判断（需有 text）
 5. 写入线索池（回写）
 6. 展后跟进（下一轮规划）
```

## 关键降级分支（需重点验证）

| 场景 | 降级行为 | 状态 |
|---|---|---|
| 只有名片、无 text | 跳过匹配/意图，纯买家信息落库 + **低意向兜底触达** | 🟡 |
| 无扫码 ID | 名片 OCR 或文本匹配兜底，标 ⚠️ 数据不全 | 🟡 |
| text 匹配不到买家 | 仍写线索池，来源「展会线索-未关联」 | 🟡 |
| 视觉模型未配置 | 仅人工录入，标 ⚠️，不阻塞 | 🟡 |

## 无 text 兜底触达（无意图 ≠ 不跟进）

只有名片、无录音/无 text 时，不静默丢进线索池就完事，走「低意向兜底触达」：

1. **落库照旧**：公司名/联系人/国家 ← OCR；来源 ← 展会线索（或「未关联」）；阶段 ← 待触达；冷热 ← ❄️冷（无意图）。
2. **邮件走最轻一档**：简短感谢 + 公司简介 + 产品目录，**不报价、不推销**（对应 workflow 里「只是逛展，暂无需求」模板）。
3. **标记待补充**：提示用户「该买家缺录音/意图信息，可后续补 text 再升级意向」。
4. **不自动发营销邮件**：只发感谢式触达，避免过度营销；发送前仍走 Growth Send 时区校验 + KB 素材检查。

- 发送：`dealclaw-email-growth-send`（Resend + 自动退订 + 回写）✅
