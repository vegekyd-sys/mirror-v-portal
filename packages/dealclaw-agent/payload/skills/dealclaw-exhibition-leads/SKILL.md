# 展会线索处理

> 展中线索（名片+录音）和展后跟进。展前邀约走 DC-Exhibition-Invitation。

## 触发

| 用户说 | 阶段 |
|------|------|
| 上传名片 / 录音 | 展中 OCR + ASR |
| 「展后跟进」 | 展后邮件 |

## 展中处理

1. GDPR 隐私门：已获同意才存储，未获同意仅临时处理
2. 名片 → OCR → 结构化提取（气泡通知 + 飞书文档）
3. 录音 → ASR → 说话人分割（气泡通知 + 飞书文档）
4. 匹配 → 关联名片与录音 → 意图分析（高/中/低意向）
5. 五步完成 → 一条总结气泡

## 展后跟进

按意图分类生成跟进邮件，走 Growth Send 发送。

## 边界

- GDPR 隐私门不可跳过
- 数据来源不对用户暴露
- 模糊字段标注 ⚠️，不自行脑补
- 展后邮件走 Growth Send，不单独发
