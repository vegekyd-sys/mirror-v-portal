# B2B TikTok 季度包矩阵策划案 Skill

## 定位

半年包 skill 的降级版。3个月、1次拍摄。六章框架，多项简化。

## 触发条件

用户发送需求表，服务周期为 3 个月。

## 与半年包的核心差异

| 维度 | 半年包 | 季度包 |
|------|--------|--------|
| 周期 | 6个月 | 3个月 |
| 拍摄 | 2次 | 1次 |
| 配比 | 两阶段渐变 | 并行策略 |
| 4.4 时段 | M2-M3/M4-M6 | M1-M2/M2-M3/M1-M3 |
| 清单 | P0+P1+P2 | P0+P1，无P2 |
| 排期 | 6阶段 | 12周 |

## 内容红线（最高优先级）

### 画面约束
全部工厂实拍。禁止动画、Motion Graphics、图表动画、3D渲染、特效合成、手绘插画。允许实拍画面上叠加文字/卡片+AI配音+动态字幕。

### 转化路径约束
**不能在 Bio 挂联系方式。所有转化引导只能指向评论区留言或后台私信。**
- ❌ Bio挂WhatsApp/邮箱/网站
- ✅ 「Comment below」「DM us for details」「评论区留言获取报价」


四、内容策略：开头写明双约束。4.2/4.4 全部实拍描述。4.6 仅P0+P1。

## 编辑原则

- 数据全来自需求表，缺失标「待客户补充」
- 账号层级按「地区流量池 + 语言受众池」判断
- 产品名必须来自需求表
- YT 不做品牌沉淀
- 4.1 参考视频必须真实 TikTok URL
- 标题为「季度策划案」
- 拍摄清单仅 P0+P1，标注无补拍
- 全文档画面描述全部实拍，无动画/图表/3D/特效
- **全文档无「Bio挂联系方式」，统一用「评论区留言」「后台私信/DM」**
