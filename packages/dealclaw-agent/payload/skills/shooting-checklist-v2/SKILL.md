# shooting-checklist-v3 — 工厂拍摄清单（v3 标准）

v2→v3 核心改进：删「科目」词、人物融入场景不单列、准备表加「工厂负责人打勾确认」列、执行表加地点/横屏/备注/优先级(P0/P1/P2)列、镜头参考≤8条。参考格式：伊科凡最终版 (Aj1BdzLhBoDkt9xHUTucMEgXnDb)。

## 触发条件

用户提供策划案，要求生成拍摄清单。

## 三部分固定结构

1. **拍摄前准备** — 按类型分表（设备/场景/人员/安全），标题：「拍摄前准备总检查（开拍前工厂负责人全部确认打勾）」
2. **拍摄项目执行清单** — 6个内容编号 + 时间估算（9:00-18:00）+「拍摄中，摄影师全部确认打勾」
3. **拍摄结束确认签字** — 客方代表 + 摄影师两行

## 🔴 表格列规则（不可变）

### 准备表列
| ☐ | 工厂负责人打勾确认 | 具体内容 | 备注 | 负责人 |

- 「负责人」列全部填「工厂」
- ❌ 不出现「类型」列
- ❌ 不包含拍摄团队设备（相机、灯光等）

### 执行表列
| ☐ | 优先级(P0/P1/P2) | 具体内容 | 物料/配合 | 地点 | 横屏 | 备注 |

- 优先级列填 **P0/P1/P2**，❌ 严禁出现「科目」字样
- 横屏列填 ✅ 或 —

## 内容分层规则

- **主线**：☐ 勾选，只写大方向（每编号6-8条）
- **镜头内容参考**：无☐列，纯参考表，≤8条。标题上方标「镜头内容参考」

## 编号结构（6个，人物融入场景不单列）

```
1. 工厂环境        — 外景、全景、标志、证书（P0为主，6-8条）
2. [方向1内容]     — 按策划案方向1（P0为主）
3. [方向2内容]     — 按策划案方向2
4. [方向3内容]     — 按策划案方向3
5. [方向4内容]     — 按策划案方向4
6. 打包发车        — 仓库、包装、叉车、装柜、发车（P0，仓库16:00前拍完）
```

## 人物拍摄处理

- ❌ 人物不作为独立编号出现
- ✅ 自然融入场景：产线工人操作时入镜，不单独拍人
- 如确有需要，在场景补拍中列≤5条，不加☐

## 时间估算规则

- 从 **9:00** 开始
- 压缩到 **18:00** 前
- 仓库打包发车安排在 **16:00-16:30**（仓库下班早）
- 17:00-18:00 机动补拍+签字

## 预算

总条目 150-200 条，P0 核心场景 ≤ 10 个

## 从策划案到清单的转换流程

1. 读策划案「Q1 内容策划」章节，提取4个内容方向
2. 每个方向 → 一个编号（2-5），标题引用方向名称
3. 方向中的选题 → 提炼为镜头内容参考表条目（≤8条）
4. 主线勾选只写大方向，6-8条☐
5. 工厂环境固定6条以内

## 准备清单固定项

按类型分表，每表3-8行，少于3行可合并。固定包含：

```
设备表：核心设备各≥1台，可正常运行，表面整洁
场景表：车间整洁、通道畅通、Logo清晰
人员表：操作员身穿工服
安全表：防护用品到位
```

- 表头：| ☐ | 工厂负责人打勾确认 | 具体内容 | 备注 | 负责人 |
- 负责人列全部填「工厂」

## 打包发车固定内容

编号6，P0，仓库16:00前拍摄：

```
仓库内景 → 包装/封箱/打托/贴标签 → 叉车铲货/穿梭/装柜 → 集装箱/货车驶出
```

## 质量确认清单

- [ ] 三部分结构完整（准备/执行/签字）
- [ ] 准备表头包含「工厂负责人打勾确认」+「负责人」列
- [ ] 执行表头包含「优先级(P0/P1/P2)」+ 地点 + 横屏 + 备注列
- [ ] ❌ 全文无「科目」字样
- [ ] ❌ 全文无「类型」列在准备表中
- [ ] 优先级列值只有 P0/P1/P2
- [ ] 编号1-6，人物自然融入场景
- [ ] 每个编号含「镜头内容参考」子表（无☐）
- [ ] 时间估算 9:00-18:00，仓库16:00
- [ ] 签字表：客方代表 + 摄影师
- [ ] 总条目 150-200

## Failure Modes

| 情境 | 处理 |
|---|---|
| 策划案方向不清晰 | 基于方向目的推断，标注"需确认" |
| 准备表出现「类型」列 | 替换为「工厂负责人打勾确认」 |
| 出现「科目」字样 | 全局删除 |
| 镜头内容参考超过8条 | 精简到8条内 |
| 文档编辑权限不足 | 告知用户，不继续修改 |
