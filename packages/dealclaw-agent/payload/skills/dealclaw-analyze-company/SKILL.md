# Analyze Company — 企业分析

> 触发：用户发 URL / 上传PDF / "分析这个公司" / 粘贴公司名

## When to Use

- 用户发送企业官网 URL
- 用户上传企业 PDF 文档（公司介绍 / 产品手册 / 资质文件等）
- 用户说「分析这个公司」「帮我看看这家」
- 用户粘贴公司名（降级：先搜到官网再分析）

## 判断准则

**不编造。** 无官方来源的产能/认证/客户一律标 `待确认`。区分「官网声称」和「推断」，推断加 `[推断]` 标签。缺失字段标待确认，不自行填充。

**双语并行。** 企业内部线用中文（官网中文页 / ICP 备案 / 企查查），外部线用英文（官网英文版 / About Us），各用各的，不交叉翻译。邮件和 WhatsApp 中的公司介绍用官网英文原文，一字不改。中文名从 官网中文页 → ICP备案 → 企查查 顺序查找，找不到才音译并标 `[音译推断]`。

**画像一对一。** 每个企业只绑一个主营业务画像（一对多：一个企业 → N 个买家画像）。用户说「换公司了」→ 新建企业画像，不覆盖旧的。

## 输出标准

**聊天里不输出表格。** 给 2-3 句判断，挑最打动人的点。

✅ 「海诺铸业，做精密铸造的。IATF16949 过了，给西门子供过货——底子比 80% 同行强。出海不缺资质，缺的是让对的买家知道你们。」

❌ 「海诺铸业成立于 1996 年，位于青岛，主营硅溶胶失蜡铸造，通过 IATF16949 认证…」

**主动纠偏。** 给完判断立刻指出不确定的字段，不等用户来改：

> 先帮我补几处，后面报告才准——
> • 产能 — 官网没给具体数字
> • 目标市场 — 我按官网客户倒推的，不一定对

纠偏完成后给钩子 ≤10 字导向下一步——「要不要找几个意大利买家？」

**不在聊天里自动生成飞书文档。** 画像写入知识库由独立触发入口完成，不属于本 skill。

## Actions

**信息采集（按可用数据源降级）**

| 用户提供了 | 走哪条路 |
|----------|---------|
| 官网 URL | `web_fetch` 中英文页面 → 按字段清单提取 |
| PDF 文档 | 直接解析提取 |
| 1688 / 阿里国际站链接 | ⚠️ 阿里系反爬，跳过 web_fetch，直接进「访谈模式」 |
| 只有公司名 | 先 web_search 找官网 → 找到走正常路径，找不到进访谈模式 |

**访谈模式**：不装模作样说「数据不足」——直接问核心问题：主营产品 / 目标市场 / 认证资质 / 工厂规模。用户答完即出画像。

**替代数据源（官网无/反爬时并行尝试）**：
- 天眼查/企查查查注册信息和规模
- Made-in-China / Global Sources 搜同名店铺
- CDP 有覆盖的国家可查贸易数据

**打开官网提取信息。** 同时读中文版 + 英文版。web_fetch 被挡（403/429/Cloudflare）→ web_search 兜底 → 仍无结果标「网站需手动验证」。按下方字段清单提取，缺的标 `待确认`。

**聊天纠偏。** 给 2-3 句判断 + 主动指出不确定字段 + 钩子导向下一步。

**播种子到知识库引擎。** 分析和纠偏完成后，自动写入本地知识库。dc-review 的纠正也同步落知识库，标记为 V 学习到的内容。

## Document Fields（知识库写入时参照）

**企业画像：**

| 字段 | 说明 |
|------|------|
| 公司名 | 内部线中文名（外部线英文名附后） |
| 成立年份 | 官网无则标待确认 |
| 国家/地区 | |
| 企业类型 | 工厂 / 贸易商 / 工贸一体（依据：生产线实拍、品控描述） |
| 主营产品 | 列出 3-5 个核心产品线 |
| 业务模式 | OEM / ODM / 自有品牌 / 分销（依据官网措辞） |
| 定制能力 | 有 / 无 / 待确认（是否提到 custom / OEM service / R&D） |
| 认证/资质 | 仅列官网明确提及的，不推测 |
| 产能/规模 | 如官网给出数字则填，否则待确认 |
| 目标市场 | 从合作案例/客户分布推断，不确定标待确认 |
| 数据来源 | 官网 URL |

**买家画像（两重身份不可合并，不可写「阀门工厂采购经理」）：**

| 字段 | 规则 |
|------|------|
| 买家身份类别 | 下游类型名，如「工业泵制造商」——不是职位 |
| 目标市场 | 买家所在国家，不填「海外」，无数据填待确认 |
| 采购产品 | 买家的具体采购需求 |
| 采购规模 | 必须量化（如「月 5000-10000 件」），无数据填待确认 |
| 联系人职位 | 该类买家中通常的决策人，如「采购总监」 |
| 关键要求 | 认证、交期、MOQ、价格敏感性等 |

## Boundaries

- 不验证官网声称的真实性（产能、认证、客户等）
- 不编造数据，不确定就标待确认
- 不自动生成飞书文档
- 纠偏时只问直接影响下一步行动的缺口。判断标准：缺了这个信息，下一步就做不了。成立年份差一两年不影响找买家→不问。出口占比不确定不影响推荐方向→不问。不要为了填充画像字段消耗用户注意力。
- 纠偏每次不超过 3 条问题。超过时按对下一步影响大小排序，只留前 3 条。
- 官网极薄（单页/纯图片）时画像偏薄，如实告知用户，不硬凑
