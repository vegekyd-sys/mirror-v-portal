# 海外采购商线索搜索技能

## 触发条件

用户提供以下信息时触发：
- 目标国家（如：巴西、墨西哥、阿联酋）
- 产品品类（如：电磁炉、茶咖机、纺织服装）
- 采购商数量（如：100、200）

典型话术：**
- "帮我找巴西 100 个电磁炉采购商"
- "针对墨西哥蓝牙音响市场，给我 50 个采购商名单"
- "生成目标国家该产品的采购商需求清单"

## 执行流程

### 第一步：确认参数

如果用户输入不完整，追问补齐：
1. 国家（必填）
2. 产品（必填）
3. 数量（必填，建议 50-200）

回复模板：
```
可以做。请确认三个条件：
1. 国家：如 巴西 / 墨西哥 / 迪拜
2. 产品：如 电磁炉 / 蓝牙音响 / 纺织服装
3. 数量：如 50 / 100 / 200
```

### 第二步：多路径并行搜索

**路径 A — Web Search（找大买家和零售商）：**
使用 `web_search` 搜索以下句式（每次 3-5 条并行）：
- `{国家} {产品} importer distributor wholesaler`
- `{国家} largest {相关品类} retailers 2024 2025`
- `{国家} {产品} 进口商 批发商 零售商`

**路径 B — 行业目录（适合特定品类）：**
- 鞋履/皮具 → Brazilian Footwear 官方目录 (brazilianfootwear.com/brands)
- 家电 → 各国 Amazon / Mercado Libre 类目卖家
- 纺织/面料 → 各国纺织协会会员目录
- 食品/饮料 → 各国进口食品协会

**路径 C — 已知渠道补全（针对常见国家）：**
直接列出目标国主要渠道类型：
- 大型零售连锁（3-5 个）
- 电商平台（2-3 个）
- 批发分销商（5-10 个）
- 专业进口商（5-10 个）
- 行业垂直渠道（酒店/餐饮/建筑等）

### 第三步：生成结构化数据

对于每个企业，按以下 6 字段生成：

| 字段 | 说明 | 要求 |
|------|------|------|
| 企业名称 | 官方名称 | 避免用简称 |
| 官网 | 完整 URL | 优先官网，其次 LinkedIn/平台页 |
| 企业介绍 | 100-200 字 | 包含：主营业务、规模、行业地位、适合中国供应商切入的方向 |
| 预计采购产品 | 具体到 SKU/材料级别 | 不要只写"电磁炉"，要写"便携单头电磁炉、嵌入式双头电磁灶、配套锅具" |
| 预计年采购规模 | 美元区间 | 保守估算，200 条中至少 80% 的区间不重复 |

**企业介绍写作规范：**
- 避免模板化尾句（如"官网为xxx，可作为中国供应商进入xxx市场的重点目标"）
- 按企业类型差异化描述：
  - 零售商 → 突出门店规模、客群定位、采购偏好
  - 批发商 → 突出分销网络、覆盖区域、进货品类
  - 品牌商 → 突出产品线、自有品牌、ODM/OEM 需求
  - 进口商 → 突出进口来源、分销能力
  - 酒店/餐饮 → 突出门店数、配置场景

**采购规模估算原则：**
- 大型零售集团：基于公开营收推算 5-15% 为采购额
- 中型零售商/分销商：按门店数 × 平均采购额
- 品牌商：按产品线数量和渠道规模
- 酒店/餐饮：按门店数 × 设备配置数量
- 使用 MD5 hash 对每个企业生成小幅随机偏移，避免大量相同值
- 规模用"约xxx-xxx万美元/年"格式

### 第四步：创建飞书表格

```bash
# 1. 创建表格
lark-cli sheets +create --title '{国家} {产品}采购商需求清单' \
  --headers '["序号","企业名称","企业介绍","官网","预计采购产品","预计年采购规模"]' \
  --as bot --json

# 2. 写入 CSV 数据
lark-cli sheets +csv-put --spreadsheet-token {token} \
  --sheet-name Sheet1 --start-cell A1 --csv @{csv_file} \
  --as bot --json

# 3. 冻结首行 + 开权限
lark-cli sheets +dim-freeze --spreadsheet-token {token} \
  --sheet-name Sheet1 --dimension row --count 1 --as bot --json

lark-cli drive permission.public patch --token {token} --type sheet \
  --data '{"link_share_entity":"anyone_readable","external_access":true}' \
  --as bot --yes --json

lark-cli drive permission.members create --token {token} --type sheet \
  --data '{"member_id":"{chat_open_id}","member_type":"openchat","perm":"full_access"}' \
  --as bot --yes --json
```

### 第五步：市场分析（可选，按用户需求追加）

如果用户要求市场分析或拜访材料，追加：

**A. 价格带分析：**
搜索六个当地主流平台获取价格参考：
- 巴西：Magazine Luiza, Mercado Livre
- 墨西哥：Amazon Mexico, Mercado Libre
- 南非：Takealot, Makro
- 越南：Shopee, Lazada
- 印尼：Tokopedia, Shopee
- 阿联酋：Amazon.ae, Noon, Carrefour

按低/中/高三个档位整理价格表，含当地货币+美元参考。

**B. 市场规模与增长数据：**
搜索行业报告数据支撑客户拜访材料。

**C. 展会对齐：**
如果用户有展会排期，匹配推荐参展优先级。

## 输出规范

1. **飞书表格**：带标题、冻结首行、列宽合理、群权限已开
2. **表格链接**：直接发到对话中
3. **数量承诺**：如实标注实际生成数量，不足时注明原因
4. **数据说明**：年采购规模是基于渠道规模/品类体量的保守估算，非公开财报数据

## 注意事项

- 采购规模是**估算值**，不是公开数据，务实在对话中说明
- 企业介绍**避免重复模板句**，每个企业的介绍要有差异化
- 优先使用`--as bot`创建文档/表格，避免权限问题
- 对于用户反馈的修改（如"太AI了""太雷同"），立即迭代重写
- 搜索不到足够数量时，先覆盖已知头部渠道，再标注实际数量
