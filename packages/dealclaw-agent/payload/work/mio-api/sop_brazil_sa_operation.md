> [XX总]，就是因为你预算紧，转让才更值得——同样18㎡正常要6-7万，你才3万多，省一半。机票酒店还不用出。说白了就是一个展位费撬一个市场。等明年预算够了，补贴还在不在谁都不知道。

> [XX总]，我理解你考虑。但名额今天确认——对方公司等着回复。就问你一句：**今年要不要也去这个市场走走？** 3万块，一两个小单的利润，换一个市场的入场券。
