### 一、项目背景

#### 1.1 客户概况

伊科凡 / 沣力通位于无锡市惠山区前洲镇，主营单柱液压机、四柱液压机、伺服液压机、伺服电缸压机、液压校直机五大品类，覆盖 10 大系列、250+ 品种及非标定制设备。核心优势包括：

- **源头厂家，支持非标定制**：根据工件尺寸、压力、行程、节拍、安全要求做方案，沟通链路短、响应快
- **高精度伺服控制**：伺服压机重复定位精度 ±0.01mm（待最终确认），位置/压力/速度三闭环控制
- **交期短、价格低、可接小单**：适合越南和印尼大量中小制造企业在自动化升级时的预算约束
- **制造经验扎实**：20 年制造经验，报价公开透明，质保一年、终身维护
- **油缸耐用性强**：油缸可使用八年以上，设备机架扎实可靠
- **认证与背书**：ISO9001 认证、10 项国家专利、4 项液压著作权、AAA 级重合同守信用企业（需确认可公开项）

目标市场：越南 + 印尼。历史有效市场还覆盖越南、巴西、伊朗（本次方案先聚焦越南和印尼）。

合作目标：曝光引流 + B2B 询盘转化 + 品牌建设。交付规模：10 个账号、300 条短视频内容，服务周期 3 个月。

#### 1.2 方案目标

本方案不是做"好看的工业视频"，而是让 TikTok 内容同时承担三件事：

1. **获得可传播的工业视觉流量**：用设备动作、精度测试、解压系列获取流量入口
2. **建立专业可信赖的工厂形象**：用制造流程、非标定制、出厂测试证明源头工厂能力
3. **引导海外批发商、经销商、工厂采购产生询盘**：用越南/印尼本地化内容+CTA降低询盘门槛

#### 1.3 核心挑战

| 挑战 | 说明 | 应对策略 |
|---|---|---|
| **低频高客单价品类** | 液压设备不是冲动消费品，买家决策周期长、信息需求大 | 每条视频回答一个采购问题，让买家看懂"能做什么、精度如何、适合哪些行业、交付和售后是否可靠" |
| **强技术信任门槛** | 海外买家担心低价设备质量、停机风险、备件供应和跨国售后 | 用真实设备动作、测试画面、工厂流程和应用场景建立信任 |
| **两个市场痛点不同** | 越南买家更关注"能不能快速升级产线"，印尼买家更关注"设备能不能稳定、省维护" | 同一批素材按不同市场编写不同标题、开头和 CTA |
| **内容生产量大** | 300 条内容不能靠人工逐条拍剪 | 通过 AI 辅助混剪与多版本内容组合，把同一批设备、工艺、测试、发货素材拆成多种询盘钩子 |

### 二、目标客户画像

#### 2.1 核心买家

| 客户类型 | 需求 | 关注点 |
|---|---|---|
| **工业设备经销商/批发商** | 寻找可长期代理或贴牌的中国液压设备工厂 | 价格空间、稳定供货、型号覆盖、售后政策、品牌资料 |
| **制造业工厂老板/采购负责人** | 采购压装、校直、整形、成型等生产设备 | 设备稳定性、交期、价格、安装调试、停机风险 |
| **自动化集成商** | 将液压压机、电缸压机接入自动化产线 | 控制接口、定制能力、重复精度、与机械手/MES/AGV配合能力 |
| **汽摩零部件/五金/电机/轴承厂** | 用于压装、冲压、校直、整形、测试等工序 | 精度、效率、良率、安全性、换型效率 |
| **中小加工厂** | 从人工或老旧设备升级到半自动/伺服设备 | 预算、操作简单、维护方便、小单可接、回本周期 |
| **贸易公司/贴牌客户** | 用自己的品牌销售液压设备 | OEM/ODM能力、交付速度、稳定质量、资料包装 |

#### 2.2 买家最常问的问题

1. 设备精度怎么证明？—— 买家不会只相信参数表，更希望看到重复定位测试、实际压装过程、检测数据上屏、误差对比等可视化证据
2. 设备能不能适配我的产品？—— 非标液压设备需要根据工件尺寸、压力、行程、节拍、安全要求定制
3. 价格低会不会牺牲质量？—— 越南、印尼买家对中国设备价格有兴趣，但也担心低价设备故障率高、机架不稳、液压系统漏油、售后跟不上
4. 交期和调试周期是否可控？—— 工业设备采购会影响生产计划
5. 海外售后如何做？—— 设备故障会直接影响产线
6. 设备重量、包装和运输怎么处理？—— 液压设备体积和重量较大

#### 2.3 内容应反复回答的 3 个问题

1. **这台机器能做什么？** —— 用真实工件、压装过程、检测结果证明
2. **为什么要从你这买？** —— 用工厂实力、制造流程、测试数据、售后政策证明
3. **下一步怎么沟通？** —— 用清晰的 CTA 引导发工件/参数/需求

### 四、奥创（Versa AI）的价值定位

#### 4.1 客户为什么要选择奥创？

工业设备工厂做海外短视频，自己搞会遇到 5 层问题：

| 自己做的问题 | 奥创怎么解决 |
|---|---|
| **不懂做什么**：拍了机器不知道海外买家想看什么 | 用客户资料+市场调研+行业洞察+竞品分析，先搞清谁说、对谁说、说什么 |
| **产能不够**：300 条视频，人工逐条拍剪根本做不到 | AI 辅助混剪与多版本内容组合，同一批素材自动拆成多市场多钩子多版本 |
| **试错太慢**：不知道哪条内容哪个市场有效 | 多账号矩阵同时分发测试，数据驱动快速收敛 |
| **询盘接不住**：有评论私信但不知道怎么转成销售线索 | 线索承接 SOP + CRM 回流闭环 |
| **自己不懂市场**：不做越南语/印尼语内容，不知道当地买家痛点 | 每个市场单独调研，内容按语言和市场本地化 |

**一句话**：客户买的不是"300 条视频"，而是从"不知道怎么做海外短视频"到"有曝光、有信任、有询盘"的一整套海外获客系统。

### 4.3 奥创 vs 自建团队：能力与价格比较

很多工厂会考虑“我能不能自己招人做 TikTok / YouTube 海外获客”。核心区别不在于能不能发视频，而在于：自建团队要同时补齐市场研究、内容策划、拍摄统筹、剪辑生产、多语种运营、账号矩阵、数据复盘、线索承接和 CRM 回流，前期试错成本高、周期长。

| 对比维度 | 自己招员工做 | 选择奥创 |
|---|---|---|
| **启动周期** | 招人、培训、摸索内容方向，通常 1–3 个月才开始稳定产出 | 直接基于客户资料、行业调研和模板化流程启动，首月即可进入内容测试 |
| **团队配置** | 至少需要海外运营/内容策划/拍摄统筹/剪辑/外语运营/数据分析，实际 3–5 人起步 | 奥创提供策略、AI 混剪、多语种内容、矩阵测试、数据复盘的一体化服务 |
| **内容产能** | 人工剪辑为主，产能受人力限制，300 条内容压力大 | AI 辅助混剪，同一批素材可拆成多语言、多钩子、多市场版本 |
| **市场理解** | 新员工需要慢慢理解越南/印尼买家、竞品、平台算法和工业设备销售逻辑 | 从方案阶段就完成市场、竞品、买家痛点、平台数据和 CTA 设计 |
| **试错成本** | 方向错了仍要持续支付工资、社保、管理和设备成本 | 用项目制服务把试错集中在内容和数据上，降低固定人力沉没成本 |
| **转化闭环** | 往往只做到发视频，评论/私信/CRM/销售跟进容易断 | 从内容发布到线索承接、CRM 回流、销售策略优化形成闭环 |
| **可复制性** | 依赖个人能力，员工离职后经验容易断档 | 方法论、模板、数据和素材资产可沉淀复用 |

#### 自建团队成本粗算（参考区间）

| 岗位 | 常见月成本区间 | 说明 |
|---|---:|---|
| 海外短视频运营/账号运营 | 12,000–20,000 元/月 | 负责账号、发布、互动、数据 |

#### 价格比较口径

奥创不应只和“一个剪辑员工”比较，而应和一支能够完成海外获客闭环的小团队比较。客户选择奥创，本质上是把固定人力成本、招聘风险和试错周期，转换成一套可交付、可复盘、可优化的项目制服务。

| 方案 | 成本结构 | 适合情况 |
|---|---|---|
| **自建团队** | 每月固定人力 + 管理 + 设备 + 试错成本，3 个月通常 21–42 万元起 | 已经有成熟海外内容负责人、长期预算充足、愿意承担试错周期 |
| **奥创服务** | 按服务包购买策略、内容生产、矩阵测试、线索承接和复盘能力 | 希望快速启动、降低试错成本、用 3 个月验证海外短视频获客模型 |

> 建议对客户表达：如果企业已经有成熟海外内容团队，奥创可以作为 AI 产能和策略增强；如果企业从 0 起步，奥创比直接招 3–5 人更快、更轻、更容易验证 ROI。最终报价以双方确认的服务包为准。

### 4.4 为什么不建议只做 3 个月，而建议 12 个月起

对于液压机、伺服压机、非标工业设备这类 B2B 高客单、低频采购品类，3 个月更适合定义为“冷启动验证期”，不适合作为完整获客周期。客户如果只做 3 个月，很容易刚完成账号冷启动、素材测试和初步询盘验证，就在真正进入转化复利前停止。

| 维度 | 只做 3 个月的问题 | 做 12 个月的价值 |
|---|---|---|
| **B2B 决策周期** | 工业设备采购不是即时下单，买家通常要经历需求确认、参数沟通、报价、内部审批、供应商比较 | 覆盖从首次触达到多轮沟通、报价、复访和成交的完整周期 |
| **账号冷启动** | 前 1–2 个月主要在测试内容方向、语言、标签、CTA 和目标人群 | 账号逐步积累垂直标签、内容资产和稳定触达，后续内容更容易命中目标买家 |
| **内容模型验证** | 3 个月只能知道“哪些视频有人看”，不一定能知道“哪些内容带来高质量询盘” | 12 个月可以从播放、私信、有效询盘、报价、商机、成交数据反推高价值内容模型 |
| **素材复利** | 初期素材还没充分复用，300 条内容只是第一轮测试 | 同一批设备、测试、发货、客户现场素材可以持续拆成多市场、多语言、多钩子版本 |
| **市场季节性** | 越南/印尼采购、展会、预算、工厂扩产都有周期，只做 3 个月可能错过采购窗口 | 覆盖全年展会季、采购预算季、行业淡旺季，能持续承接不同阶段需求 |
| **销售闭环** | 只做内容，CRM 和销售跟进还没形成稳定反馈 | 内容数据、询盘质量、销售反馈、成交画像可以形成闭环，持续优化投放和内容 |
| **品牌信任** | 工业设备买家看到一个新账号，短期内信任不足 | 持续更新 12 个月能让买家感知这是一家真实、稳定、长期经营的源头工厂 |

#### 推荐表达口径

奥创可以把前 3 个月定义为“验证期”，但不建议客户把它理解为完整项目周期：

1. **0–3 个月：冷启动与模型验证**  
   搭建账号矩阵，测试设备动作、精度测试、非标定制、售后、娱乐引流等内容模型，验证哪些方向有播放和询盘。

2. **4–6 个月：放大高效内容模型**  
   把已验证的高播放、高私信、高询盘选题做多语言、多账号、多开头放大，建立稳定线索来源。

3. **7–12 个月：销售闭环与品牌沉淀**  
   将内容数据、CRM 线索、销售反馈、成交客户画像打通，形成“内容获客 → 询盘承接 → 销售跟进 → 成交复盘 → 内容优化”的增长闭环。

> 建议对客户表达：3 个月可以买到一次内容试验，12 个月才有机会建立一套可持续的海外获客系统。工业设备不是消费品，真正的价值不在于短期发了多少条视频，而在于能否持续积累信任、线索和成交数据。

### 六、AI 短视频选题库（基于客户需求表，拍摄实操优先）

#### 6.1 生产实力类（基于客户"焊接/装配/车加工"工艺）

1. 🔥 **【Custom hydraulic press】发一个工件，我们怎么定制设备？**
   → 拍摄工件→沟通→工程师讨论→设计图→组装→调试完整流程

2. **【从焊接到装配】一台液压机如何被制造出来？**
   → 焊接→车加工→装配→液压系统安装→电气接线→调试

3. **【非标设备出厂前】我们会测试哪些项目？**
   → 压力测试→重复动作测试→安全检查→参数复核→出厂视频

4. **【可接小单】中小工厂也能定制自己的压机**
   → 突出交期短、价格友好、适合越南/印尼中小制造企业

#### 6.2 品质测试类（基于客户"精度测试+出厂测试"）

1. 🔥 **【±0.01mm？】伺服压机重复定位精度测试**
   → 设备重复下压→检测仪表→数据上屏→对比标尺

2. **【一台设备完成压装】从对位到压合再到检测**
   → 工件放置→触摸屏参数设定→压装动作→取件检测

3. **【压力从 0 到目标值】压力表和液压动作特写**
   → 压力表→油缸→滑块→工件受力瞬间

4. **【手动设备 vs 伺服压机】效率和稳定性对比**
   → 旧方式/手动方式与伺服压机对比

#### 6.3 产品魅力类（基于客户"五大主推设备"）

1. **单柱液压机：适合小吨位压装和校正场景**
2. **四柱液压机：适合大台面和精密成型**
3. **伺服液压机：高精度+节能+能效优化**
4. **伺服电缸压机：精密压装+数据可追溯**
5. **液压校直机：弯曲→恢复直线度的可视化过程**

#### 6.4 应用场景类（基于客户"汽摩零部件/五金/电机/轴承等行业"）

1. 🔥 **【汽车零部件压装】伺服压机如何提升一致性？**
2. **【液压校直机】弯曲工件如何恢复直线度？**
3. **【客户现场生产过程】这台设备每天在工厂做什么？**
4. **【一机多用】压装、整形、校直、冲裁能否一台解决？**

#### 6.5 B2B 转化类（基于客户"买家最常问的问题 + 核心痛点"）

1. **【How to get a quote】买液压机前要提供哪些信息？**
2. **【从中国工厂发往越南/印尼】设备如何包装发货？**
3. **【OEM/ODM】贸易公司如何贴牌合作？**
4. **【质保一年，终身维护】海外客户最关心的售后问题**
5. **【为什么这台液压机更耐用？】看机架、油缸和液压系统**

#### 6.6 TikTok 娱乐引流类（控制在 15–20%，每条约 30–45s）

1. **液压机压万物/解压系列**：压报废零件、铝罐、木块、橡胶块、废旧轴承 → 钩子："What should we crush next?"
2. **猜结果挑战**：开头展示待压物体→暂停 1 秒让观众猜→压合结果 → 钩子："Comment: crush/explode/survive"
3. **反差式工业娱乐**：干净产品镜头→突然强力压合慢动作 → "Satisfying or terrifying?"
4. **工厂老板看得懂的娱乐化测试**：娱乐素材→接一秒真实参数（吨位/行程/控制方式/适用工件）

> 安全注意：娱乐化内容必须使用安全可控的测试物，保留防护罩/操作距离/安全提示，不损害设备厂商专业形象。

### 七、单条视频结构

#### 结构 A：视觉钩子型（适用于工厂实力 + 产品魅力）

- 0–2 秒：强视觉钩子（机器动作/压力瞬间/火花/慢动作）
- 2–8 秒：过程/产品展示/细节
- 8–15 秒：结果/卖点/应用价值
- 结尾：CTA + 询盘引导

#### 结构 B：测试信任型（适用于品质测试）

- 0–2 秒：买家担忧/测试悬念
- 2–8 秒：测试过程
- 8–15 秒：结果特写/数据验证
- 结尾：询盘/样品 CTA

#### 结构 C：娱乐引流型（适用于解压/娱乐内容）

- 0–2 秒：悬念钩子"What happens when..."
- 2–20 秒：液压/变形/破坏过程（慢动作+声音）
- 20–25 秒：收束接真实工业应用一句话
- 结尾：引导关注+CTA

### 十、发布与转化

#### 10.1 发布频率与内容配比

服务周期 3 个月，300 条混剪内容按 10 个账号均衡铺开：

- 10 个账号整体共享同一套内容池
- 每个账号约 30 条混剪内容，可根据实际数据上下浮动
- 每个账号每周约 2–3 条，保证持续更新
- 不提前规定某个国家账号必须偏向某类内容，按数据自然调整

#### 10.2 内容发布原则

1. **工厂实力**：车间/焊装/加工/包装/发货，约 20%
2. **产品展示**：五类设备/部件/屏幕/操作，约 20%

### 十一、产品视频规划（AI 增强版）

#### 11.1 为什么需要 AI 增强版

部分压装场景、行业应用和抽象卖点，仅靠实拍难以充分展示：
- **精度不可见**：±0.01mm 精度在实拍中难以用画面量化
- **应用场景缺失**：无法拍到客户工厂的生产过程
- **流程抽象**：设备从需求到交付的定制逻辑难以在15秒内讲清
- **跨语种展示**：需要同一画面适配多语种信息

AI 增强视频可以将实拍素材与 AI 合成画面结合，快速生成虚拟应用场景、数据可视化、流程动画等。

#### 11.2 AI 增强视频类型

| 类型 | 内容 | 适合场景 | 目标 |
|---|---|---|---|
| **虚拟应用场景** | 在虚构工厂场景中展示设备运作 | 缺少客户现场素材时 | 让买家"看到"设备在自己的产线里运作 |
| **数据可视化** | 精度/压力/行程/效率用动态图表呈现 | 参数类卖点 | 把数字变成可理解的画面 |
| **三维拆解** | 用 3D 动画展示设备结构/液压系统/安全装置 | 技术信任卖点 | 让买家"看透"设备内部 |
| **流程动画** | 从需求→设计→生产→交付→售后的完整链路 | B2B 转化 | 让买家理解合作全流程 |

### 十二、官号视频策划案（复用承接版）

> 官号不再另开一套新内容战线，而是把前面的短视频、产品视频、AI 产品视频做"精选复用 + 品牌承接 + 线索转化"。矩阵号负责产内容和跑流量，官号负责把流量收口成可信赖的品牌主页。

#### 12.1 官号的意义

- **品牌确认**：海外买家看到矩阵号内容后，可以通过官号确认这是同一家真实工厂
- **内容归档**：把分散在多个矩阵号里的优质视频，按产品、测试、工厂、下单流程重新组织
- **线索承接**：集中放置 catalog、sample request、WhatsApp、MOQ/交期等采购入口
- **信任增强**：通过置顶视频、合集、主页信息，让买家快速判断"这家公司是否值得询盘"

**一句话**：矩阵号做流量，产品视频做展示，官号做信任和转化。优先复用，不新增战线。

#### 12.2 官号置顶视频（全部可由已有内容改剪）

1. **视频 1：3 分钟工厂全景** → 车间/设备/测试/发货/团队 →"Who We Are"
2. **视频 2：五大主推设备 60s 快速看** → 每台机器最精彩的 10s
3. **视频 3：How to Get a Quote** → 发工件→报价→排产→出货

#### 12.3 执行原则

- 置顶视频全部从已拍素材精剪，不单独拍摄
- 官号主页信息用英语（必修）+ 越南语/印尼语（按需）
- 置顶视频定期替换为最新高播放内容
