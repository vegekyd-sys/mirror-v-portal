### ⚡ 巴西电网为什么这么差？

- 风光发电爆发式增长，输电设施跟不上——2025年弃风弃光率达 **17.2%**
- 水电仍占电网 46-50%，干旱年份直接缺口
- 电网运营商ONS公开警告：分布式发电再增50%，未来停电只会更多
- 数据中心大举进驻（AWS/微软/谷歌），对备用电源要求极高

**→ 巴西的电网问题不是短期现象，是结构性的。每次停电，就多一个人需要发电机。**
