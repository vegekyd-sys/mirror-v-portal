## 第二类：CBIE & 知识库（入口链路）

让对方模型 / 飞书对话测试。

### 2.1 给 URL 触发 CBIE
```
在飞书对话中发: www.saametools.com
```
- [ ] 2 秒内回复确认（不等分析完）
- [ ] 20 秒内给出判断式摘要（不是表格、不是数据罗列）
- [ ] 摘要包含: 公司定位(1句) + 核心竞争力(1句) + 出海判断(1句)
- [ ] 判断后追问待确认项（产能、渠道等），不是一次扔四个问题

### 2.2 用户补充信息后
```
回复: "手动工具+电动套件，欧洲，KENDO自有品牌"
```
- [ ] 收到确认后，更新画像
- [ ] 不主动发 KB 链接
- [ ] 只问一句「知识库建好了，要看吗？」

### 2.3 用户说「看」
```
回复: "看"
```
- [ ] 发三条链接
- [ ] 链接是纯链接，没有任何说明文字、没有"三层""首页""主题页"等描述
- [ ] 没有物料清单、没有就绪度分析

### 2.4 用户不说看
```
重新开始一次: 给 URL → 确认信息 → 出现「要看吗」→ 回复"不用"或直接不理
```
- [ ] 不发链接，到此为止，不追问
