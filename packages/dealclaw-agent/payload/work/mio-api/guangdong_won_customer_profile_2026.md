# 广东赢单客户画像与数据开发方向（CRM 2026样本）

> 数据口径：Deals模块，Stage=赢单，Created_Time>=2026-01-01；广东样本按 firstDept/secondDept/Team/公司名含广佛、深圳、华南及广东城市关键词筛选。本次共拉取 2026 年赢单商机 2935 条，筛出广东/华南相关赢单 1219 条，覆盖约 947 家公司。注意：行业归类基于 CRM 的 Main\_Products、zone、部门和商机名称关键词，适合作业务开发方向判断，不等同财务口径。

## 一句话结论

广东赢单客户不是单一行业，最强的高转化方向集中在五类：**泛家居/礼品日用、工业机械/设备、家电3C、建材五金、纺织服装**。其中最适合业务团队优先开发的是：

1. **佛山/中山/东莞/广州的制造型外贸客户**；
2. **有明确展会品类匹配的客户**，特别是面辅料、建材、办公家具、服装、厨房/日用家电、卫浴五金、食品加工包装机械；
3. **已验证市场方向为印尼、越南、阿联酋/迪拜、巴西、墨西哥、沙特**的客户；
4. **复购/多项目客户**：同一家公司一年内多条赢单，说明跨市场、跨展会复制空间大。

### 重点解读

- **泛家居/礼品日用**：样本最大，覆盖家具、餐厨、清洁、纸尿裤、咖啡机、家居用品等，适合做广谱开发池。
- **工业机械/设备**：数量非常高，且常和包装、食品加工、金属加工、液压、电机等场景绑定，适合按“应用场景 + 目标市场”开发。
- **家电3C**：广东优势明显，尤其厨房家电、日用家电、消费电子、照明、电源/逆变器。
- **建材五金**：门窗、遮阳、卫浴五金、建筑材料、玻璃胶等转化明显，适合搭配中东、东南亚、拉美市场。
- **纺织服装**：面料、服装、内衣、箱包鞋子表现强，且复购客户较明显。

## 5. 高转化客户画像

### A类：广东制造 + 明确出口展会匹配

特征：公司名/产品清晰，CRM Main\_Products 和展区能对应；例如面料、门窗、办公家具、厨房家电、包装机械、卫浴五金。  
开发方向：优先找有展会记录、海关提单、B2B平台、官网、广交会/国际展会刊标签的企业。

### B类：可跨市场复制的复购客户

特征：同一家公司在多个市场/展会赢单，如巴西、墨西哥、沙特、波兰、越南、印尼多项目出现。  
开发方向：不要只卖一个展；用“同品类跨市场组合包”推进，例如巴西 + 墨西哥、印尼 + 越南、阿联酋 + 沙特。

### C类：佛山/中山/东莞产业带客户

特征：家电、家具、建材五金、机械设备高度集中，客群密度高。  
开发方向：围绕产业带做名单开发，而不是散点找客户。

### D类：已有明确产品词的客户

高频产品词包括：面料、家具、门窗、办公椅、服装、机械、箱包、咖啡机、电风扇、燃气灶、内衣、液压泵、纸尿裤、玩具、逆变器。  
开发方向：把产品词作为筛选条件，先圈出“产品词 + 出口/展会/官网/B2B平台”交集客户。

## 6. 建议业务团队马上执行的开发方向

### 第一优先级：五大品类池

1. **面辅料/服装/内衣/箱包鞋**：重点广州、佛山、中山、东莞；主推波兰、日本、沙特、巴西、阿联酋。
2. **家电3C/厨房小家电/日用家电/照明**：重点中山、佛山、东莞、惠州、深圳；主推印尼、越南、阿联酋、巴西、墨西哥。
3. **建材五金/门窗/卫浴/遮阳/胶类**：重点佛山、广州、中山；主推中东、东南亚、拉美。
4. **泛家居/家具/办公家具/餐厨清洁**：重点佛山、广州、东莞、中山；主推印尼、越南、墨西哥、巴西、南非。
5. **工业机械/包装/食品加工/金属加工**：重点佛山、东莞、广州、惠州；主推印尼、越南、沙特、阿联酋、巴西。

### 第二优先级：复购打法

对一年内多条赢单客户，优先做：

- 同品类跨市场加购；
- 同市场不同展区扩展；
- 老客户转介绍同产业带；
- 对标客户名单开发。

## 7. 推荐筛选规则

给数据开发团队的圈选条件建议：

1. 地域：佛山、广州、东莞、中山优先；惠州、江门、深圳、珠海补充。
2. 标签：国际展会刊、广交会、海关提单、B2B平台、官网、近年营销活跃。
3. 产品词：面料、服装、门窗、办公椅、厨房家电、日用家电、卫浴五金、包装机械、食品加工机械、咖啡机、电风扇、燃气灶、箱包、内衣、液压泵、逆变器。
4. 排除：无明确产品、无官网/无出口/无展会线索、仅本地贸易噪声的低质量数据。
5. 打分：产品匹配 + 展会/提单/平台标签 + 目标市场匹配 + 是否同产业带 + 是否有历史赢单相似客户。

## 最终建议

如果业务团队明天就要做数据开发，我建议先开三个池：

1. **佛山/中山家电3C + 厨房/日用家电池**：转化路径清晰，市场匹配强。
2. **佛山/广州/东莞建材五金 + 门窗卫浴池**：中东、东南亚、拉美都有验证。
3. **广州/佛山纺织服装 + 面辅料/内衣池**：复购和跨市场空间明显。

这三个池先各圈 300-500 家，按“有官网/有展会/有提单/有B2B平台/有近年营销标签”打分，业务优先打 A/B 分层名单。不要一上来全广东撒网。
