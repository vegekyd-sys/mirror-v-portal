## 三、选择逻辑（对话里怎么给用户选）

1. 知道用户「行业 + 目标国家/展会」→ 从对应「行业专业展」里选一个同行业、同语言（西语=拉美/墨西哥，葡语=巴西，英语=中东/其他）的模板。
2. 单个展商要推自己 → 用「展商推广」类，替换展商名/产品/展位号。
3. 没有完全匹配的行业 → 用最接近的行业模板，或「泛家居」兜底（当前无泛家居模板时，用 DEFU 软装或 Homelife 类兜底）。
4. 语言优先跟目标市场走：墨西哥/拉美→西语，巴西→葡语，迪拜/中东→英语。

## 四、生成时替换的字段（模板里的占位）

- 展会名 / 日期 / 地点 / 国家
- 展商名 / 展位号 / 产品线
- 报名入口链接 / 退订链接
- 参展商名录（行业专业展类）
