### 部署过程（踩坑记录）

- **Jenkins PT_CHECKBOX 参数提交格式**：`DEPLOY_SERVICE_LIST` 是 ExtendedChoiceParameter(PT_CHECKBOX) 类型，`buildWithParameters` 用普通逗号分隔值或 JSON 数组值都会被静默丢弃（构建 #33/#34/#35 失败——回退到 SERVICE_NAME=dealclaw-nexus 找不到 Dockerfile）。**正确格式是重复表单字段**：多次 `--data-urlencode 'DEPLOY_SERVICE_LIST=服务名'`（与浏览器提交 checkbox 行为一致）
- Jenkins REST 触发需要：cookie jar 维持会话 + crumb 同会话获取（`buildWithParameters` 端点，`build` 会 400）
