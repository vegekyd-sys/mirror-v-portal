# 早晚报推送格式（冻结 v1.0）

> 定稿：2026-09-11 · 田耕郡（决定：**不做上届对比**，先固化发布）
> 参考样例：`docs/daily-brief/push-sample-battle.md`（合成数据）
> 实现：`work/mio-api/dc_daily_report.py`（`_exhibition_battle` / `_today_metrics` / `_fmt_pipeline_morning` / `_fmt_pipeline_evening` / `_pipeline_brief`）

## 结构（推送文案，从上到下）

**早报**
1. `【本届展会战报】` —— 漏斗 + 高匹配 + 新增商机
2. `【今日数据】` —— 今日会谈/收到回复/待跟进 + 邮件 + 新增商机 + 本届展会
3. `【今日优先】` —— Top-N（有证据客户）
4. `【待分层批量跟进】` —— 无商机证据的批量跟进
5. `【风险】` —— 数据质量 / 邀约拒绝等
（其后接原有指标行：发送/送达/回复/退信、待跟进、草稿、明细链接）

**晚报** = 1、2 同上；第 3 段换 `【晚报核销】`（done/partial/unresolved），再接原有指标行。

## 字段口径

- **战报漏斗**：邀约 N → 到展 M（到场率 M/N）→ 有效商洽 K（商洽率 K/M）→ 商务推进 J
  - 到展 = `isCheckIn=1`；有效商洽 = 到展且 `isMeeting=1` 或 meeting 互动有内容；商务推进 = 有商务信号或 stage∈{报价中,需求明确,商务跟进}
  - 只统计**本届展会**买家（exhibition_id 门禁）；无本届数据 → 整块不输出
- **高匹配买家**：A 级 / B 级数量
- **今日数据**：今日会谈 = 今日 `channel=meeting` 互动（按客户去重）；收到回复 = 今日 `inbound` 互动；待跟进 = 管线里 buyer 目标去重数；邮件 = 发送/送达/回复/退信；新增商机 = 今日报价/样品/会议意向信号；本届展会 = 到展/会议/未到场
- **时区**：日期一律转 `Asia/Shanghai` 再取日（`_local_date_of`），避免 UTC 跨日错配

## 硬规则（冻结）

1. Top-N 只放**有商机证据**的客户，不按读取顺序。
2. 无商机证据的买家归【待分层批量跟进】，不虚构重点客户。
3. 数据未同步 → 出【数据质量风险】，**不报 0**。
4. lost / 停止触达 / 退订 / paused / won 不生成发送建议。
5. LLM 建议**只做影子**，不进推送、不执行 proposal、不接自动发送。
6. 任一片段生成失败/无数据 → 返回空串，**不破坏旧文案**（推送可用性优先）。

- 不含金额 / 意向额（数据源未就绪）。
