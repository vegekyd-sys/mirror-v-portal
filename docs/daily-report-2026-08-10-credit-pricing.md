## 二、定价模型

### 公式

```
Skill Credit = 平衡（成本底线，业务价值底线，商业消耗底线）
成本底线 = 直接成本 × 风险系数 ÷ 0.01 ÷（1 - 目标毛利率）
直接成本 = Token成本（实测 ¥0.013/1K）+ 外部API成本
```

### 三轮平衡逻辑

- **成本底线**：保证不亏钱（Token+API+风险系数）
- **业务价值底线**：客户愿意为这个动作付多少钱
- **商业消耗底线**：保证套餐在合理周期消耗完，驱动续费升级

三者取平衡，非简单取最大值。

### 关键发现

**Token 成本极低。** deepseek-v4-pro 实测 $0.0018/1K token，一条买家搜索的 Token 成本仅 ¥0.13。真正驱动成本的是外部 API（CDP、Apollo、OCR 等）。

## 四、商业消耗验证

**Start 500K · 中度用户**（月耗 ~46K → 可用 ~11 个月）：
- 月搜 30 次买家 + 3 次画像 + 半份报告 + 100 封邮件
- 一年合同期内够用，年末需要续费

**Start 500K · 重度用户**（月耗 ~118K → ~4 个月溢出）：
- 月搜 60 次买家 + 8 次画像 + 1 份报告 + 300 封邮件
- 自然升级 Growth（1,500K）或续充 ¥1,000/100K

**续费→升级→持续收入链条完整。**
