## 二、需要平台层做的（关键卡点）

### 2.1 定时调度（必须 per-tenant）

现在只有本机 crontab（租户 `100000834234`）。**客户实例没有这两条 → 不会自动跑。**

```cron
# 出站 · 每 30 分钟（决策→路由→生成→发送）
*/30 * * * * cd <agent_workspace> && python3 work/mio-api/dc_marketing_automation_cron.py --company-id $MIO_CDP_SUPPLIER_ID --no-dry-run >> /tmp/marketing-automation.log 2>&1

# 入站 · 每 15 分钟（回复→触发 smart-reply）
*/15 * * * * cd <agent_workspace> && python3 work/mio-api/dc_marketing_automation_inbound.py --company-id $MIO_CDP_SUPPLIER_ID --no-dry-run >> /tmp/marketing-inbound.log 2>&1
```

**要求**：每个租户/实例按**各自的 workspace + `MIO_CDP_SUPPLIER_ID`** 配这两条。
> 参考：`HEARTBEAT.md` 已写明「本 Agent 的自主定时运行需配置层显式开启」——同一原则。

### 2.2 generator 运行前提

`dc_marketing_automation_generator.openclaw_generator` 调 `openclaw agent --agent dealclaw --thinking off --message-file ... --json`。
**要求**：客户环境必须有 `openclaw` CLI，且注册了 `dealclaw` agent（workspace 指向该租户）。

### 2.3 每租户配置项
- `MIO_CDP_SUPPLIER_ID`（企业 key）
- 发件身份（默认 `V@mail.dealclaw.io`，或租户自有）+ **Resend 域名预热**
- 飞书绑定（回信通知）
