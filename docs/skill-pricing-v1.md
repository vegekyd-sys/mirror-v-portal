# 出海精灵·小元 Skill 定价文档 V1.2

> 版本：V1.2（实测成本校准 + 商业消耗平衡）
> 日期：2026-08-10
> 定价公式：Skill Credit = 平衡(成本底线, 业务价值底线, 商业消耗底线)
> 数据来源：6个内测群 1.15M token 实测（$0.0018/1K token, deepseek-v4-pro）

---

## 定价公式

```
Skill Credit = 平衡（成本底线，业务价值底线，商业消耗底线）

成本底线 = 直接成本 × 风险系数 ÷ 0.01 ÷（1 - 目标毛利率）
直接成本 = Token成本（实测 ¥0.013/1K） + 外部API成本

商业消耗约束：Start 500K 中度用户 10-11 个月用完，重度用户 4 个月溢出
```
