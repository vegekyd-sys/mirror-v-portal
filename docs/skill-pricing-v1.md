# 出海精灵·小元 Skill 一期定价文档

> 版本：V1.0
> 日期：2026-08-10
> 适用：测试期间（非商业化环境）
> 基准：Start 套餐 500,000 Credit，1 Credit = ¥0.01

---

## 0. 定价公式（来自《统一 Credit 商业化方案 V2.0》）

```
Skill Credit = max(业务价值底线, 成本底线)

成本底线 = 预计直接成本 × 风险系数 ÷ 0.01（Credit单位售价）÷（1 - 目标毛利率）
```

- Credit 单位售价 = ¥0.01（即 100,000 Credit = ¥1,000）
- 目标毛利率：数据/联系人类 65%，文本/报告类 80%，邮件/通道类 50%
- 结果向标准档位取整

## 5. 后续调整规则

| 场景 | 调整方式 |
|---|---|
| 某个 Skill 实际成本高于预期 | 提高风险系数或降低目标毛利率，重新计算成本底线 |
| 客户普遍觉得某 Skill 太贵 | 降低业务价值底线（但不得低于成本底线） |
| 新数据源/新模型降低成本 | 更新预计直接成本，调低定价 |
| 供应商涨价 | 触发临时调价，不影响已执行中任务 |

## 6. 一期不做什么

- 不做动态国家/行业/渠道系数（全部 baseline 参数透明）
- 不做 Shadow Billing 先行（测试期直接 Live，价格随时调）
- 不做预售占和部分结算（测试期量小，全部执行后一次性扣费）
- 不做 Lot 有效期管理（人工配余额）
- 不做 7 日返还/退费（测试期不纠结这个，客户用的就是送的 Credit）

**这些等商业化前夕统一上线。**
